# マスマティック・ザ・ギャザリング を Google Apps Script（GAS）で公開する

学校の iPad で遊ぶための **1ファイル版** と、**スプレッドシートを使うサーバー** です。
**学内（学校の Google アカウントの人）だけ** に公開します。

| ファイル | 中身 |
|---|---|
| `Code.gs` | ゲームを表示するプログラム ＋ サーバー（データはスプレッドシートに置く） |
| `index.html` | ゲーム本体（JS・CSS・絵をすべて中に入れた1ファイル。約 2.3MB） |
| `appsscript.json` | 設定（学内だけに公開・デプロイした先生として実行） |

## はじめの準備（パソコンで1回だけ）

ファイルが大きい（2.3MB）ので、手で貼り付けずに **clasp**（Google 公式の、コマンドでアップロードする道具）を使います。

### 1. clasp を入れる

1. パソコンに **Node.js** を入れる（https://nodejs.org の「LTS」）
2. ターミナル（Mac）／コマンドプロンプト（Windows）で：
   ```sh
   npm install -g @google/clasp
   clasp login
   ```
   ブラウザが開くので、**学校の Google アカウント** でログインして「許可」
3. https://script.google.com/home/usersettings を開いて「Google Apps Script API」を **オン** にする

### 2. 3つの ファイルを 手元に置く（git は いりません）

1. パソコンに フォルダを 1つ作る（例：デスクトップに `mathgathering`）
2. 次の 3つを 開いて、それぞれ「名前を付けて保存」（Ctrl+S）で その フォルダに 保存する。**名前は そのまま**（`Code.gs`・`index.html`・`appsscript.json`）
   - [Code.gs](https://raw.githubusercontent.com/shimpseguchi-jpg/math-gathering/main/gas/Code.gs)
   - [index.html](https://raw.githubusercontent.com/shimpseguchi-jpg/math-gathering/main/gas/index.html)
   - [appsscript.json](https://raw.githubusercontent.com/shimpseguchi-jpg/math-gathering/main/gas/appsscript.json)
   - Windows で「.txt」が 後ろに つかないように、保存の 種類は「すべてのファイル」にする
3. ターミナルで その フォルダに 移る：`cd Desktop/mathgathering`（Windows は `cd Desktop\mathgathering`）

（git が 使えるなら `git clone https://github.com/shimpseguchi-jpg/math-gathering.git` して `gas` に 移っても よい）

**Mac なら**、ターミナルで まとめて 保存できる（ブラウザで 保存すると `.txt` が つく ことが あるので こちらが おすすめ。更新の ときも おなじ）：

```sh
mkdir -p ~/Desktop/mathgathering && cd ~/Desktop/mathgathering
for f in Code.gs index.html appsscript.json; do curl -fsSLO "https://raw.githubusercontent.com/shimpseguchi-jpg/math-gathering/main/gas/$f"; done
```

### 3. スプレッドシートとスクリプトを作る

```sh
clasp create --type sheets --title "マスマティック・ザ・ギャザリング" --rootDir .
```

- Google ドライブに **スプレッドシート** と、それにつながった **スクリプト** ができます
- このフォルダに `.clasp.json`（どのスクリプトに上げるかのメモ）ができます。**消さないでください**
- clasp が `appsscript.json` を書きかえることがあるので、つづけて元に戻します：
  2 で 保存した `appsscript.json` を もう一度 保存しなおしてください（git を 使った ときは `git checkout appsscript.json`）

### 4. アップロードしてデプロイ

```sh
clasp push        # 「マニフェストを上書きするか」と聞かれたら y（アップロードするのは Code.gs・index.html・appsscript.json の 3つだけ）
clasp open        # ブラウザで スクリプトの エディタが ひらく
```

エディタで：

1. 右上の「デプロイ」→「新しいデプロイ」→ 種類の選択（⚙️）で「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**（学校・自治体名）内の全員**
2. 「デプロイ」を押す。承認を求められたら自分のアカウントを選び、「詳細」→「（プロジェクト名）（安全ではないページ）に移動」→「許可」
   - スプレッドシートの読み書き、開いた人のメールアドレスを知る（先生かどうか・ひきつぎの持ち主を見分ける）、外部サイト（GitHub）からゲームを取ってくる、ための許可です
3. 表示された **ウェブアプリの URL**（`…/exec` で終わる）を子どもに配る
   - iPad の Safari で開き、共有ボタン →「ホーム画面に追加」

はじめてだれかが開いたとき、スプレッドシートに必要なシートが自動でできます。

## 私物の アカウントで 作って、学校の アカウントで 公開する とき

clasp（パソコンに のこる ログイン）は 私物の Google アカウントに して、学校の アカウントは パソコンに 入れない やりかたです。

| だれ | すること |
|---|---|
| 私物の アカウント | 1〜4 の 1・2・3 と `clasp push`（スクリプトの もちぬし）。スクリプトを 学校の アカウントと **共同編集** に する |
| 学校の アカウント | **データ用の スプレッドシートを 学校の ドライブに 作る**（下の 1）。デプロイする（下の 3） |

1. 学校の アカウントで、学校の ドライブに 空の スプレッドシートを 作る（名前は 例えば「マスギャザ データ」）。URL の `/d/` と `/edit` の あいだの 長い 文字が ID
2. 学校の アカウントで スクリプトの エディタを ひらき、左の ⚙️「プロジェクトの設定」→ 下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
   - プロパティ：`SHEET_ID`　値：1 の ID
   - これで 子どもの データ（ゴースト・ひきつぎ など）は 学校の ドライブに おかれる。私物の ドライブには 入らない（私物で 作る ときは、3 の `clasp create` を `--type standalone` に すると、私物の ドライブに シートが できない。`--type sheets` で 作った ときは、その シートは 空の まま。けしても よい）
3. 学校の アカウントで「デプロイ」→「新しいデプロイ」（実行：**自分**、アクセス：**学内の全員**）
   - 実行するのは デプロイした 学校の アカウント なので、学校の アカウントが 自動で 先生（かんりしゃ）に なる。私物の アカウントは 学内では ないので ひらけない
4. **たしかめる**：学校の べつの アカウント（同僚や テスト用）で URL を ひらき、「せってい」に「あずける／もどす」の ボタンが 出るか 見る
   - 「学校の アカウントで ひらくと つかえる」と 出たら、ひらいた 人の メールアドレスが とれて いない（スクリプトの もちぬしが 学外の ため）。その ときは 学校の アカウントで スクリプトを「コピーを作成」して、コピーの ほうを デプロイする（ゲームの 更新は ボタンで できるので、clasp を つかうのは Code.gs が かわった ときだけ）

**Code.gs が かわった ときは**：私物の アカウントで `clasp push` → **学校の アカウントで** エディタの「デプロイ」→「デプロイを管理」→ ✏️ →「新バージョン」。`clasp deploy` は 私物の アカウントの 名前で デプロイして しまうので つかわない。

## ゲームを新しくしたとき

### ふだん（カードや 画面が かわった とき）：ボタン 1つ

1. 先生の アカウントで ゲームを ひらき、タイトルの「開発モード（先生）」→ **「ゲームを最新にする」**
2. アプリを ひらきなおす（子どもの iPad も、ひらきなおすと 新しい 版に なる）

- Google の サーバーが、公開リポジトリ（GitHub）から 最新の ゲーム本体と カードの 一覧を とって、スプレッドシートの「ゲーム本体」シート（かくして ある）に おきます。iPad は GitHub に つながりません
- とってくる ブランチは「せってい」シートの **読みこみ元**（ふつうは `main`）
- パソコンも clasp も いりません（iPad からでも 押せます）
- 学校の 管理者が 外部サイトへの 接続を とめて いて エラーに なる ときは、下の「サーバーが かわった とき」と おなじ やりかたで ファイルごと 上げて ください

### たまに（サーバーの しくみ＝Code.gs が かわった とき）

「最新にする」で **「サーバー（Code.gs）が かわって います」** と 出たら、パソコンで：

1. 2 と おなじ リンクから `Code.gs`・`index.html`・`appsscript.json` を 保存しなおす（同じ フォルダに 上書き。`.clasp.json` は 消さない）
2. その フォルダで：
   ```sh
   clasp push
   clasp deployments          # いちばん下の「AKfy…」で はじまる ID を コピー（@HEAD では ない ほう）
   clasp deploy -i （コピーした ID） -d "更新"
   ```
   （エディタの「デプロイ」→「デプロイを管理」→ ✏️ →「新バージョン」→「デプロイ」でも おなじ）

URL は変わりません。スプレッドシートのデータもそのまま残ります。

## 先生がつかうもの

### 開発モード（先生だけ）

先生のアカウントで開くと、タイトルに **「開発モード（先生）」** が出ます。子どもには出ません。

| できること | 中身 |
|---|---|
| デバッグモード | この端末だけ、せってい画面で弾・こうこく・プレイマットを自由にかえられる（テスト用）。子どもの端末ではオンにしない |
| パックに入れる弾 | 第3弾などをパックに入れる・はずす |
| つかわないサブセット・番外編 | もんしょうで解放しても まぜないもの（番外編は他社の作品なので、必要ならここで止める） |
| レイド | レイドID と おわる日時。日時を空にするとレイドなし |
| オンライン バトル | ランキングの更新時刻、のこすゴーストの数 |
| かんりしゃ | 開発モードを使える先生の学校アカウント（デプロイした人はいつも使える） |
| ゲーム本体 | 「ゲームを最新にする」ボタンと、読みこみ元の ブランチ |
| あいことば | 3つのことば・もらえるカード・期間・回数 |

ここで変えた内容はスプレッドシートにも入ります。スプレッドシートを直接書きかえても同じです（反映まで最大5分）。

### スプレッドシートのシート

| シート | 中身 |
|---|---|
| せってい | 上の「パックに入れる弾」などの値（`こうもく` と `あたい`） |
| かんりしゃ | 先生のメールアドレス |
| ゴースト | オンライン バトルの相手（1行1デッキ。とどいた階ごとに 30人まで） |
| デッキの点 | 戦ったデッキの点（かち＋2・ひきわけ＋1・まけ−1） |
| ランキング | 上位20（毎日 7:00 と 17:00 に作りなおす） |
| レイド・レイドゴースト | レイドの陣営と統率者の点、統率者デッキのゴースト |
| あいことば・あいことばの記録 | あいことばと、使った人（読めない番号）・日時 |
| ひきつぎ | セーブのバックアップ（1人1行。読めない番号・日時・大きさ・データ） |
| ゲーム本体（かくしシート） | GitHub から とった ゲーム本体と カードの 一覧。さわらない |

- 子どもの **メールアドレスはどのシートにも書きません**。ひきつぎ・あいことばの記録は、メールアドレスから作った読めない番号です
- ゴーストのニックネームは定型語の番号（「ゆうかんな ドラゴン」など）。自由入力はありません
- 変なデッキやランキングを消したいときは、その行を削除してください
- 書式は「書式なしテキスト」にしてあります（ID や日時が数・日付に変わらないように）

### ひきつぎ（子ども）

せってい画面の「ひきつぎ」で **あずける／もどす**。学校のアカウントで開いていれば、ほかの iPad や、セーブが消えたときにも戻せます。

## まえの版からの ひっこし

スクリプト プロパティにデータを置いていた前の版から移すときは、新しいスクリプトに前のスクリプト プロパティを写してから、エディタで関数 `mtgMigrate` を1回実行します（ゴースト・デッキの点・レイドがシートに入ります）。まだ公開していなければ不要です。

## 知っておくとよいこと

- GAS は配信するときに大きなスクリプトを書き換えてしまうことがあるため、JS と CSS は **base64（英数字だけの文字列）** にして HTML の中に入れ、ブラウザの中で元に戻してから動かしています。英数字だけの行がたくさん並んでいるのは正常です
- セーブは iPad のブラウザの中に残ります。Safari で7日以上開かないと消えることがあるので、ホーム画面に追加して開くか、ときどき「ひきつぎ」で あずけてください
- GitHub Pages 版（サーバーなし）は いつもデバッグモードで、オンライン バトルは見本デッキとの れんしゅうになります

## 開発者むけ

```sh
node tools/build_gas.mjs   # → gas/ の Code.gs・index.html・appsscript.json を作り直す（esbuild を npx で使う）
node tools/gastest.mjs     # Google の かわりの にせもので Code.gs を うごかして しらべる
```

`Code.gs` の元は `tools/gas_Code.gs`。カードの点数と色、弾の一覧は `js/data/cards.js` から自動で書きこまれます。
ゲームの側でサーバーとつなぐところは `js/ui/server.js`、開発モードの画面は `js/ui/admin.js`。
