# マスマティック・ザ・ギャザリング を Google Apps Script（GAS）で公開する

学校の iPad などで github.io が開けないときのための **1ファイル版** と、**オンライン バトル（非同期）** のサーバーです。
GAS の「ウェブアプリ」として公開すると、`https://script.google.com/...` の URL で遊べます。

| ファイル | 中身 |
|---|---|
| `Code.gs` | ゲームを表示するプログラム ＋ オンライン バトルのサーバー（ゴーストをあずかる） |
| `index.html` | ゲーム本体（JS・CSS をすべて中に入れた1ファイル。約320KB） |
| `appsscript.json` | clasp を使う人むけの設定（手作業なら不要） |

アルカナンバー・かずまほ（リポジトリの `gas/`）とは **別のプロジェクト** にしてください（ゴーストの保存場所を分けるため）。

## 手順（パソコンで1回だけ）

1. https://script.google.com を開いて「新しいプロジェクト」。左上の名前を「マスマティック・ザ・ギャザリング」にする
2. 最初からある `コード.gs` の中身を全部消して、[`Code.gs`](https://raw.githubusercontent.com/shimpseguchi-jpg/app-maker/claude/math-tcg-requirements-8oklux/mathtcg/gas/Code.gs) の中身を貼る
3. 左の「ファイル」の **＋** →「HTML」→ 名前を **`index`** にする（`.html` は自動でつく）
   中身を全部消して、[`index.html`](https://raw.githubusercontent.com/shimpseguchi-jpg/app-maker/claude/math-tcg-requirements-8oklux/mathtcg/gas/index.html) を開いて「すべて選択 → コピー」したものを貼る
4. 保存（💾 または Ctrl+S / ⌘+S）
5. 右上の「デプロイ」→「新しいデプロイ」→ 種類の選択（⚙️）で「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：
     - 学校の Google アカウントで作った場合 →「（学校・自治体名）内の全員」
     - 個人の Gmail で作って、子どもは学校のアカウントで開く場合 →「全員」
6. 「デプロイ」を押す。承認を求められたら自分のアカウントを選び、「詳細」→「（プロジェクト名）（安全ではないページ）に移動」→「許可」
   （ゴーストを保存するために、このスクリプト自身の保存領域を使う許可です。Google ドライブやメールには一切さわりません）
7. 表示された **ウェブアプリの URL**（`…/exec` で終わる）を iPad の Safari で開く
   - 共有ボタン →「ホーム画面に追加」で、アイコンから開けるようになる

> リンクは PR のブランチ（`claude/math-tcg-requirements-8oklux`）のファイルです。マージしたあとは、ブランチ名のところを `ccr-a96fc02a-yijbz1` に変えてください。

## ゲームを新しくしたとき

1. `index.html`（サーバーが変わったときは `Code.gs` も）の中身を新しいものに貼り替えて保存
2. 「デプロイ」→「デプロイを管理」→ ✏️（編集）→ バージョンを「新バージョン」→「デプロイ」

URL は変わりません。セーブデータ・ゴーストもそのまま残ります。

## オンライン バトル（非同期）

- 冒険を おえる（クリア または 途中で ちからつきる）と、その デッキが **ゴースト** として この スクリプトに あずけられる
- 冒険で くんだ デッキは **3つまで 保管** できる（いっぱいの ときは、冒険の おわりに どれと 入れかえるか えらぶ）
- タイトルの「オンライン バトル」で、保管した デッキを えらび、ほかの 人の ゴーストと たたかう。ゴーストは AI が動かす
- あいては **ランダム**：あずけられた ゴースト ぜんぶから 1人。まだ だれも いない ときは 見本デッキの「れんしゅう あいて」
- 勝つと トロフィー ＋3、負けると −1（ブロンズ → シルバー 10 → ゴールド 25 → ニクス 50）。トロフィーは その iPad の 中の きろく
- 自分の ゴーストが 勝つと、つぎに メニューを 開いたとき「きみの ゴーストが ○回 かったよ！」と出る
- 安全のため：チャットなし、なまえは 定型語を 2つ 組み合わせる だけ（「ゆうかんな ドラゴン」「ほのお ドラゴン」など）。あずかるのは デッキ・なまえ・とどいた 階・勝ち負けの 数 だけ

### サーバーの しくみ

| 関数 | すること |
|---|---|
| `mtgSubmitGhost` | ゴーストを あずける。デッキを チェック（20まい・30点まで・2色まで・知っている カードだけ） |
| `mtgRandomGhost` | あずかっている ゴースト ぜんぶから ランダムに 1人 かえす（自分の ゴーストは のぞく） |
| `mtgReport` | たたかいの けっか（ゴーストの 勝ち負けの 数を ふやす） |
| `mtgMyGhosts` | 自分の ゴーストの 勝ち負けの 数 |

- ゴーストは **スクリプト プロパティ** に、とどいた 階（1〜5・クリア）ごとに **30人まで**（古い ものから 消える）
- 消したいとき：エディタ左の ⚙️「プロジェクトの設定」→ 下の「スクリプト プロパティ」で `ghosts:1` 〜 `ghosts:6` を削除
- だれでも ゴーストを 送れる しくみなので、ルールに あわない デッキは うけとらない

## 知っておくとよいこと

- GAS は配信するときに大きなスクリプトを書き換えてしまうことがあるため、JS と CSS は **base64（英数字だけの文字列）** にして HTML の中に入れ、ブラウザの中で元に戻してから動かしています。英数字だけの行がたくさん並んでいるのは正常です
- セーブは iPad のブラウザの中に残ります（GitHub Pages 版とは別々）
- GitHub Pages 版（サーバーなし）でも「オンライン バトル」は 見本デッキとの れんしゅうとして 遊べます

## 1ファイル版の作り方（開発者むけ）

```sh
node mathtcg/tools/build_gas.mjs   # → mathtcg/gas/ の Code.gs・index.html・appsscript.json が作り直される（esbuild を npx で使う）
```

`Code.gs` の元は `mathtcg/tools/gas_Code.gs`。カードの点数と色は `js/data/cards.js` から自動で書きこまれます。
