## 1. ゲームの きまり（カードを 考える ときに 守る こと）

| 項目 | 内容 |
|---|---|
| 対象 | 小学生（1〜3年生が 読める）。iPad 横画面 |
| マナ | DM 式：毎ターン 手札から 1まい マナゾーンに 置く。カードの 色の マナが 出る |
| 手札 | 毎ターン 5まいに もどる（捨てる・墓地に 置く ことが 安い） |
| デッキ | 20まい。キャパシティ 30点（C 1・U 2・R 3・L 4点、きほんカード 0点）。2色まで |
| 色 | 白 W・青 U・黒 **K**・赤 R・緑 G（黒は K。B は きほんカードの ID で つかって いる） |
| レアリティ | C（コモン）・U（アンコモン）・R（レア）・L（レジェンド） |
| たたかい | 塔の 敵と たたかう ローグライク。たたかいの 中で 問題は 出さない。**勝つために 考えると 自然に 計算する** 能力に する（「ぴったり」：敵の タフネスと ちょうど 同じ ダメージで たおすと ボーナス） |
| ことば | キーワードは MTG の 日本語名の まま（飛行・接死・絆魂 など）。残酷な ことばは 言いかえる（生け贄に捧げる → 墓地に置く） |

| 元の カード | なるべく 実在の MTG カードを もとに する（英語名を 書く）。オリジナルは「オリジナル」 |
| 禁止 | リアルタイム対戦は 入れない |

## 2. カードの 表の 書きかた

設計書（`docs/SET3.md` など）の 表と おなじ 形。1行 1枚。

```
| ID | 名前 | レアリティ | コスト | タイプ | P/T | テキスト | 元のカード | 算数 |
|---|---|---|---|---|---|---|---|---|
| K01 | 夜（よる）の 子（こ） | C | 2 K | クリーチャー — 吸血鬼（きゅうけつき） | 2/1 | 絆魂（はんこん）。 | Child of Night | − |
| K02 | どくの ネズミ | C | 1 K | クリーチャー — ネズミ | 1/1 | 接死（せっし）。 | Typhoid Rats | 1点でも たおす |
```

- コスト：「数字 色」（`3 W` ＝ 合計3マナで 白が 1つ 要る。2色なら `4 WK`）。無色は 数字だけ
- P/T：クリーチャー だけ。ほかは `−`
- 算数：その カードで 自然に する 計算（足し算・ひき算・かけ算・数える・比べる など）。なければ `−`
- ID：色の 記号＋2けたの 番号（W41 など。つかって いない 番号に する）

## 3. いまの 作業：第3弾「冥界の 門」を ふやす（2026-10-28）

- いま 81種。黒 42・黒の 2色 16・無色 5・ほかの 4色 4〜5種ずつ（[`SET3.md`](SET3.md)）
- **方針（決定）**：黒が メインの まま、白・青・赤・緑に **1色 10種くらい**（C 5・U 3・R 1・L 1 くらい）足して、第3弾だけでも 5色で 遊べる 弾に する。合計 約120種
- 第1弾・第2弾に もう ある 仕組みは つかわない：召集・大隊・獰猛・飛行の 白青・カウンターの 緑青・呪文の 青赤（第1弾）、集会・消失・喊声・暴勇・**脱出**・適応（第2弾）
- 黒の 2色の アーキタイプ（足す カードは これと つながると よい）：白黒＝強請＋来世、青黒＝昂揚＋探査＋忍術、黒赤＝貪食＋マッドネス、黒緑＝−1/−1カウンター＋墓地から 回収
- **色ごとの 仕組みの 候補（まだ きまって いない。ユーザーが えらぶ）**：

| 色 | 候補 |
|---|---|
| 白 | ①降霊（墓地から 霊として 唱えなおす・Disturb）②ライフの 目標（25 いじょう なら・Ajani's Pridemate）③護法（ねらうと 追加で 2マナ・Ward） |
| 青 | ①切削（山札の 上を 墓地へ・Mill）②フラッシュバック ③予顕（いま 2マナ はらって 伏せ、あとで 安く・Foretell） |
| 赤 | ①墓地から 一時的に よみがえる（Unearth）②絢爛（敵が ダメージを 受けた ターンは 安い・Spectacle）③宝物トークン |
| 緑 | ①墓地を 数える（Lhurgoyf・Undergrowth）②マナを 置くたびに 誘発（DM の マナを いかした オリジナル）③再生 |

- おすすめ（Claude）：白①・青①・赤①・緑②（どれも 墓地か マナで 黒の 2色に つながる）

**ほかの AI に たのむ こと**：えらんだ 仕組みで、4色 × 10種の カードの 表（2章の 形）を 作る。ID は W・U・R・G の あいて いる 番号（SET3.md の 3章を 見て かさならない ように）。できた 表を この リポジトリの 作業（Claude）に わたせば、データ化・うごき・テストを する。
