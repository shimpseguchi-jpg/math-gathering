# 除去カードの コストの 見なおし

クリーチャーを 除去する カード（破壊・追放・ダメージ・−N/−N・−1/−1カウンター・もどす・留置・とめる オーラ・格闘・うばう）の コストを、ユーザーが きめた **つよさの じゅんばん** で そろえる ための しらべと 案。

- 状態：**入れた**（2026-11-06。ユーザーが「ぜんぶ 入れる」と きめた。入れた ときに かえた ところは 5章）
- しらべた もの：`js/data/cards.js` の `SETS` の ぜんぶの 弾（第1〜5弾・サブセット 6〜9・番外編 10〜12・14〜16）。レイド（13）・トークン・プロモ（まだ ない）は のぞく。学習（LS01・LS08・LS09）は 入れた
- 数：除去に かかわる カード **396まい**。モデルで 点を つけた もの 326まい（呪文・エンチャント 189・からだの ある もの 137）、モデルの 外（英雄譚・PW・連携 だけ・よわめる だけ など）70まい
- しるし（ずれ 1 いじょう）：**124まい** → 直す 案 **A 44まい**・ねらいかたの きまり **R 8まい**、ようすみ 72まい。さらに 4.6 の「じゅんばんの さかさま」チェックで **A 3まい**（K69・K94・SR117）を 足した
- 文は `js/data/texts.js`（docs の 表から）、コスト・レア・タイプは `BY_ID`、ねらいかたは `game.js` の `pickOf`・`PICK_FREE` と 各 `set*.js` の うごきで たしかめた

## 1. ルール（コストの モデル）

### 1.1 つよさの じゅんばん（ユーザーが きめた）

| # | じゅんばん | モデルの たし・ひき |
|---|---|---|
| 1 | **インスタント ＞ ソーサリー** | インスタント・瞬速 ＋0.5 |
| 2 | **−1/−1カウンター ＞ ターン終了時まで −N/−N** | カウンターは −N/−N より ＋1（のこる・増殖で ふえる）。オーラの −N/−N も のこる ので ＋1 |
| 3 | **追放 ＞ 破壊** | 追放は 破壊より ＋0.5 |
| 4 | **じぶんで えらぶ ＞ 条件つき ＞ ランダム** | えらぶ 0・条件つき（パワーが いちばん 大きい など）−0.5・ランダム −1・敵が えらぶ（いちばん 小さい を 墓地へ）−1 |

ねらいかたは カードの レアリティで きまる（REQUIREMENTS 8.6：コモン ランダム・アンコモン いちばん 大きい・レア/レジェンド えらぶ。`PICK_FREE` は どの レアでも えらぶ）。モデルは 文では なく **ほんとうの うごき** で 点を つけた（たとえば コモンでも うごきが「いちばん 大きい」の U104・R102・FG128 は 条件つき）。

### 1.4 からだの ある カード（クリーチャー の 出たとき・攻撃・能力・宝具・戦技 など）

**きたいの コスト ＝ からだ ＋ こうか × かかり ＋（R・L・多色）**

- からだ：P＋T が 7 まで は（P＋T − 1）÷ 2、8〜12 は 3 ＋（P＋T − 7）÷ 2、13 いじょう は 5.5 ＋（P＋T − 12）÷ 4。飛行・接死 ＋0.5、速攻・警戒・到達・先制攻撃・絆魂・トランプル ＋0.25、破壊不能 ＋1、防衛 −1
- こうか：1.2・1.3 を ソーサリーと して（瞬速の クリーチャーの 出たとき だけ ＋0.5）。0 より 下には しない
- かかり：出たとき 1 ／ 条件つきの 出たとき 0.75 ／ 攻撃するたび 1 ／ ブロックするたび 0.5 ／ 能力（マナ）0.75 ／ タップ（マナ なし）1.5 ／ エネルギー 0.75 ／ 戦技（毎ターン つかえる）1.5 ／ 死亡したとき 0.5 ／ 星座 0.75 ／ 魔技 1 ／ 宝具 NP＋50 0.45・＋40 0.5・＋36 0.55・＋30 0.6（オーバーチャージ ＋0.05）。出たときと 攻撃の 両方は ＋0.5
- 出来事：呪文の ぶん ＋0.5（あとで クリーチャー）を、出来事の コストと くらべる
- 連携スキル だけの エージェント（1戦 1回 くらい）は モデルの 外

### 1.5 あわせかた（いまの カードの まん中に あわせた）

1. かたち（たし・ひきの 大きさ）は ユーザーの 4つの じゅんばん・MTG の もとの カードの コスト・REQUIREMENTS 8.6 の「ランダムに なった コモンは −1」から きめた
2. もとの ねだんは、いまの カード 326まいで **いま − モデル の 中央値が 0 に ちかく なる** ように 0.5 ずつ うごかした：破壊 2.5 → **3**（追放 3.5）、ぜんたいは ＋0.5。ダメージは いちばん 多い かたち「1マナ・インスタント・ランダム 3点」（SR65・R47・SR144 など 7まい）が ちょうど に なる **1点 0.5**
3. けっか（いま − モデル の 中央値）：ぜんぶ ＋0.25（呪文 ＋0.5・からだ つき ＋0.15）。しゅるい べつ：呪文の 破壊・追放 0、ダメージ・マイナス ＋0.5、もどす・留置 0、格闘 0、ぜんたい ＋0.5、からだ つき −0.5〜＋0.5
4. コストは 整数、モデルは 0.5 きざみ。モデルが x.5 なら x も x＋1 も ずれ 0.5（しるし なし）。**ずれ 1 いじょうに しるし**

> 例：夜の さばき（K13）＝破壊 3 − ランダム 1 ＋ インスタント 0.5 ＝ **2.5** → いま 3（ずれ ＋0.5・OK）
> 例：やけつく 連発（R88）＝5点 2.5 − いちばん 大きい 0.5 ＋ インスタント 0.5 ＝ **2.5** → いま 5（ずれ ＋2.5・しるし）
> 例：はらぺこの 冥界犬（K19・2/2）＝からだ 1.5 ＋（破壊 3 − 0.5）× 出たとき 1 ＝ **4** → いま 4（ずれ 0）

アンコモンの「いちばん 大きい」は 8.6 で コストを かえなかった ので、モデルより ＋0.5 の ものが 多い（コストが 整数なので 1まいずつは 直せない。まとめての きもちは 4章）。

## 2. 直す カード（案）

- **しるし**：いまの コスト − モデル が 1 いじょう（モデルは 0.5 きざみ・コストは 整数 なので、モデルが x.5 なら x も x＋1 も ずれ 0.5 で しるし なし）。ずれの 数は「いま − モデル」（＋ は たかすぎ・− は 安すぎ）
- **A**＝コスト・数・じき などを かえる 案。**R**＝ねらいかたを REQUIREMENTS 8.6 の きまり どおり「じぶんで えらぶ（PICK_FREE）」に する 案（コストは そのまま）。どちらも「案の あと」の ずれを かっこに 書いた
- **ようすみ**＝しるしは ついたが、ちかい カードとの じゅんばんは さかさまで なく、MTG の もとの カードと おなじ コストで、レア・レジェンドの つよい からだ・命令・エージェントなど モデルの 外 寄りの もの。いまは かえない（各弾の 2つめの 表）
- X の 呪文は X＝3（X X X は X＝1、X＝2 の めやすの もの は X＝2）の ときの マナで くらべた
