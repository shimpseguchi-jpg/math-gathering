# デジタル 限定の カード（アルケミー）の 検討

MTG アリーナ（MTGA）の「アルケミー」に ある **デジタルでしか できない しくみ** を、この ゲームに 入れる かの 検討と、カードの 案。弾の 一覧は [`ROADMAP.md`](ROADMAP.md)、要件は [`REQUIREMENTS.md`](REQUIREMENTS.md)。

- 状態：**開発中**（2026-10-24 データ化。WEB版の 開発モードで えらぶと パックに 入る。うごきは `js/data/alchemy.js`、名前・コスト・P/T は この 表から `js/data/skel.js` に 自動で 入る。数値は バランス調整前。永久に・探す・創出・呪文書・強度・恩恵・二体掛りは `js/data/kit.js`。ゲームで かんたんに した ところは [`ROADMAP.md`](ROADMAP.md) 6章）
- アルケミーとは：MTGA の フォーマット。紙では できない しくみ（永久に・探す・創出・呪文書 など）を 持つ **デジタル 限定の カード** と、出した あとで 数字を かえる **再調整（さいちょうせい）** が ある。本の セットの あとに 30まいくらいの「アルケミー：（セット名）」が 出る

---

## 1. この ゲームに 合う わけ

| わけ | 中身 |
|---|---|
| コンピューターが 数を おぼえて くれる | 「この カードは ずっと ＋1/＋1」「強度 3 → 4 → 5」のような 記録は、紙だと たいへん だが、画面なら 数字が 出る。**数が かわって いく ようすが 見える** |
| くじ引きの 楽しさ | 「15まいの 本から 3まいが 出て 1まい 選ぶ」は ガチャの ような わくわく。お金は いらない |
| 算数の 条件で さがす | 「コストが **偶数** の カードを さがす」「パワー **4 いじょう**」「コスト **ちょうど 3**」— さがす 条件が そのまま 算数に なる |
| ローグライクと 合う | 冒険の あいだに カードが **育つ**（階を のぼるたびに 強くなる）。Slay the Spire の ように「この 冒険 だけの 自分の デッキ」が できる |
| もう やって いる こと | 第2弾で シミュレーションを 見て 数字を 直した（バウンスなど）。これは アルケミーの **再調整** と 同じ |

## 2. メカニズムの 一覧と おすすめ

日本語の 名前は MTGA 日本語版に あわせた（たしかめられなかった ものは（仮））。

| メカニズム | 英語 | MTGA での 中身 | この ゲームでは | 算数 | おすすめ |
|---|---|---|---|---|---|
| **永久（えいきゅう）に** | Perpetually | 場所が かわっても（手札・墓地・ライブラリー）変化が のこる | 1回の たたかいの あいだ ずっと。とくべつな カードは「**冒険の あいだ ずっと**」（下の 3章） | **たし算の つみかさね**（＋1 が 3回 で ＋3） | ◎ 入れる |
| **探（さが）す**（シーク） | Seek | ライブラリーから 条件に あう カードを **ランダムに** 1まい 手札へ | 条件を 数に する（偶数・奇数・3 いか・ちょうど 5・パワー 4 いじょう） | **偶数・奇数・大小比較・ぴったり** | ◎ 入れる |
| **創出（そうしゅつ）** | Conjure | ゲームの 外から カードを 作って 手札・ライブラリー・戦場へ | パックに 入らない「創出 だけの カード」も 作れる。たたかいが おわれば きえる | − | ◎ 入れる |
| **呪文書（じゅもんしょ）から ドラフト** | Spellbook / Draft | その カードの 本（15まいくらい）から 3まいが 出て、1まい 選んで 手札へ | 「たし算の 呪文書」「九九の 呪文書」など **算数の 本**。第5弾の **学習** も これ | 選ぶ・くらべる | ◎ 入れる |
| **強度（きょうど）** | Intensity | 数字を 持つ カード。条件で 1ずつ 上がる（同じ 名前の カード ぜんぶ 上がる ものも） | 「初期強度 3」から 4・5・6… | **たし算の くりかえし**（3・4・5…） | ◎ 入れる |
| **恩恵（おんけい）**（仮） | Boon | 「つぎに ◯◯ したとき」に 1回だけ おきる こうか | 画面の 上に 小さい アイコン。使ったら きえる | **先読み**（つぎの ターンの ために） | ○ 入れて よい |
| **二体掛（にたいがか）り** | Double team | 攻撃すると、同じ カードを 手札に 1まい 創出（1回だけ） | 1まいで 2体 | **2倍** | ○ 入れて よい |
| 専門化（せんもんか） | Specialize | 色の カードを 捨てて、5つの すがたの どれかに かわる | 1まいの ために 5まい 作る ことに なる。子どもには 少し むずかしい | − | △ あとで |
| 組み込む（仮） | Incorporate | カードの 文章に 能力を 永久に 足す | 文が 長く なる | − | △ あとで |
| 強奪（ごうだつ）（仮） | Heist | 相手の ライブラリーから 3まい 見て、1まいを 自分の ものに | 塔の 敵の カードは とくべつ（コスト 0・無色）なので 合わない。オンラインの ゴースト相手 なら できる | − | × 塔では 入れない |
| 再調整（さいちょうせい） | Rebalancing | 出した あとで カードの 数字を かえる（MTGA は 名前に「A-」） | シミュレーションで 強すぎ・弱すぎを 直す。ずかんに「調整 2」と 出す | − | ◎ もう やっている |

- そのほかの MTGA の デジタル しくみ（Covercast・Backbone・Prismatic・Unstoppable・Not the starting player）は、数が あまり 出ないので 入れない
- **たたかいの 中で 問題は 出さない**（REQUIREMENTS 5.1）は かわらない。どれも 勝つ ために 考えると 数が 出てくる しくみ

## 3. この ゲームでの きまり（案）

| ことがら | きまり |
|---|---|
| 永久に の はんい | ふつうは **その たたかいの あいだ**。たたかいが おわると もとに もどる |
| 冒険の あいだ ずっと（ローグライク版） | 一部の カードだけ「**冒険の あいだ ずっと**」。階を クリアするたびに 強く なる など。冒険の セーブに いっしょに のこす。冒険が おわれば もどる |
| 見せかた | MTGA と 同じく、永久に かわった 数字は **むらさき色**。強度は カードの 右上に バッジ |
| 創出した カード | たたかいが おわると きえる（デッキには のこらない）。ずかんでは「創出 だけ」の ページ |
| ランダム | 探す・呪文書の 3まいは、たたかいの シード（`seeded`）で きまる。シミュレーションも 同じ けっかに なる |
| オンライン | ゴーストの デッキは カードの ID だけ なので、永久の 変化（たたかいの 中だけ）は 問題に ならない。「冒険の あいだ ずっと」の 強さは ゴーストには のこさない（公平に） |
| 学年 | 呪文書の 中身を 学年で かえられる（1年は たし算の 本、2年は 九九の 本）。REQUIREMENTS 5.2 |

## 4. 呪文書（じゅもんしょ）の 例

呪文書は「15まいくらいの カードの 本」。ドラフトすると、本から ランダムに 3まいが 出て、1まい 選ぶ。中身は いまの カード（第1弾・第2弾）から えらんだ。

- 3まいは **デッキの 色で 唱えられる カード だけ**、しかも **ぜんぶ ちがう カード**（2026-10-24。色の 合わない カードを 引いても 使えないため）。合う カードが ない ときだけ 本の ぜんぶから
- 人が 遊ぶ ときは 3まいの せつめい（色つき）が 出て、自分で 1まい えらぶ。第5弾の 学習（レッスン）も 同じ

## 7. 作るときの メモ

| もの | すること |
|---|---|
| 永久に | カードの 実体（`card(def)` で 作る もの）に `perp: { p, t, cost, kw }` を 持たせ、`pt()`・コストの けいさん・キーワードで 足す。場所が かわっても `card` は 同じ ものを つかう（いまも 手札 → 戦場 → 墓地で 同じ オブジェクト） |
| 冒険の あいだ ずっと | 冒険の セーブ（`A`）に「カード番号 → 変化」を のこす。たたかいの はじめに `perp` に 入れる |
| 探す | `s.P.lib` から 条件（`(def) => boolean`）に あう ものを `s.rng` で 1まい 手札へ。ないときは 何も しない |
| 創出 | `api.card(BY_ID[id])` を 手札・ライブラリー・戦場へ。創出だけの カード（YT）は `BY_ID` に 入れ、パックの `POOL` には 入れない |
| 呪文書 | `SPELLBOOK = { tashizan: ['W12', …] }`。ドラフト ＝ ランダムに 3まい → `pickMany`（1まい）→ 創出 |
| 強度 | カードの 実体に `intensity`。「同じ 名前 すべて」は `s.P` の 全部の 場所（手札・ライブラリー・墓地・戦場・追放）を さがす |
| 恩恵 | `s.P.boons = [{ when: 'creatureCast', run }]`。おきたら けす。画面の 上に アイコン |
| 二体掛り | `onAttack` で 同じ `def` を 手札に 創出し、どちらの 実体にも `perp.noDoubleTeam` |
| 画面 | 永久の 変化は むらさき（`--perp`）、強度は バッジ、恩恵は 上の アイコン。ずかんに「デジタル」「創出だけ」の しるし |
| ふりがな | `node mathtcg/tools/kanji_drafts.mjs` |
