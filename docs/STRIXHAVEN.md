# ストリクスヘイヴンの 塔（魔法学院の 塔）

3つめの せかい（プレーン）。第5弾「大きな 数の 塔」（[`SET5.md`](SET5.md)）と いっしょに 出す（[`ROADMAP.md`](ROADMAP.md) 1.1）。要件は [`REQUIREMENTS.md`](REQUIREMENTS.md) 7章。

- 状態：**出て いる**（2026-10-29。第5弾と いっしょに 出した。うごきは `js/data/strixhaven.js`、冒険の しくみは `js/ui/app.js` と `js/engine/run.js` の `runStrix`）
- **6階だて**：1〜5階は **5つの 寮の しけん**（じゅんばんは ランダム。ぜんぶ まわる）、6階は **卒業試験**（オリークの エクタス）
- テーロス・ラヴニカとの ちがい（2026-10-29 きまり）：**入学式で 寮を えらぶ**・**ライフを ひきつぐ**・**休み時間**・**通知表**。テーロスと ラヴニカは「階ごとの てきの きまり」で あそぶ 塔、ストリクスヘイヴンは「6階を どう のりきるか、作戦を 立てる」塔

## 1. 冒険の ながれ

| じゅん | なに | くわしく |
|---|---|---|
| 1 | **入学式** | 5つの 寮から 1つ えらぶ。**デッキは その 寮の 2色**。入学いわいに 寮の **誓約魔道士**（アンコモン）と **寮の 命令**（レア）を もらう |
| 2 | パック 3つ | **ファウンデーションズ（第1弾）と 第5弾** の、**寮の 2色の カードだけ**（色の ない カードも 出ない） |
| 3 | 1〜5階 | 5つの 寮の しけん（2章）。かつと ライフは そのまま つぎの 階へ（3章） |
| 4 | 休み時間 | 階と 階の あいだ（5回）。**保健室・図書室・授業** から 1つ（4章） |
| 5 | 6階 | 卒業試験（2.6） |
| 6 | **通知表** | 6つの 教科の ★（5章）。のぼりきったら「そつぎょう おめでとう」 |

- 入学式の 画面は **入学の 手紙**（2026-10-29）：羊皮紙（ようひし）の 紙・封蝋（ふうろう）・明朝体の 字。さいしょは 学院の しらせ（封蝋は「学」）、寮を えらぶと 学長からの「入学 おめでとう」（封蝋は 寮の 色と 頭の 字）。ストリクスヘイヴンが ひらいた ときの しらせも 同じ 手紙（`js/ui/app.js` の `letter`、`css/style.css` の `.parchment`）
- コンティニューは 1回（ほかの 塔と 同じ）。まけた 階を **ライフ 20** で やりなおす（むずかしいは 22 より ふえないので 20）
- 統率者戦・むげんの とうは なし（入学式の 2色と あわない ため）。ドラフトは できる（色を えらぶ かわりに 寮の 2色）
- ひらく 条件：**第5弾が パックに 入る**（WEB版は せっていで 第5弾を えらぶ／GAS版は 先生が 第5弾を 出す）**＋ テーロスの 塔を「ふつう」で のぼりきる**（ラヴニカと 同じ）

## 2. 階（しけん）

どの 階も **学長の ライフを 0に する**。てきは ほかの 塔と 同じく マナを 使わず、毎ターン やまふだの 上を めくって 使う。自分の 寮の しけんも ある（先生は 手かげん しない）。

学長の ライフ（かんたん／ふつう／むずかしい）：シャイル 10/13/16・ウヴィルダ 11/14/18・リゼット 12/15/19・アウグスタ 11/14/18・キアン 10/13/16。てきが めくる まいすうは 1／1／1.25（むずかしいは 4ターンに 1回 2まい）。

| 寮 | 学長 | きまり | 算数 |
|---|---|---|---|
| シルバークイル | シャイル | てきの ターンの はじめに、カウンターの ない てきの クリーチャー ぜんぶに ＋1/＋1カウンターを 1こ | ＋1 ずつ |
| プリズマリ | ウヴィルダ | てきが めくった じゅもんは **2回 おきる**（コピー） | 2ばい |
| ウィザーブルーム | リゼット | リゼットの ライフが **10 より 少ない** とき、てきの ターンの はじめに 薬で ＋3（10 まで） | 10 と くらべる |
| ロアホールド | アウグスタ | てきの ターンの はじめに（2ターンに 1回）、てきの 墓地で **いちばん パワーの 大きい** クリーチャーが もどる | 大小くらべ |
| クアンドリクス | キアン | **2ターンに 1回**、てきの ターンの はじめに 0/0 の フラクタル（こうげき しない）が 出る。カウンターは **2・4・6・8**（2の だん。8の つぎは 2） | 2の だん |

### 2.6 6階 卒業試験：オリークの エクタス

- 卒業式を おそった ひみつ結社 オリークの かしら。5つの 寮の まほうを ぬすんで、**5教科を じゅんばんに** 出して くる
- てきの ターンの はじめに、こくご → さんすう → りか → しゃかい → ずこう の じゅんで 1つ（2章の きまりと 同じ。さんすうの フラクタルは カウンター 4、ずこうは その ターンの じゅもんが 2回）。つぎの 教科は 画面に 出る
- ライフ 16／22／28

## 3. ライフを ひきつぐ

- はじめの ライフは **かんたん 40・ふつう 30・むずかしい 22**（ほかの 塔は 20）
- 階を かつと、のこった ライフで つぎの 階へ。**はじめの ライフより ふえない**（絆魂などで ふえすぎない ように）
- もんしょうの ライフ（＋）は はじめの ライフに たす

## 4. 休み時間（階と 階の あいだ）

3つから 1つ えらぶ。

| えらぶ もの | こうか |
|---|---|
| **保健室** | ライフ ＋15／＋12／＋10（かんたん／ふつう／むずかしい。はじめの ライフ まで） |
| **図書室** | パックを 1つ あけて、デッキを くみなおせる（寮の 2色だけ） |
| **授業** | デッキの カードを 1しゅるい えらんで、冒険の あいだ **ずっと 強く** する。クリーチャーは ＋1/＋1、ほかは コスト −1（色の マナより 下には ならない）。同じ カードを なんども えらべる |

- ほかの 塔は 階ごとに パックが 1つ もらえる。ストリクスヘイヴンは **パックも 回復も 強化も「えらんだ ときだけ」**
- 授業で 強く した カードは、塔の 画面に「そだった カード」として 出る

## 5. 通知表

階ごとに ★を 3つまで。

| ★ | 条件 |
|---|---|
| ★ | かった（コンティニュー した 階は ★ なし） |
| ★ | ぴったりで 1回 いじょう たおした |
| ★ | その 階で へった ライフが 4 いか |

- 6教科（5つの 寮 ＋ 卒業試験）で ★ 18こ まんてん。15こ いじょう「たいへん よく できました」、10こ いじょう「よく できました」、それより 少ない「がんばりました」
- いちばん よかった ★の 数は ずかんに のこる

## 6. 数字（シミュレーション）

`PLANE=strixhaven node tools/sim.mjs runs` で たしかめる（`COLLEGE=quandrix` で 寮を きめる、`HEAL_AT`・`PACKS` で 休み時間の AI を かえる）。目標は ほかの 塔と 同じ（かんたん 75〜85%・ふつう 50〜70%・むずかしい 20〜30%）。

- AI の 休み時間：ライフが 18 いかなら 保健室、図書室は 2回まで、のこりは 授業（いちばん 強い クリーチャー）
- パックは ファウンデーションズ ＋ 第5弾 の 寮の 2色だけ（`STRIX.sets`）

けっか（2026-10-29・1000回ずつ。寮は ランダム）：

| むずかしさ | クリア | 寮ごと（シルバークイル・プリズマリ・ウィザーブルーム・ロアホールド・クアンドリクス） | 通知表（クリアした とき） |
|---|---|---|---|
| かんたん | **80%** | 87・67・72・92・78 | ★ 12.7 |
| ふつう | **68%** | 84・48・61・81・61 | ★ 12.9 |
| むずかしい | **28%** | 46・10・32・38・11 | ★ 13.3 |

調整で かえた こと：

- はじめは ライフ 30・上限 40・保健室 ＋12 で、かんたん 63%・ふつう 55%・むずかしい 55%。**学長の ライフを かえても ほとんど かわらなかった**（まける のは てきの こうげきで ライフが 0に なる とき）。むずかしさは「はじめの ライフ」と「てきが めくる まいすう」で つけた（むずかしいを 1.5まいに すると 8% と きびしすぎた → 1.25）
- クアンドリクス：フラクタルが まいターン 出ると かべで たたかいが 長く なり（勝率 58%・山札切れ 60%）、こうげき する フラクタルに すると 3% → **2ターンに 1回**（69%）
- エクタスの ライフ 20／26／32 → 16／22／28（クリア率は かわらず、ターンが みじかく なる）
- 入学いわいに 寮の 命令を 足した：ふつう プリズマリ 45 → 53%、ウィザーブルーム 54 → 65%、クアンドリクス 56 → 68%（ぜんぶ 上がる ので はじめの ライフを 35 → 30 に）

のこって いる こと：

- 寮ごとの 差（ふつうで プリズマリ 48% 〜 シルバークイル 84%）。青の 寮が ひくいのは AI が インスタント・X の 呪文を うまく 使えない せいも ある。人が あそんで みて から きめる
- ウィザーブルームの しけんは どの むずかしさでも 98〜100%（リゼットの くすりが あまり 出ない）。休けいの 階で よいか、人が あそんで みて から
- ストーリー 5章（ストリクスヘイヴン「まほうの 授業」）は できた（2026-10-29）：案内役は PW31 クイントリウス（ロアホールドの 学生）。5-1 魔技・5-2 学習・5-3 クアンドリクスの しけん。第5弾が パックに 入る ときだけ 出る（`js/ui/story.js`）。ごほうびの プレイマットは 5章「ストリクスヘイヴンの 黒板」、塔を のぼりきると「卒業の ランタン」
