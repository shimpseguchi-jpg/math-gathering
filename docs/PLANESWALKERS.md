# プレインズウォーカー

MTG の プレインズウォーカー を この ゲームで 使えるように する。**ちゅうせい**（忠誠）の 数を たし算・ひき算で 管理する カード。要件は [`REQUIREMENTS.md`](REQUIREMENTS.md) 3.6。

- 状態：**開発中**（2026-10-24。WEB版の 開発モードの せっていで「プレインズウォーカー」を えらぶと パックに 入る。うごきは `js/data/pw.js`、名前・コスト・ちゅうせいは この 表から `js/data/skel.js` に 自動で 入る）
- 5色に 1まいずつ。どれも レジェンド（4点）

## 1. きまり

| ことがら | きまり |
|---|---|
| 出る とき | カードに 書いた **ちゅうせい** を もって 出る（カードの 右下に ◆4 の ように 出る） |
| のうりょく | **1ターンに 1かい**、自分の メインの とき。「＋1」は ちゅうせいが 1 ふえ、「−3」は 3 へる。ちゅうせいが たりない −の のうりょくは 使えない。マナは いらない |
| 0 に なる | ちゅうせいが 0 に なると 墓地へ（−の のうりょくで 0 に しても、こうかは おきてから 墓地へ） |
| こうげき される | てきの クリーチャーが ブロックされなかった とき、**ちゅうせいを 0 に できる** プレインズウォーカーが あれば そちらを こうげきする（ちゅうせいの 大きい ものから）。できなければ プレイヤーを こうげき。ダメージの ぶん ちゅうせいが へる |
| 画面 | タップすると のうりょくの ボタンに「ちゅうせい 4 ＋ 1 ＝ 5」の ように **計算が 出る** |
| MTG と ちがう ところ | 自分の クリーチャーで てきの プレインズウォーカーを こうげきする ことは ない（てきは 持たない）。トランプルの てきは プレイヤーを こうげきする |

## 3. シミュレーション

見本デッキ 2つ（赤緑・青白）に プレインズウォーカーを 2まいずつ 入れて ゼナゴス・エレボスと 600戦：かち 85.2% → 86.7%（少し つよい くらい）。見本デッキ 6つ × 5つの 階 3000戦 でも 88.9% → 88.9%。AI は 1戦 4回 くらい のうりょくを 使う（＋と − を ちゅうせいを 見て えらぶ）。レジェンド（4点）なので デッキに 入る かずが 少なく、強すぎる ことは ない
