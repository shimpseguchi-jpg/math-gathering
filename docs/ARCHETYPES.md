# アーキタイプの 総ざらい（これから 作れそうな しくみ）

これから 作る 弾・塔・モードの ために、MTG と、MTG 以外の カードゲーム（デュエマ・デュエプレ・遊戯王・ポケカ・ほかの TCG・デジタルCCG・デッキ構築ローグライク・ボードゲーム・トランプ・算数の 教育ゲーム）から、**算数に つながる しくみ** を ひろく 集めた もの。弾ごとの くわしい 案は [`ROADMAP.md`](ROADMAP.md)、いま ある カードは [`CARDLIST.md`](CARDLIST.md)。

- 状態：**調べた だけ**（2026-10-29）。ここに ある ものは まだ 1つも 作って いない。作る ときは 弾の 案（`SET*.md`）に うつして、シミュレーション（[`SIMULATION.md`](SIMULATION.md)）で たしかめる
- 2024〜2026年の 新しい しくみは、公式ルールや 公式ニュースで たしかめた（2026年10月 時点）。たしかめきれなかった ものには「要確認」と 書いた。日本語版の ない ゲームは カタカナに した
- ほかの ゲームの **名前・キャラクター・カード名は 使わない**。使うのは しくみ（ルールの 形）だけ。名前は ゲームの 次元（せかい）に 合わせて つける（[`ROADMAP.md`](ROADMAP.md)「次元の きまり」）

## 0. 読みかた

- **合う度**：◎ ＝ すぐ 使える／○ ＝ 工夫すれば 使える／△ ＝ 算数との つながりが うすい・子どもに むずかしい
- **入れる 場所**：
  - **カード**：カード 1まいの 能力（キーワード）。弾に 入れる
  - **階**：塔の 1つの 階の きまり（てきの とくちょう）
  - **冒険**：塔・冒険の しくみ（お店・休み時間・道えらび など）
  - **モード**：新しい あそびかた
  - **構築**：デッキを 組む ときの きまり
- **方針との 関係**（[`REQUIREMENTS.md`](REQUIREMENTS.md)）：問題を 出すのでは なく、**ルールの 中で 自然に 計算が おきる** ものを えらぶ。とくに「ぴったり」「10の まとまり」「2倍・九九」「大小くらべ」に つながる ものを 高く した
- **てきは マナを 使わない**：塔の てきは 山札の 上を めくって たたかう。対人戦（ゴースト・オンライン）で しか 動かない ものは そう 書いた
- 賭けの 要素（スナップの キューブ・ブラックジャック・Balatro の お金 など）は、お金や「賭ける」と いう ことばを 使わず、点・星・パックで あらわす

### 7.1 ゲームを こえて 何度も 出て くる 12の 形

### 7.2 おすすめの じゅんばん

1. **① えらんで 足して ぴったり を、つぎの 弾の 目玉に**：ゲームの 方針「ぴったり」の ど真ん中で、いちばん 多くの ゲームに 出て きた。遊戯王（シンクロ）・MTG（証拠収集・搭乗）・デュエマ（合計パワー除去）が 同じ 形。1年生から わかる
2. **⑩ てきの 予告 と ⑨ 相性 を いまの 塔に 足す**：カードを 作らずに、テーロス・ラヴニカ・ストリクスヘイヴンの 塔 ぜんぶが 算数らしく なる。「つぎの ターン 3 × 2 ＝ 6点」「この てきは 赤に よわい（× 2）」
3. **④ 数の しきい値 と ⑤ コストを へらす を 弾の 小さな キーワードに**：作る 手間が 小さく、どの 次元にも 合う
4. **⑪ 2つめの 目標 を レイドと 新しい 塔の ボスに**：「封印 6つを ちょうど 0 に」「守備 5 を ちょうど 0 に」
5. **② そろえて かける**：第5弾（九九）の つづきに
6. **⑫ 冒険の 道と お店**：むげんの 塔を 作りかえる ときに まとめて（手間が 大きい）

### 7.5 気を つける こと

- **賭けの 表現**：スナップ・Balatro・ブラックジャック などの「賭ける」「お金を ふやす」は、点・星・パックに 言いかえる
- **新しさが 少ない もの**：ドン!!（ワンピース）・ポケポケの エネルギーゾーン・Star Wars: Unlimited の 資源・水の 技（MTG）は いまの マナや 召集と ほぼ 同じ
- **子どもに むずかしい もの**：チェーン・ペンデュラムの はし（遊戯王）・ルーン（Riftbound）・交互アクション（Star Wars: Unlimited）・リンクマーカー
- **強すぎに 注意**：ストーム・範例・2の X 乗
- **PvE で 動かない もの**：対人戦 だけの しくみ（贈呈・交互アクション・スナップの 撤退）は オンライン用に とって おく
- **名前**：公式の 和名と ちがう ものが ある。来世（公式は 死後・Afterlife）・讃美（公式は 賛美・Exalted）・学習（公式は 履修・Learn。2026-10-29 に わざと「学習」に した）。Amass は 動員、Mobilize は 応召で、まちがえやすい

## 8. 決めて ほしい こと

1. **つぎに 作る 形**：おすすめは ①「えらんで 足して ぴったり」を つぎの 弾の 目玉に（7.2）
2. **つぎの 次元**：ゼンディカー／ヘクスヘイヴン／シャドウムーア／エルドレイン／カラデシュ／アモンケット（レイド）／ブルームバロウ … どれから？（7.3）
3. **いまの 塔に 足すか**：てきの 予告（計略デッキ・かけ算の インテント）と タイプ相性（弱点）は、カードを 作らずに 今の 塔に 足せる
4. **学年スイッチ**：弱点を 1〜2年は ＋2、3年からは × 2 に する、HP を 10倍で 見せる など、学年で ルールを かえるか
5. **新しい モード**：3つの じんち・学級の 塔・オートバトル の どれかを 作るか（7.4）
6. **名前**：来世（第3弾）→ 死後、讃美（ストック）→ 賛美 と、公式の 名前へ そろえるか（子ども向けに わかりやすい ほうを のこすか）
