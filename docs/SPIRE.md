# 次元渡り（大人向けモード）

Slay the Spire 型のローグライク。いまのバトル（デュエマ式マナゾーン・クリーチャー・攻撃とブロック）をそのまま使い、分かれ道のマップ・お店・休憩所・レリック・ポーション・アセンションを足したモード。3つの次元（テーロス → ラヴニカ → ストリクスヘイヴン）を渡り、それぞれのボスをたおす。

- 状態：**v1 を作った**（2026-10-30）。WEB版（デバッグモード）のタイトルに「次元渡り」のタイルが出る。GAS 版では先生がデバッグモードをオンにした端末だけ（子どもには出ない）
- 表記：このモードの画面は **ふつうの大人の日本語**（ふりがな・わかち書きなし）。`tools/kanji.mjs` の対象外（`js/ui/spire.js`・`js/data/spire.js`・`js/ui/adult.js` は UI_FILES に入れない。ポーション・レリックの文は `textOver` に書き、`texts.js` には入れない）
- **バトル画面・カードも大人向けの表記**（2026-10-31）：次元渡りのあいだは `js/ui/adult.js` が画面に出た文字をその場で置きかえる（ふりがなを外す・わかち書きの空白を詰める・よく出るひらがなの言葉を漢字にする：てき → 敵、こうげき → 攻撃、やまふだ → 山札、ターン おわり → ターン終了 など）。バトル・ログ・カードの文は子ども向けのまま共通なので、言葉の表（`WORDS`）を足していく
- ファイル：データ `js/data/spire.js`、冒険のロジック（画面と AI シミュレーションで共通）`js/engine/spire.js`、画面 `js/ui/spire.js`、シミュレーション `node tools/sim.mjs spire`

## 1. ながれ

| じゅん | なに | くわしく |
|---|---|---|
| 1 | **統率者をえらぶ** | ランダムな伝説のクリーチャー 3枚から 1枚（「他の 3枚」で引き直せる）。**色は統率者の色**（多くは 1色）、**カードの弾は統率者の弾 ＋ ランダムな弾 2つ**（その色のカードが 12種いじょうある弾）。報酬とお店はこの 3つの弾の、統率者の色と無色のカードだけ（1つの旅で 60〜80種くらい） |
| 2 | **旅立ちの祝福** | 4つから 1つ（最大ライフ +8・レア 3枚から 1枚・カードを 2枚取り除く・金貨 +100・ランダムなレリック・カード 2枚を強化） |
| 3 | **第1幕 テーロス** | マップを下から上へ。最後はボス（死者の神エレボス） |
| 4 | **第2幕 ラヴニカ** | ボスはギルドパクトのジェイス |
| 5 | **第3幕 ストリクスヘイヴン** | ボスは卒業試験（オリークのエクタス）。たおせばクリア |

- **ライフは引きつぐ**（戦闘のあとは回復しない）。回復するのは：休憩所（30%）・ボスをたおして次の幕へ（全回復。アセンション 5 から 75%）・燃える血（勝つたび ＋5）・計算尺（ぴったりで ＋2）・癒しの薬（＋10）・神々の祠（＋15）
- **墓地をまぜてもライフは失わない**（ふつうの塔の 2・4・6… はない。デッキを薄くするほど強い StS の考え方）。かわりに **次元のゆらぎ**：15ターン目から、あなたのターンのはじめにライフ −1・−2・−3…（長い戦闘をおわらせる。予告にも出る）
- **デッキは持っているカードぜんぶ**（ふつうの冒険のキャパシティ 30点・20枚はない）。カードを足すほど引きたいカードが来にくくなるので、お店や祝福で取り除く
- **はじめのデッキ**（11枚）：統率者 ＋ 基本カード 4枚（色でわける）＋ コモン 5枚（クリーチャー 3枚以上）＋ アンコモン 1枚（コスト 4 まで）
- **統率の冠**（ボスのレリック）：統率者をデッキからぬいて統率領域に置く。統率者はいつでも唱えられ、唱えるたびにコスト ＋2（いまの統率者戦と同じ）。もつまで、ボスのレリックの 1つめにかならず出る
- 最大ライフ 50
- コンティニューはない。負けたらおわり

## 2. マップ

- 1幕は **9段 ＋ ボス**。横は 4列。下から 4本の道を引き、となりの列（−1・0・＋1）へ進む道をつなげる（StS と同じ作り方）
- 段ごとのきまり：1段目は戦闘、5段目は宝箱、9段目は休憩所。ほかは重みつきでランダム
  - 戦闘 45・？（イベント）22・エリート 16（6段目から）・休憩所 12（6段目から）・お店 7（3段目から）
  - 1本の道で、エリート・休憩所・お店は 2つ続けない
- 進めるのは、いまのマスから線でつながっている上の段のマスだけ

## 3. 敵

| 種類 | 中身 | 金貨 | カード報酬 |
|---|---|---|---|
| 戦闘 | このモード用の「ふつうの敵」（ライフを持つ本体 ＋ 山札。1幕 6種・ぜんぶで 18種） | 10〜20 | 3枚から 1枚（C 60%・U 37%・R 3%） |
| エリート | いまの塔の階（テーロスの 1〜4階・ラヴニカの ギルド・ストリクスヘイヴンの 寮） | 25〜35 | 3枚から 1枚（C 50%・U 40%・R 10%）＋ レリック |
| ボス | エレボス・ジェイス・エクタス | 95〜105 | レア 3枚から 1枚 ＋ ボスレリック 3つから 1つ |

- **予告**：すべての敵で、つぎにめくる山札のカードが見える（「つぎにめくる：ミノタウロス 3/2」）。StS のインテントのかわり
- ふつうの敵は、その幕のはじめの 2戦は「弱い敵」、あとは「強い敵」から出る
- **幕で強くなる**：第1幕はライフを持つ敵のライフ ×1.2、第2幕は敵クリーチャー ＋1/＋1・×1.7、第3幕は ＋2/＋2・×2.4。`ACTS` の `buff`・`lifeMul`（`bossBuff`・`bossDiff` でボスだけ変えられる）
- **エリート**の敵クリーチャーはいつも ＋1/＋1（`SPIRE.eliteBuff`。アセンション 3 でさらに ＋1）
- ふつうの敵の山札は、なくなると墓地をまぜてもどす（ずっと動く）
- ポーションは戦闘のあと 40% で出る（出なかったら次は ＋10%、出たら −10%）

## 4. マスの種類

| マス | 中身 |
|---|---|
| 戦闘・エリート・ボス | 3章 |
| ？ | イベント（6章）。ときどき戦闘（10%）・お店（3%）・宝箱（2%） |
| お店 | カード 5枚（C 50・U 75・R 150・L 200 金貨。1枚は半額）、レリック 3つ（C 150・U 250・R 300）、ポーション 3つ（50〜100）、カードを取り除く（75。使うたび ＋25） |
| 休憩所 | **休む**（最大ライフの 30% 回復）か **鍛える**（カード 1枚を強化） |
| 宝箱 | レリック 1つ |

- **強化**：クリーチャーは ＋1/＋1、ほかはコスト −1（色のマナより下にはならない）。1枚に 1回まで。名前のあとに「＋」（ストリクスヘイヴンの授業と同じ `grown`）

## 5. レリックとポーション

- **レリック**：その冒険のあいだずっと効く。C・U・R（宝箱・エリート・お店）と、ボス（ボスの報酬だけ）。29種（C 10・U 9・R 4・ボス 6。`js/data/spire.js` の `RELICS`）
  - バトルの中で効くものは、もんしょう・祝福と同じ値（`turnPing`・`turnBolster`・`turnTap`・`wither`・`startMana`・`exactLife`・`exactPing`・`handSize`・`mulligan`・`swap`・`hand`）と、新しいフック `hooks`（`start`・`turn`・`cast`・`exact`）で作る
  - 冒険で効くもの：最大ライフ・金貨・お店の値引き・休憩の回復・カード報酬の数・ポーションの枠
- **ポーション**：3枠。戦闘のはじめに手札に入る、コスト 0 のインスタント（`potion: true`）。手札の枚数に数えない・マナゾーンに置けない・使うと追放（墓地にもどらない）。使わなかったものは次の戦闘へ持ちこす

## 7. アセンション（むずかしさ）

クリアすると次の段がひらく（0〜10）。それより下のきまりもぜんぶ入る。

| 段 | きまり |
|---|---|
| 1 | エリートが出やすい |
| 2 | ふつうの敵のライフ ＋20% |
| 3 | エリートの敵クリーチャー さらに ＋1/＋1 |
| 4 | ボスの難しさが「むずかしい」 |
| 5 | ボスのあとの回復が 75% |
| 6 | はじめのライフが最大の 90% |
| 7 | ふつうの敵の山札を 1.25 枚ずつめくる |
| 8 | エリートの難しさが「むずかしい」 |
| 9 | 金貨 −25% |
| 10 | はじめのデッキに呪い「後悔」（使えない・マナにもできない） |

## 8. エンジンに足したもの

- `game.js`：`emblem.hooks`（`start`・`turn`・`exact`）、手札の補充でポーションを数えない、`emblem.freeShuffle`（墓地をまぜてもライフを失わない）、`emblem.stall`（次元のゆらぎ）
- `ai.js`：`castCard` でポーションは追放、`cast` フック、AI はポーションをマナにしない
- `battle.js`：ポーションをマナゾーンに置けない。戦闘のおわりに残ったポーション（`potions`）を返す
- 敵の予告：`js/engine/spire.js` の `withPeek` が階の `intent` に「つぎにめくる」を足す

## 9. シミュレーション

`node tools/sim.mjs spire`（`N`・`ASC`）。AI は：色はランダム、報酬は `cardValue` が高いもの（デッキが 22枚を越えたら取らないこともある）、休憩はライフ 60% 未満なら休む、お店は取り除き → カード、道はランダム。

目標（v1）：アセンション 0 で AI のクリア率 20〜30%（人は予告を見られるので、もっと勝てるはず）。結果は 10章。
