# 第5弾 カード案「大（おお）きな 数（かず）の 塔（とう）」（84種 ＋ レッスン 10種）

マスマティック・ザ・ギャザリングの第5弾（拡張）の案。弾の 一覧は [`ROADMAP.md`](ROADMAP.md)、第4弾は [`SET4.md`](SET4.md)、デジタル 限定の しくみは [`ALCHEMY.md`](ALCHEMY.md)、要件は [`REQUIREMENTS.md`](REQUIREMENTS.md)。

- 状態：**開発中**（2026-10-24 データ化。WEB版の 開発モードで えらぶと パックに 入る。うごきは `js/data/set5.js`、名前・コスト・P/T は この 表から `js/data/skel.js` に 自動で 入る。数値は バランス調整前。ゲームで かんたんに した ところは [`ROADMAP.md`](ROADMAP.md) 6章）
- 5色（第3弾で 黒が 入った あと）として 書いて いる
- 書き方は 第1弾〜第4弾と 同じ。元のカードは 実在の MTG カード（英語名）。オリジナルの ものは そう 書く

## 8. 作るときの メモ

| もの | すること |
|---|---|

| フラクタル | 0/0 の トークンに X個の カウンター（第1弾の X クリーチャーと 同じ） |

| ヴェロマカス | ライブラリーの 上 7まいを 見せて、ただで 唱える シート |

| スタジアム | 点カウンター 10 で かち（第2弾 フェリダーの 君主と 同じ `s.over = 'win'`） |
