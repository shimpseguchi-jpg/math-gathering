- **学習** は 紙の MTG では「サイドボードの レッスン（Lesson）」だが、この ゲームは **デジタル なので「学習の 本」から ランダムに 1まい**（[`ALCHEMY.md`](ALCHEMY.md) の 創出と 同じ。学習で 手に 入れた カードは 創出した カードと 同じ あつかい）
- はじめ（2026-10-28 まで）は「10まいから 3まい 出して 1まい えらぶ」（呪文書の ドラフトと 同じ）だった。2026-10-29 に **本（ランダムに 1まい）か 次の ページ（捨てて 引く）を えらぶ** に かえた。えらぶ のは「どちらに するか」だけ なので、すぐ 決まる。本は えらべない かわりに、デッキの 色で 唱えられる ものだけ 出す
- ことばは **「学習」で そろえる**（2026-10-28）：レッスンは **学習呪文（がくしゅうじゅもん）** と よび、タイプは「ソーサリー — 学習」。「学習する」で 学習呪文を さがす、と すぐ わかる ように
- X を 2回・3回 はらう カード（コスト「X X」「X X X」）が ふえる。**X × 3 ＋ 1 マナ** を 子どもが 計算する

ストリクスヘイヴンの 塔の パックは **第1弾（ファウンデーションズ）＋ 第5弾** の、寮の 2色の カードだけ（[`STRIXHAVEN.md`](STRIXHAVEN.md)）。第1弾には **黒が ない** ので、黒の 寮（シルバークイル 白黒・ウィザーブルーム 黒緑）の パックは 66種、ほかの 3つの 寮は 94種 だった。それに 黒は 出て いる 弾（第1弾・第2弾・第5弾）の 中で いちばん 少ない 色。だから **黒を 28種**（C 12・U 9・R 5・L 2）、ほかの 4色を 4種ずつ（C 2・U 1・R 1）、寮の 2色を 2種ずつ（U・R）、友好色の 2色を 1種ずつ（U）、無色を 1種 足した。これで 塔の パックは シルバークイル・ウィザーブルームが **100種**、プリズマリ・ロアホールド・クアンドリクスが **104種** に なる（色の ない カードは 塔の パックに 出ない）。
