## 共通のきまり

### 書き方

- **元のカード**：実在の MTG カードをモチーフにする（決定）。英語名で書く。数値・テキストは本作のルール（DM のマナ・ライフ20・1対1ブロック）に合わせて作り直している
- **名前**：こども向けのオリジナルの名前（決定）。漢字には読みを（）で書く。ゲーム内ではルビになる（ひらがな／漢字（ふりがな）／漢字 の3モード）
- **キーワード・カードタイプ・用語**：MTG のまま（決定）。読みは REQUIREMENTS 3.2・3.3
- **ID**：色の頭文字＋番号（W＝白、U＝青、G＝緑、R＝赤、C＝無色、B＝きほんカード、2文字は2色）
- **コスト**：「4 W」＝ 合計4マナ、うち白を最低1つ（DM の文明条件）。「4 WU」＝ 合計4マナ、白か青を最低1つ。「X R」＝ X ＋ 1 マナ、うち赤を最低1つ
- **レアリティ**：C＝コモン（1点）、U＝アンコモン（2点）、R＝レア（3点）、L＝レジェンド（4点）

### 敵（チャレンジ・デッキ）とのきまり

- テキストの「敵」は、相手（ハイドラ・大群・神・エレボスなど）のこと。「クリーチャー1体か敵を対象とする」のダメージは、敵本体にも与えられる
- 敵にダメージを与えたときは、各階のルールに従う（ハイドラは頭に、大群はライブラリーを削る、など。REQUIREMENTS 7章）
- 敵のカードを手札にもどす効果は、かわりに敵のライブラリーの一番上に置く（敵には手札がないため。つぎのターンにまためくられて出てくる）。トークンは消える。オンラインバトルでは、あいての手札にもどる（2026-10 変更）
- 敵にカードを引かせる・捨てさせる効果は何もしない
- 打ち消し呪文は、敵が公開して唱えた呪文を打ち消せる

### 数を 意識する 能力（2026-10 追加）

算数は問題として出さず、**勝つために 考えると 自然に 計算する** 能力を各アーキタイプに入れた（REQUIREMENTS 5章）。

| 能力 | MTG の原作 | 内容 | 意識する数 | カード |
|---|---|---|---|---|
| 圧倒（あっとう） | Formidable | 自分のクリーチャーのパワーの合計が 8 以上なら | たし算・10のまとまり | G03・G11・G16 |
| 激励（げきれい） | Strive | 対象を好きな数だけ。2つめから1つにつき N マナ多くかかる | たし算・かけ算 | W12・W15・U03 |
| 鼓舞（こぶ） N | Bolster | タフネスがいちばん小さい自分のクリーチャーに ＋1/＋1カウンター N個 | 大小比較 | W05・W14 |
| 集団戦術（しゅうだんせんじゅつ） | Pack tactics | 攻撃しているクリーチャーのパワーの合計が 6 以上なら | たし算 | R03・R05 |
| 教導（きょうどう） | Mentor | 攻撃したとき、パワーが小さい攻撃クリーチャー1体に ＋1/＋1カウンター | 大小比較 | R02・R07 |
| 訓練（くんれん） | Training | パワーが大きい なかまと攻撃すると ＋1/＋1カウンター | 大小比較 | G10 |
| キッカー | Kicker | マナを多く払うと強くなる | マナの のこり | R04 |
| 増呪（ぞうじゅ） | Escalate | モードを好きな数だけ。2つめから1つにつき N マナ多くかかる | たし算・かけ算 | U13・RW01 |
| 待機（たいき） N | Suspend | 少しのマナで待機。時間カウンターが N ターンでなくなると ただで唱える | ひき算・先読み | R11・U19 |
| Lvアップ | Level up | マナを払うとレベルが1あがる。レベルで強さが変わる | くりかえしのたし算 | U21・G25 |
| **ぴったり**（オリジナル） | − | 敵のクリーチャーを、タフネスと **ちょうど同じ** ダメージで倒したとき（あまり 0）。何体かの合計でもよい | たし算・ひき算・分解 | R10・W13・G08・R18 |

- **ぴったり** は MTG にない本作だけの能力。ゴーレム工場の鍵（ちょうど同じ数で壊れる）と同じ考え方。カードに書いていなくても、ぴったりで倒すと画面で「ぴったり！」と出て、冒険の きろく に回数が残る
- 英雄譚（えいゆうたん）は、文章が長くなり低学年には読みにくいので **第2弾の候補**（決定）
