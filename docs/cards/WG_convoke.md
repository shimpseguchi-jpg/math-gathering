マスマティック・ザ・ギャザリングのカードリスト。共通のきまりは [`README.md`](README.md)、要件は [`../REQUIREMENTS.md`](../REQUIREMENTS.md)。

- 状態：**第1案**（数値はバランス調整前。シミュレーションで直す）
- 白と緑は、ほかのアーキタイプ（青白・赤白・緑赤・青緑）とも共有する。ここには **白緑で使うカード** を書く

## 1. 召集（しょうしゅう）のルール

MTG の召集を、DM のマナシステムに合わせる。

| ルール | 内容 |
|---|---|
| 支払い | 召集を持つカードは、コストを払うとき、マナゾーンのカードをタップするかわりに、**自分のアンタップ状態のクリーチャーをタップ** して1つぶん払える |
| 色の条件 | 「そのカードの色のマナを最低1つ」は、**同じ色のクリーチャーをタップ** しても満たせる（白のクリーチャーで白の条件、緑のクリーチャーで緑の条件） |
| 出たばかり | 出たばかりのクリーチャーもタップして払える（MTG と同じ） |
| トークン | トークンもクリーチャーなので払える |
| 2色のクリーチャー | 白と緑の両方の条件に使える |

### 1.1 遊びの中の算数（問題は出さない）

画面は式を出さない。勝つために考えると、自然に たし算 をする。

- **召集**：「森の大ワームは コスト7。マナは 4。なかまを 何体 タップすれば 出せる？」（4 ＋ □ ＝ 7）
- **圧倒（あっとう）**：「パワー 3 と 2 と 2 と 1 で 8。圧倒が 起きる！」（いくつかの数を たして 8 をつくる。10のまとまり・繰り上がりの たし算）
- 召集で なかまを タップすると、そのターンは 攻撃に 使えない。「出すか、攻撃するか」も 数で くらべて きめる
