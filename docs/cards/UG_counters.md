# カードリスト：青緑「＋1/＋1カウンター＋マナブースト」

マスマティック・ザ・ギャザリングのカードリスト。共通のきまりは [`README.md`](README.md)。

- 状態：**第1案**（数値はバランス調整前）
- これで青・緑ともに26枠すべて埋まる
- 青緑の算数カードは、ストリクスヘイヴンの数学の学寮 **クアンドリクス**（青緑）がモチーフ

---

## 1. アーキタイプの遊び方

- **マナブースト**：ライブラリーのカードをマナゾーンに置いて、DM の緑のようにマナを早く増やす
- **＋1/＋1カウンター** をクリーチャーに置いて育てる。**進化（しんか）**・**増殖（ぞうしょく）** でカウンターがどんどん増える
- 最後は、増えたマナで大きい呪文、増えたカウンターで大きいクリーチャー

### 1.1 算数：大きな数・くりかえしのたし算・倍

```
カウンター 3個 → 増殖 → 4個 → 増殖 → 5個     （1ずつふえる）
カウンター 3個 → 原初のハイドラ → 6個 → 12個   （2倍ずつふえる）
```

- **1年**：1ずつ数える（増殖）、大小比較（進化：出てきたクリーチャーのほうが大きい？）
- **2年から**：くりかえしのたし算・九九
- **4年から**：大きな数（ハイドラのカウンターが 24 → 48 → 96）
- **5年**：偶数・奇数（クルフィックス：マナ2枚につき1個 → あまりはいくつ？）
- けいさんボーナス（正解）：カウンターの数を予想して当てると、カウンター ＋1【提案・調整可】
