# カードリスト：青緑「＋1/＋1カウンター＋マナブースト」

マスマティック・ザ・ギャザリングのカードリスト。共通のきまりは [`README.md`](README.md)。

- 状態：**第1案**（数値はバランス調整前）
- これで青・緑ともに26枠すべて埋まる
- 青緑の算数カードは、ストリクスヘイヴンの数学の学寮 **クアンドリクス**（青緑）がモチーフ

---

## 1. アーキタイプの遊び方

- **マナブースト**：ライブラリーのカードをマナゾーンに置いて、DM の緑のようにマナを早く増やす
- **＋1/＋1カウンター** をクリーチャーに置いて育てる。**進化（しんか）**・**増殖（ぞうしょく）** でカウンターがどんどん増える
- 最後は、増えたマナで大きい呪文、増えたカウンターで大きいクリーチャー

### 1.1 遊びの中の算数：大きな数・くりかえしのたし算・倍（問題は出さない）

- **増殖**：カウンター 3個 → 4個 → 5個（1ずつ ふえる）。Lvアップの レベルも 増殖で ふえる
- **原初のハイドラ**：3個 → 6個 → 12個（2倍ずつ。大きな数）
- **Lvアップ**：「空見の弟子は レベル 3 で 4/2。いま レベル 1。あと 何回？ マナは 2 × 2 ＝ 4」（くりかえしの たし算・かけ算）
- **待機（たいき）**：「未来のひらめきは いま 3マナ、待機なら 1マナで 2ターン あと」
- **クルフィックス**：マナ 2枚につき カウンター 1個（7枚なら 3個で 1 あまる。偶数・奇数）
- **進化**：「出てきた クリーチャーの ほうが 大きい？」（大小比較）
