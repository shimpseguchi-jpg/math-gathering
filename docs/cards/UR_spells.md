# カードリスト：赤青「X呪文（エックスじゅもん）＋果敢（かかん）」

マスマティック・ザ・ギャザリングのカードリスト。共通のきまりは [`README.md`](README.md)。

- 状態：**第1案**（数値はバランス調整前）
- 青は青白・青緑とも、赤は赤白・緑赤とも共有する

---

## 1. アーキタイプの遊び方

- インスタント・ソーサリーを **たくさん唱えて**、果敢（かかん）や「呪文を唱えるたび」のクリーチャーを強くする
- **X呪文**：コストの X を自分で決めて払う。X が大きいほど強い
- 青のカードを引く呪文で手札を切らさず、赤のダメージ呪文でとどめ

### 1.1 X呪文のルール

| ルール | 内容 |
|---|---|
| コスト | 「X R」は、X ＋ 1 マナ（うち赤を最低1つ）。X は0以上なら好きに決めてよい |
| マナゾーン | DM のマナと同じく、X のぶんはどの色のカードをタップしてもよい |
| 召集など | X にも召集などの支払い方は使える（ほかのアーキタイプのカードと組んだとき） |

### 1.2 遊びの中の算数：□を使った式・マナの のこり（問題は出さない）

- **X を 自分で きめる**：X を −／＋ で えらぶ。「タフネス 3 の 敵に ぴったり 3点。マナは X ＋ 1 ＝ 4 つかう」（□を使った式）。火炎は ぴったりで 倒すと カードを 1枚 引ける
- **キッカー・増呪（ぞうじゅ）**：「マナ 4。なぞめいた命令を 2つ えらぶと 3マナ。のこり 1 で 選択も 唱えられる」（マナの のこりを 考える）
- **待機（たいき）**：「裂け目の稲妻は いま 3マナ、待機なら 1マナで つぎの ターン」（ひき算・時間の 先読み）
- **果敢**：「呪文を 3回 唱えたら パワーは 1 ＋ 3」
