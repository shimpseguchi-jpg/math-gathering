# カードリスト：第2弾「英雄譚（えいゆうたん）の 時代（じだい）」（62種）

マスマティック・ザ・ギャザリングの第2弾のカードリスト。コンセプト・新しい能力・アーキタイプは [`../SET2.md`](../SET2.md)、共通のきまりは [`README.md`](README.md)。

- 状態：**データ化ずみ**（`js/data/cards.js` の 第2弾。パックは 第1弾と まぜて 出る）。数値は シミュレーションで 直していく
- 英雄譚（えいゆうたん）の 章は、出たときと、あなたのターンのはじめ（**手札の補充の前**）に 1つずつ 進む
- 消失（しょうしつ）の 時間カウンターは、あなたのターンのはじめに 1個（こ）へる。0になったら 墓地（ぼち）へ
- 脱出（だっしゅつ）で 追放する 墓地の カードは、古い ものから 自動で えらばれる
