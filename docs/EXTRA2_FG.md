## 2. 新しい しくみ

### 2.1 しくみの 表

| しくみ | 説明（長おしで 出す 文の 案） | 算数 |
|---|---|---|
| **オーバーチャージ** | 宝具（ほうぐ）を つかう とき、NP を **100・200・300** の どれだけ つかうか えらべる。**200 つかうと、カードの 〔 〕の 中の 数が 2倍**、**300 つかうと 3倍** に なる。オーバーチャージの サーヴァントの 宝具は **1ターンに 1回** だけ。 | **100 の まとまり**（NP 260 は 100 が 2つと 60 → 2倍。260 − 200 ＝ 60）・**かけ算**（〔3〕点 × 2 ＝ 6点、〔2〕体 × 3 ＝ 6体） |
| 〔 〕の 数 | オーバーチャージの カードで、2倍・3倍に なる 数。ダメージ・ライフ・カウンター・トークン・「〔2〕 いか」の 数・NP など。〔 〕の ない 数は かわらない。 | 〔2〕 いか → 4 いか → 6 いか |
| つかった NP 100 に つき | クリプター（マスター）の 能力。NP を 200 つかったら 2回、300 なら 3回 おきる。 | 300 は 100 が 3つ → 3回 |
| **クラス相性（あいしょう）** | サーヴァントには クラスが ある。**相性の よい クラスの 相手に あたえる ダメージは 2倍**。<br>セイバー → ランサー → アーチャー → セイバー<br>ライダー → キャスター → アサシン → ライダー<br>ルーラー → ムーンキャンサー → アヴェンジャー → ルーラー<br>**バーサーカー** は、クラスの ある 相手（シールダー いがい）に あたえる ダメージも、うける ダメージも 2倍。クラスの ない 相手とは いつも 1倍。 | **2倍**（3 × 2 ＝ 6）。オーバーチャージと かさなると 〔2〕 × 2（OC）× 2（相性）＝ 8。**3すくみ**（どれが どれに つよいか 矢印を たどる） |
| 対（たい）〇〇 | カードに 書いた クラスの 相手に あたえる ダメージが 2倍（謎のヒロインX は セイバー、織田信長は ライダー）。 | 2 × 2 ＝ 4 |
| 塔の 階の クラス（案） | 塔の 階には クラスが ある（「この 階の てきは ライダー」）。その 階の てきの クリーチャーは みんな その クラス。サーヴァントで ない あなたの クリーチャーには 関係ない。 | どの サーヴァントを つれて いくか きめる（ライダーの 階には アサシン） |

- **どちらも 問題を 出さない**：オーバーチャージは「NP が いくつ あるか → 100 が いくつ とれるか → 〔 〕の 数 × いくつ」を じぶんで きめて 計算する。クラス相性は 攻撃・ブロックを きめる ときに「この 相手なら 2倍」と 考える。ログと ボタンに 式を 出す（`ほうぐ ×2（NP 260 − 200 ＝ 60）`、`クラス相性：3 × 2 ＝ 6点`）
- オーバーチャージを **1ターンに 1回** に する わけ：しないと「100 の 宝具を 2回」と「200 の 宝具 1回」が 同じに なり、かけ算を しなくても すむ。1回に すると「いま 2倍で つかうか、100 を のこして つぎの ターンにも つかうか」の えらびに なる（第1弾の サーヴァントは いまの まま 何回でも。5章 #1）
- NP 200・300 に とどく 道：令呪（＋100）・オベロン（＋100）・スカディ（毎ターン ＋50）・アルトリア・キャスター／光のコヤンスカヤ／ククルカン（出たとき ＋50）・虚数魔術（＋60）・カレイドスコープ（＋80）・アーツチェイン・始皇帝の 宝具 など。モルガンの 宝具は「つぎの オーバーチャージを 1つ 上げる」（NP 100 で 2倍）

### 2.2 実装メモ

エンジンの 変更は **3か所**（`set10.js` の 宝具・`game.js` の `damage`・`battle.js` の ボタンの 文字）と、データ（塔の 階の クラス・トークン・もんしょう）。

#### (1) オーバーチャージ（`js/data/set10.js`）

いまは `hogu` が 1つだけ（`npUse: true`・NP − 100）で、`fireNP(s, E, p, t)` が NP を 100 へらして `npFx(s, E, p, t)` を よぶ。これを **「何倍か（k）」を もつ** ように する。第1弾の `npFx` は 5つめの 引数を 見ないので、そのまま うごく。

```js
// 〔 〕の 数：オーバーチャージ（k）と 黒の聖杯（plus）。オーバーチャージの カードは npFx の 中で oc(p, 3) の ように つかう
export const oc = (p, n) => (n + (p.grailPlus || 0)) * (p.ocK || 1);

export function fireNP(s, E, p, t, k = 1) {
  const was = p.np, use = 100 * k;
  p.np -= use;
  let lv = k;
  if (p.def.oc) {
    const up = s[p.side].flags.ocUp || 0;                       // モルガン（FG164）：つぎの オーバーチャージを 1つ 上げる
    if (up) { lv = Math.min(3, k + up); s[p.side].flags.ocUp = 0; }
    p.flags.turn.hogu = true;                                    // オーバーチャージの 宝具は 1ターンに 1回
    p.grailPlus = [...s.P.bf, ...s.E.bf].filter((q) => q.attached === p.uid && q.def.grail).length; // 黒の聖杯（FG166）
  }
  p.ocK = lv;
  E.L(s, `ほうぐ！ ${p.def.name}（NP ${was} − ${use} ＝ ${p.np}）${lv > 1 ? `オーバーチャージ ${lv}倍` : ''}`);
  s.hoguSrc = p;                                                 // クラス相性で 宝具の ダメージの 出どころを 知る ため
  try { p.def.npFx(s, E, p, t, lv); } finally { s.hoguSrc = null; }
  for (const q of [...s[p.side].bf]) q.def.onHogu?.(s, q, p, E, k); // クリプター：つかった NP 100 に つき（k 回）
  E.sba(s);
}

// 宝具の ボタン：オーバーチャージの サーヴァントは ×1・×2・×3 の 3つ（たりない ものは 出さないか 灰色）
const hoguK = (k) => ({
  cost: 0, npUse: 100 * k, when: [1, 2],
  label: k > 1 ? `ほうぐ ×${k}（NP − ${100 * k}）` : 'ほうぐ（NP − 100）',
  can: (s, p) => (p.np || 0) >= 100 * k && !(p.def.oc && p.flags.turn.hogu),
  cantWhy: k > 1 ? `NP が ${100 * k} に たりない か、この ターンは もう つかった` : 'NP が 100 に たりない か、この ターンは もう つかった',
  play: (s, p, E) => ((p.np || 0) >= 100 * k ? { score: 8 + 4 * (k - 1), run: () => fireNP(s, E, p, undefined, k) } : null),
});
const withTgt = (a, x) => (x.npTgt ? { ...a, tgt: [x.npTgt], apply: (s, E, [[t]], _x, p) => fireNP(s, E, p, t, a.npUse === true ? 1 : a.npUse / 100) } : a);
const np = (npGain, npFx, x = {}) => ({ np: npGain, npFx, ...x,
  acts: [...(x.oc ? [1, 2, 3].map((k) => withTgt(hoguK(k), x)) : [withTgt(hogu, x)]), ...(x.acts || [])],
  onAttack: (s, p, E, atk, a) => { x.onAttack?.(s, p, E, atk, a); addNP(s, E, p, npGain); } });
```

- AI：点が 8・12・16 なので、つかえる いちばん 大きい 倍で うつ（いまの「たまったら すぐ」の まま）。てきがわの サーヴァント（`addNP` の `while`）は `k = Math.min(3, Math.floor(p.np / 100))` で 1回
- `npNote`：オーバーチャージの サーヴァントには「NP 200 で 〔 〕が 2倍、300 で 3倍（1ターンに 1回）」を 足す
- カードの 書き方の れい：`FG145: np(50, (s, E, p) => E.hitEnemy(s, oc(p, 2), null), { oc: true })`（巴御前。〔2〕点）
- 単体を えらぶ 宝具（`npTgt`）は ×1・×2・×3 の どれでも 人が えらぶ（`withTgt`）。「〔1〕体」の ように 何体も えらぶ ものは 自動（いちばん たおしやすい てきから じゅんに）で よい

#### (3) クラス相性（`js/engine/game.js` の `damage`）

```js
// クラス相性：矢印の さきの クラスに 2倍
const BEATS = { セイバー: 'ランサー', ランサー: 'アーチャー', アーチャー: 'セイバー', ライダー: 'キャスター', キャスター: 'アサシン', アサシン: 'ライダー', ルーラー: 'ムーンキャンサー', ムーンキャンサー: 'アヴェンジャー', アヴェンジャー: 'ルーラー' };
const CLASSES = new Set([...Object.keys(BEATS), 'バーサーカー', 'シールダー', 'アルターエゴ', 'フォーリナー', 'プリテンダー']);
export function classOf(s, p) {
  if (!p || p === 'face' || typeof p !== 'object' || !isCreature(p)) return null;
  if (p.flags?.turn?.cls) return p.flags.turn.cls;                                  // クラスチェンジ（FG118）
  if ((p.def.sub || []).includes('servant')) return p.def.sub.find((t) => CLASSES.has(t)) || null;
  return p.side === 'E' ? s.floor.cls || null : null;                               // 塔の 階の クラス（案。ない 階は null）
}
export function clsMult(s, src, t) {
  const a = classOf(s, src), b = classOf(s, t);
  let m = 1;
  if (a && b) {
    if (BEATS[a] === b) m = 2;
    else if (a === 'バーサーカー' && b !== 'シールダー') m = 2;
    else if (b === 'バーサーカー' && a !== 'シールダー') m = 2;
  }
  if (b && src?.def?.vsCls?.[b]) m *= src.def.vsCls[b];                            // 対セイバー（FG114）・対ライダー（FG136）
  return m;
}
```

`damage()` の `n = boostDmg(...)` の すぐ あとに 1つ 足す（クリーチャーへの ダメージだけ。本体には かからない）：

```js
if (isCreature(p)) { const m = clsMult(s, src || s.hoguSrc, p); if (m > 1) { L(s, `クラス相性：${n} × ${m} ＝ ${n * m}点`); n *= m; } }
```

- `api` に `classOf`・`clsMult` を 足す（カードの うごきから つかう）
- **AI の よそう**（`blockFacts`・`burnTarget`）にも `clsMult` を かける。かけないと「2倍で たおれる」を 見おとす（はじめは なしでも うごく）
- 画面：攻撃する 相手・ブロックの 相手を えらぶ シートで、2倍に なる 相手に「（相性 ×2）」と 出す
