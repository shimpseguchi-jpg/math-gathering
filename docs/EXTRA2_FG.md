## 2. 新しい しくみ

### 2.1 しくみの 表

| しくみ | 説明（長おしで 出す 文の 案） | 算数 |
|---|---|---|
| **オーバーチャージ** | 宝具（ほうぐ）を つかう とき、NP を **100・200・300** の どれだけ つかうか えらべる。**200 つかうと、カードの 〔 〕の 中の 数が 2倍**、**300 つかうと 3倍** に なる。オーバーチャージの サーヴァントの 宝具は **1ターンに 1回** だけ。 | **100 の まとまり**（NP 260 は 100 が 2つと 60 → 2倍。260 − 200 ＝ 60）・**かけ算**（〔3〕点 × 2 ＝ 6点、〔2〕体 × 3 ＝ 6体） |
| 〔 〕の 数 | オーバーチャージの カードで、2倍・3倍に なる 数。ダメージ・ライフ・カウンター・トークン・「〔2〕 いか」の 数・NP など。〔 〕の ない 数は かわらない。 | 〔2〕 いか → 4 いか → 6 いか |
| つかった NP 100 に つき | クリプター（マスター）の 能力。NP を 200 つかったら 2回、300 なら 3回 おきる。 | 300 は 100 が 3つ → 3回 |

- **問題は 出さない**：オーバーチャージは「NP が いくつ あるか → 100 が いくつ とれるか → 〔 〕の 数 × いくつ」を じぶんで きめて 計算する。ボタンと ログに 式を 出す（ボタン `ほうぐ ×2（NP 260 − 200 ＝ 60）`、ログ `ほうぐ！ 巴御前（NP 260 − 200 ＝ 60）オーバーチャージ ×2` → `てき：〇〇 に 4点`）
- オーバーチャージを **1ターンに 1回** に した わけ（2026-11-01 ユーザーが きめた）：しないと「100 の 宝具を 2回」と「200 の 宝具 1回」が 同じに なり、かけ算を しなくても すむ。1回に すると「いま 2倍で つかうか、100 を のこして つぎの ターンにも つかうか」の えらびに なる。**第1弾の サーヴァントは いまの まま**（100 ずつ 何回でも）
- NP 200・300 に とどく 道：令呪（＋100）・オベロン（＋100）・スカディ（毎ターン ＋50）・アルトリア・キャスター／光のコヤンスカヤ／ククルカン（出たとき ＋50）・虚数魔術（＋60）・カレイドスコープ（＋80）・ダブルチャージ（NP を 2倍）・アーツチェイン・始皇帝の 宝具 など。モルガンの 宝具は「つぎの オーバーチャージを 1つ 上げる」（NP 100 で 2倍）
- **クラス相性（あいしょう）は 入れない**（2026-11-01 ユーザーが きめた）。案に あった「相性 2倍（3すくみ × 3）」「バーサーカーの あたえる・うける 2倍」「対（たい）〇〇」「塔の 階の クラス」は ぜんぶ やめた。`game.js` の `damage()` は かえて いない

### 2.2 実装（2026-11-01）

エンジン（`game.js`）は かえて いない。かえたのは `js/data/set10.js`（宝具の しくみ）と `js/ui/battle.js`（ボタンの 文字）、カードの うごきは `js/data/set14.js`。

#### (1) オーバーチャージ（`js/data/set10.js`）

- `fireNP(s, E, p, t, k = 1)`：NP を `100 × k` へらして `npFx(s, E, p, t, k)` を よぶ。第1弾の サーヴァントは いつも k ＝ 1 で、ログも まえと 同じ（`ほうぐ！ 〇〇（NP 120 − 100 ＝ 20）`）
- オーバーチャージの サーヴァント（`def.oc`）だけ：
  - **1ターンに 1回**：つかった ターンの 番号を `p.ocT` に おぼえる（`ocUsed(s, p)`。てきの ターンでも はたらく）
  - **〔 〕の 数**：`oc(p, n)` ＝ （n ＋ 黒の聖杯の 数）× 倍。npFx の 中で `oc(p, 2)` の ように 書く
  - モルガン（FG164）：`s[側].flags.ocUp` が あれば 倍を 1つ 上げて（3 まで）けす。ログは `オーバーチャージ ×2（1 ＋ 1）`
  - 黒の聖杯（FG166）：宝具を つかう ときに、その サーヴァントに ついて いる 黒の聖杯（`def.grail`）の 数を `p.grailPlus` に
- クリプター：宝具の あとに、同じ 側の パーマネントの `onHogu(s, q, p, E, k)` を よぶ（k ＝ つかった NP の 100 の 数。モルガンで 倍が 上がっても k は かわらない）
- 宝具の ボタン（`np(npGain, npFx, x)`）：`x.oc` が あると「ほうぐ ×1（NP − 100）」「×2（NP − 200）」「×3（NP − 300）」の 3つ（`npUse` が 100・200・300、`ocK` が 1・2・3）。NP が たりない ものと、この ターン もう つかった ときは 灰色（`can`）。第1弾は いまの まま 1つ（`npUse: true`）
- 単体を えらぶ 宝具（`npTgt`。FG120）は ×1・×2・×3 の どれでも 人が えらぶ。「〔1〕体」の ように 何体も えらぶ ものは 自動（パワーが 大きい じゅん）
- **AI**：ボタンの 点が 8・12・16 なので、つかえる いちばん 大きい 倍で うつ。`x.npAI(s, p, E, ctx, k)` で「いま うって よいか」を カードごとに きめる（戦闘の まえに つかう ＋N/＋0 は メイン1 だけ・あいての クリーチャーが いない ときは うたずに NP を ためる など）。人は いつでも うてる
- てきがわの サーヴァント（`addNP` の じどう）：オーバーチャージは つかえる いちばん 大きい 倍で 1回だけ（`k ＝ Math.min(3, Math.floor(NP / 100))`）。set14.js の「ダメージを うけるたび」「ブロックするたび」の NP は、てきがわでは ためる だけ（`gainNP`）
- `npNote`（カードを タップした ときの せつめい）：オーバーチャージの サーヴァントには「NP を 100・200・300 の どれだけ つかうか えらぶと、〔 〕の 数が 1ばい・2ばい・3ばい（1ターンに 1回）」を 出す
- `set10.js` から export した 道具：`np`・`oc`・`addNP`・`servants`・`isServant`・`bestServant`（ほかの 1体を えらぶ ため `except` を 足した）・`detain`・`biggest`・`allFoes`・`master`・`randomFoe`・`ocUsed`
