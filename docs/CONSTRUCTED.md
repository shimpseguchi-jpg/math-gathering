# こうちくモード

ローグライク（冒険）とは べつの モード。**パックけん** で ショップの パックを あけて カードを あつめ、もって いる カードで デッキを くむ。

- 状態：**実装ずみ**（2026-10-28。ショップ・デッキ・れんしゅう・もって いる カード）。オンラインの「こうちくの 部」は **これから**（8章）
- ねらい：パックの 弾（だん）を **じぶんで えらべる** ように する。冒険の パックは 先生が きめた 弾（GAS の せってい シート）か、出て いる 弾の まぜ だけで、子どもは えらべない（`js/ui/settings.js` の `enabledSets`）
- 冒険は いままで どおり「毎回 同じ 条件で あそぶ」（[`REQUIREMENTS.md`](REQUIREMENTS.md) 8.1）。こうちくモードの カード・デッキは 冒険に もちこまないので、この きまりは かわらない

| | 冒険（ローグライク） | こうちくモード |
|---|---|---|
| カード | 毎回 3パックから | あつめた カードが のこる |
| パック | いつもの まぜ（先生が きめた はんい） | ショップで **弾を えらんで** あける |
| たのしさ | その場の やりくり | あつめる・考えて くむ |
| 算数 | ぴったり・たたかいの 中の 計算 | 30点の やりくり・パックけんの ひき算 |

| 項目 | 内容 |

| ショップ | こうちくモードの メニューの「ショップ」で、パックけんと パックを ひきかえる |
| 売って いる パック | **ぜんぶの 弾** |

| 4まい そろった カード | **ショップの パックから もう 出ない**（そうしないと いつまでも あつめきれない） |

## 2. パックけんの かず

| もらいかた | まい数 | メモ |
|---|---|---|
| とう | クリアした 階 1つに **1まい**（5階 のぼりきると 5まい）。とうの おわり（クリア・まけ）に まとめて。おわりの 画面に「パックけん ＋3まい」 | テーロス・ラヴニカ、統率者戦・ドラフト、むずかしさ、どれでも 同じ。コンティニューして クリアした 階も 1まい（同じ 階で 2まいには ならない）。とちゅうで やめて「あたらしい ぼうけん」を はじめた ときは、その とき のぼった 階の ぶん |
| むげんの とう | **5階 のぼるごとに 1まい**（おわりに まとめて） | 1階ずつ だと 多すぎる（AI で まんなか 13階。[`ENDLESS.md`](ENDLESS.md)） |
| しゅぎょう | ごうかくで **1まい**（ぼうけんの まえ・おわり、むげんの とうの 休けい所も）。**1日 5まいまで** | 60びょうで もらえるので、上限が ないと とうより ずっと 早く たまる。けっかの 画面に「パックけん ＋1（きょう あと 3まい）」。もんしょうポイントは いままで どおり |
| トロフィー | ブロンズ **1**・シルバー **2**・ゴールド **3**・プラチナ **5**（23こ ぜんぶで 44まい） | こうちくモードが できる まえに もらった トロフィーの ぶんも、はじめて ひらいた ときに まとめて もらえる。ショップの パックで レジェンド・サプライズを 引いても トロフィー |

- 見せかた：「パックけん 3 − 1 ＝ 2まい」（もんしょうの ポイントと 同じ ひき算。[`EMBLEMS.md`](EMBLEMS.md)）
- もらった ときは「パックけん ＋2まい（トロフィー）」の ように、どこで もらったかを 出す

## 3. ショップ

- **1まい ＝ 1パック**（8まい）。中身の 出かたは 冒険の さいしょの 3パックと 同じ（コモン 4・アンコモン 3・レア 1、8パックに 1回 レアが レジェンド、20分の1で サプライズ・レジェンド。[`REQUIREMENTS.md`](REQUIREMENTS.md) 6.1）。「よく 使う 色が 出やすい」は なし
- **ならぶ 弾**：メイン（第1〜5弾）・サブセット（ラヴニカ・三つの 旗・アルケミー・プレインズウォーカー）・番外編（FGO・スターレイル・ゼンゼロ）。サブセット・番外編も もんしょう なしで 買える。レイドの 統率者カードは ならばない
  - 開発中の 弾には「開発中」の しるし
  - GAS 版で 先生が 止めた もの（せってい シートの「つかわない弾」）は ならばない
- 弾ごとに「もって いる ○ / ○しゅるい・4まい そろった ○」を 出す。中の カードの 一覧は 出さない
- **4まい もって いる カードは もう 出ない**（同じ パックの 中でも 5まいめに ならない ように かぞえる）
  - その レアリティが ぜんぶ 4まい そろったら、ちかい レアリティの カードが 出る（コモンの わく → アンコモン → レア → レジェンド。レジェンドの わく → レア → アンコモン → コモン）
  - のこりが 8まいより すくない ときは、のこりの カードだけ 出る
  - 弾の カードが ぜんぶ 4まい そろうと「**コンプリート！**」で、その 弾の パックは もう 買えない（パックけんを むだに しない）
  - だから **弾の しゅるい ÷ 2 パック**で かならず コンプリートする（第1弾 126しゅるい → 63パック、第2弾 74しゅるい → 37パック）
- あけかたは 冒険と 同じ ガチャの 演出（光る パックを やぶる → 1まいずつ めくる。`js/ui/gacha.js`）。カードは あける まえに もちものに 入るので、とちゅうで とじても なくならない

## 4. もって いる カードと デッキ

| ルール | まい数 | キャパシティ | 色 | 同じ カード |
|---|---|---|---|---|
| **ノーマル** | 20まい | 30点 | 2色まで（無色は 自由。旗が あれば その 3色） | 4まいまで |
| **エターナル** | 20まい | なし | なし（何色でも） | 4まいまで |
| **ノーマル（統率者）** | 20まい ＋ 統率者 | 30点（統率者は 数えない） | 統率者の 色だけ（と 無色） | 4まいまで（統率者も 1まい） |
| **エターナル（統率者）** | 20まい ＋ 統率者 | なし | 統率者の 色だけ（と 無色） | 4まいまで（統率者も 1まい） |

- **統率者の ルール**（2026-10-28）：冒険の 統率者戦（[`REQUIREMENTS.md`](REQUIREMENTS.md) 8.5）と 同じ。もって いる 伝説の クリーチャーから 統率者を えらぶ（`commander.js` の `pickLegend` の `only`）。統率者は とうそつりょういきに いて、唱える たびに ＋2マナ。統率者に 1まい つかうので、デッキに 入れられる 同じ カードは のこりの まい数（4まい もって いれば 3まい）。エターナル（統率者）も 色は 統率者の 色だけ（点の せいげんだけ ない）
- デッキ構築で「かえる」を おすと 統率者を かえられる。色が あわない カードは デッキから はずれる

- ノーマルは とうと 同じ きまり（[`REQUIREMENTS.md`](REQUIREMENTS.md) 6.2）なので、バランスの 調整を そのまま 使える。エターナルは もって いる つよい カードを 自由に くみあわせる ルール
- どちらも たりない ぶんは きほんカード（よく つかう 色から）。きほんカードは 4まいの 数に 入らない
- レジェンドも 4まいまで 入れられる。ただし 戦場に 出せるのは 同じ 名前 1つだけ（伝説の きまり。[`REQUIREMENTS.md`](REQUIREMENTS.md) 3.3）
- 冒険の デッキは いままで どおり（パックから 出た まい数まで。[`REQUIREMENTS.md`](REQUIREMENTS.md) 6.2）
- **もって いる カード ＝ ショップで 出た カード**。冒険の パックで 出た カードは 入らない（ずかん だけ）。ショップで 出た カードも ずかんに のる
- デッキは ルールを えらんで つくる。デッキは **10こまで** ほぞん。なまえは「ノーマル 白緑 1」「エターナル（統率者） 青緑 1」の ように 自動で つく（統率者の ルールは 統率者の 色）
- **ならべかえ・しぼりこみ**：デッキ構築の「こまかく」（冒険と 同じ。なまえ・マナコスト・色・しゅるい・しゅぞく・レアリティ・のうりょく・デッキ）に「**弾**」（弾が 2つ いじょう まざって いる ときだけ 出る）と「**テキスト**」を 足した。
  - テキスト：カードの 文と タイプの 行（「アーティファクト — 装備品」）から さがす。空白で 区切った ことばが ぜんぶ ある カード（「1まい 引く」でも「引く 1まい」でも）。漢字（1枚 引く）・ふりがな（1まい 引く）・まぜても あたる。全角・半角は 同じ（＋1/＋1 と +1/+1）。なまえの さがしかたも 同じに した
  - こうちくモードの せっていは 冒険とは べつに のこる（`mtg-build-filter-c`）。「もって いる カード」の 画面にも 同じ「こまかく」
- **デッキの カード**：デッキ構築の「デッキ ○まい」の タブで、いま デッキに 入って いる カードを 1行ずつ（同じ カードは まとめて「×2」、マナコストの じゅん）。−／＋で 1まいずつ 出し入れ、なまえで せつめい。上に マナコストごとの まい数の グラフと クリーチャーの まい数（冒険の デッキ構築でも 同じ）
- デッキ構築の 画面は 冒険の もの を つかう。同じ カードは 1まいに まとめて、右上に「●●○○」（● デッキに 入れた・○ まだ 入れて いない）。「すぐ 入れる」では タップで 1まいずつ 入れ、ぜんぶ 入れた カードを タップすると ぜんぶ はずす。「せつめいを 見る」では「1まい 入れる」「1まい はずす」
- おまかせ：ノーマルは 冒険と 同じ（いちばん つよい 2色で 30点の 中で）。エターナルは いちばん つよい 2色の ねうちの 高い じゅんに 20まい。統率者の ルールは 統率者の 色で
- もって いない カードが 入った デッキ（ぜんぶ 開放を やめた あとなど）は「もって いない カード ○まい」と 出て、たたかう ときは その ぶんが きほんカードに なる

## 5. くんだ デッキで あそぶ

| あそびかた | 内容 |
|---|---|
| れんしゅう | すきな せかい（テーロス・ラヴニカ）・むずかしさ・てき（1〜5階の ぜんぶ）を えらんで 1戦。どの ルールの デッキでも。統率者の デッキは 3階から 上の てきが ＋1/＋1（冒険と 同じ）。**パックけん・トロフィー・ずかんの きろくは ふえない**（つよい デッキで かんたんな 階を くりかえして ためられない ように） |
| オンライン バトル | 「**こうちくの 部**」を ふやし、**ノーマル**・**エターナル**・**ノーマル（統率者）**・**エターナル（統率者）** の 4つに 分ける（2026-10-28 きまり）。ランキングは 冒険の 部と この 4つで べつ。あいては 同じ ルールの ゴーストから えらぶ（あつめて くむ デッキの ほうが つよいので、冒険の デッキとは まぜない）。**これから**（8章） |

- 冒険には もちこまない

## 6. 画面

- タイトルに「**こうちく**」ボタン（`パックけん ○まい` を 小さく 出す）
- こうちくモードの メニュー：**ショップ**／デッキ／れんしゅう／もって いる カード。下に「パックけんの もらいかた」（しゅぎょうは きょう あと ○まい）
- もって いる カード：弾ごとに、もって いる カードだけ ならべて 右上に「×2」

## 7. ほぞんと 先生の ためし

- ブラウザの `localStorage`（`mtg-collection`）：パックけん・もらった 合計・もって いる カード（ID ごとの まい数）・デッキ・しゅぎょうで もらった 1日の まい数・パックけんに した トロフィー
- ひきつぎ（`mtg-` で はじまる キーを ぜんぶ あずける。`js/ui/server.js` の `packSave`）に そのまま 入る
- **カードを ぜんぶ 開放**（`mtg-cards-all`。この 端末だけ）：先生の 開発モード（GAS 版）か、WEB版の せっていの デバッグモードで オン。こうちくモードで ぜんぶの 弾の カードを 4まいずつ もって いる ことに なる（デッキを くんで ためす ため）。ほんとうの もちもの・パックけん・ショップの「4まい そろった」は そのまま のこり、オフに すると もどる。子どもの 端末では 先生か デバッグモード で ないと きかない

## 8. これから

- オンラインの「こうちくの 部」（ノーマル・エターナル・ノーマル（統率者）・エターナル（統率者））：GAS の シートを 部ごとに 分け、サーバーで「20まい・30点・2色・4まいまで・知って いる カード」（エターナルは 点と 色を 見ない。統率者は 統率者の 色と 統率者の カード）を チェックする。もって いる カードは 端末に あるので サーバーでは たしかめられない（ずる対策は 子ども向けなら 許容。[`ROADMAP.md`](ROADMAP.md) 8章と 同じ 考え）
- 弾ごとに パックの ねだんを かえるか（いまは どれも 1まい）
- エターナルの バランス（つよい カードだけの デッキ）は、あそんで もらってから 見る
