# こうちくモード

ローグライク（冒険）とは べつの モード。**パックけん** で ショップの パックを あけて カードを あつめ、もって いる カードで デッキを くむ。

- 状態：**案**（2026-10-28。1章は きまった こと、【提案】は かわりが なければ その 内容で 作る）
- ねらい：パックの 弾（だん）を **じぶんで えらべる** ように する。いまは 先生が きめた 弾（GAS の せってい シート）か、出て いる 弾の まぜ だけで、子どもは えらべない（`js/ui/settings.js` の `enabledSets`）
- 冒険は いままで どおり「毎回 同じ 条件で あそぶ」（[`REQUIREMENTS.md`](REQUIREMENTS.md) 8.1）。こうちくモードの カード・デッキは 冒険に もちこまないので、この きまりは かわらない

| | 冒険（ローグライク） | こうちくモード |
|---|---|---|
| カード | 毎回 3パックから | あつめた カードが のこる |
| パック | いつもの まぜ（先生が きめた はんい） | ショップで **弾を えらんで** あける |
| たのしさ | その場の やりくり | あつめる・考えて くむ |
| 算数 | ぴったり・たたかいの 中の 計算 | 30点の やりくり・パックけんの ひき算 |

---

## 1. きまった こと（2026-10-28）

| 項目 | 内容 |
|---|---|
| パックけんの もらいかた | ① とうの 階を クリアする（とうの おわりに まとめて もらう）② しゅぎょう ③ トロフィーを もらった とき |
| ショップ | こうちくモードの メニューの「ショップ」で、パックけんと パックを ひきかえる |
| 売って いる パック | **ぜんぶの 弾** |
| パックの 中身 | **わからない**（弾は えらべるが、出る カードは あけるまで わからない） |
| デッキの ルール | ① **ノーマル**：とうと 同じ（20まい・30点・2色まで）② **エターナル**：キャパシティと 色の 制限が ない（4章） |
| 同じ カード | **4まいまで**（きほんカードは のぞく）。ノーマルも エターナルも |

## 2. パックけんの かず【提案】

| もらいかた | まい数 | メモ |
|---|---|---|
| とう | クリアした 階 1つに **1まい**（5階 のぼりきると 5まい）。とうの おわり（クリア・まけ・やめる）に まとめて | テーロス・ラヴニカ、統率者戦・ドラフト、むずかしさ、どれでも 同じ。コンティニューして クリアした 階も 1まい（同じ 階で 2まいには ならない） |
| むげんの とう | **5階 のぼるごとに 1まい**（おわりに まとめて） | 1階ずつ だと 多すぎる（AI で まんなか 13階。[`ENDLESS.md`](ENDLESS.md)） |
| しゅぎょう | ごうかくで **1まい**（ぼうけんの まえの しゅぎょうも）。**1日 5まいまで** | 60びょうで もらえるので、上限が ないと とうより ずっと 早く たまる。もんしょうポイントは いままで どおり |
| トロフィー | ブロンズ **1**・シルバー **2**・ゴールド **3**・プラチナ **5**（23こ ぜんぶで 44まい） | こうちくモードが できる まえに もらった トロフィーの ぶんも、はじめて ひらいた ときに まとめて もらえる |

- 見せかた：「パックけん 3 − 1 ＝ 2まい」（もんしょうの ポイントと 同じ ひき算。[`EMBLEMS.md`](EMBLEMS.md)）
- もらった ときは「パックけん ＋2まい（シルバーの トロフィー）」の ように、どこで もらったかを 出す

## 3. ショップ【提案】

- **1まい ＝ 1パック**（8まい）。中身の 出かたは 冒険の さいしょの 3パックと 同じ（コモン 4・アンコモン 3・レア 1、8パックに 1回 レアが レジェンド、20分の1で サプライズ・レジェンド。[`REQUIREMENTS.md`](REQUIREMENTS.md) 6.1）。「よく 使う 色が 出やすい」は なし
- **ならぶ 弾**：メイン（第1〜5弾）・サブセット（ラヴニカ・三つの 旗・アルケミー・プレインズウォーカー）・番外編（FGO・スターレイル・ゼンゼロ）。サブセット・番外編も もんしょう なしで 買える。レイドの 統率者カードは ならばない
  - 開発中の 弾には「開発中」の しるし
  - GAS 版で 先生が 止めた もの（せってい シートの ban）は ならばない
- 弾ごとに しゅるいの 数と、ずかんで あつめた 数（「38 / 81」）を 出す。中の カードの 一覧は 出さない（ずかんで 見た ことの ある カードは ずかんで 見られる）
- **同じ カードが 出すぎない**：デッキに 入れられる 上限（4まい）まで もって いる カードは もう 出ず、その 弾の 同じ レアリティの ほかの カードに かわる。その レアリティを ぜんぶ もって いる ときは そのまま 出る
- あけかたは 冒険と 同じ ガチャの 演出（光る パックを やぶる → 1まいずつ めくる）

## 4. もって いる カードと デッキ

デッキの ルールは 2つ（2026-10-28 きまり）。

| ルール | まい数 | キャパシティ | 色 | 同じ カード |
|---|---|---|---|---|
| **ノーマル** | 20まい | 30点 | 2色まで（無色は 自由） | 4まいまで |
| **エターナル** | 20まい | なし | なし（何色でも） | 4まいまで |

- ノーマルは とうと 同じ きまり（[`REQUIREMENTS.md`](REQUIREMENTS.md) 6.2）なので、バランスの 調整を そのまま 使える。エターナルは もって いる つよい カードを 自由に くみあわせる ルール
- どちらも たりない ぶんは きほんカード。きほんカードは 4まいの 数に 入らない
- レジェンドも 4まいまで 入れられる。ただし 戦場に 出せるのは 同じ 名前 1つだけ（伝説の きまり。[`REQUIREMENTS.md`](REQUIREMENTS.md) 3.3）
- 冒険の デッキは いままで どおり（パックから 出た まい数まで。[`REQUIREMENTS.md`](REQUIREMENTS.md) 6.2）
- 【提案】**もって いる カード ＝ ショップで 出た カード**。冒険の パックで 出た カードは 入らない（ずかん だけ）。ショップで 出た カードも ずかんに のる
- 【提案】デッキは ルールを えらんで つくる（ノーマルなら 30点の メーターと 色の 制限が 出る）。ノーマルの デッキは エターナルでも つかえる
- 【提案】デッキは **10こまで** ほぞん。なまえは「ノーマル 白緑 1」「エターナル 5色 1」の ように 自動で つく
- 【提案】デッキ構築の 画面は 冒険の もの（ならべかえ・しぼりこみ・おまかせ）を つかう

## 5. くんだ デッキで あそぶ

| あそびかた | 内容 |
|---|---|
| オンライン バトル | 「**こうちくの 部**」を ふやし、**ノーマル** と **エターナル** に 分ける（2026-10-28 きまり）。【提案】ランキングは 冒険の 部・ノーマル・エターナルの 3つ べつ。あいては 同じ ルールの ゴーストから えらぶ（あつめて くむ デッキの ほうが つよいので、冒険の デッキとは まぜない） |
| とうの れんしゅう | 【提案】すきな せかい・階を えらんで 1戦（どちらの ルールの デッキでも）。**パックけんは もらえない**（つよい デッキで かんたんな 階を くりかえして ためられない ように） |

- 冒険には もちこまない

## 6. 画面【提案】

- タイトルに「**こうちく**」ボタン（`パックけん ○まい` を 小さく 出す）
- こうちくモードの メニュー：**ショップ**／デッキ／たたかう（オンライン・れんしゅう）／もって いる カード
- もって いる カードは ずかんと 同じ ならびで、まい数（×2）を 出す

## 7. ほぞん

- ブラウザの `localStorage`（`mtg-collection`）：パックけん・もって いる カード（ID ごとの まい数）・デッキ・しゅぎょうで もらった 1日の まい数
- ひきつぎ（`mtg-` で はじまる キーを ぜんぶ あずける。`js/ui/server.js` の `packSave`）に そのまま 入る
- サーバーでは もって いる カードを たしかめられない（端末に ある）。こうちくの 部の チェックは、ノーマル「20まい・30点・2色・4まいまで・知って いる カード」、エターナル「20まい・4まいまで・知って いる カード」だけ（ずる対策は 子ども向けなら 許容。[`ROADMAP.md`](ROADMAP.md) 8章と 同じ 考え）

## 8. まだ きまって いない こと

- しゅぎょうの 1日の 上限（5まい）で よいか
- オンラインの「こうちくの 部」の サーバー（GAS の シートを 部ごとに 分ける）は、ショップ・デッキが できた あとに 作る
- 弾ごとに パックの ねだんを かえるか（いまは どれも 1まい）
- エターナルの バランス（5色の つよい カードだけの デッキ）は、あそんで もらってから 見る
