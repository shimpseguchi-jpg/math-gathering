## 2. 新しい しくみ

ゼンゼロの 戦闘の「連携スキル」（ブレイクした ときに 2人で つづけて こうげき）と「紊乱（びんらん）」（ちがう 属性異常が かさなると 大きな ダメージ）を、**たし算** と **2倍** に した。問題を 出すのでは なく、ルールの 中で 計算が おきる。

| しくみ | 説明（長おしで 出す 文の 案） | 算数 |
|---|---|---|
| **連携（れんけい）スキル** | 「連携スキル ― 〜」は、あなたが **ブレイクを つかった あと** に おきる。この クリーチャーと、あなたの ほかの エージェント（伝説（でんせつ）の クリーチャー）1体を えらんで、2体の **パワーを たす**。その 合計が「**連携の 数**」。ほかの エージェントが いなければ、この クリーチャーの パワーだけ。**エージェント（伝説の クリーチャー）は みんな もつ**（2026-11-04。第1弾の 28人も）。2026-11-04 に たした 46人は 連携の 数の **半分（はんぶん）**（あまりは すてる）を つかう | **たし算**（4 ＋ 3 ＝ 7）。「7 いか」の くらべっこ（トリガー・儀玄）、あまり（9 − 6 ＝ 3。葉瞬光）。**わり算**（7 ÷ 2 ＝ 3 あまり 1。2026-11-04 に たした 46人） |
| **属性異常（ぞくせいいじょう）** と **異常（いじょう）** | 属性異常を もつ クリーチャーが 敵（てき）の クリーチャーに ダメージを 与（あた）えると、その クリーチャーに じぶんの **色の 異常** を つける（1体に 1つ。あたらしい 色で 上書き）。カードの こうかで 異常を つける ことも ある。異常は その クリーチャーが 場に いる あいだ のこる。**異常を つけると、その 色の 属性ブレイク**（その 色の ゼンゼロの クリーチャーが 場に いれば ブレイクカウンター 2こ。同じ 色を つけなおしても たまらない） | 色を 見分ける |
| **紊乱（びんらん）** | 異常が ついた 敵（てき）の クリーチャーに、**その 異常と ちがう 色を もつ** あなたの クリーチャーが ダメージを 与（あた）えると「紊乱」。その ダメージは **2倍** に なる。異常は きえる（属性異常を もつ クリーチャーなら、こんどは その 色の 異常が つく） | **2倍**（3 × 2 ＝ 6、3 ＋ 3 ＝ 6）。連携と かさなると（4 ＋ 3）× 2 ＝ 14 |

- 連携スキルは ブレイク（10 の まとまり）の ごほうび。ブレイクは 1戦 1回 くらい（第1弾の シミュレーション）なので、**たまに おきる 大きな たし算**。人が 遊ぶ ときは あいての エージェントを じぶんで えらぶ（「アンビー 4 ＋ トリガー 2 ＝ 6」の ボタン）。ログにも「連携スキル：4 ＋ 3 ＝ 7」と 出す
- **エージェントは みんな 連携スキル**（2026-11-04）：はじめは 9まい（レジェンド 7人 ＋ 防衛軍の 兵士・雲嶽山の 門下生）だけ だった。第1弾・第2弾の エージェント 53人 みんなに した。もとから ある 9まいは その まま。のこりの **46人**（第1弾 28・第2弾 18）は 色ごとの かたで、もとの 9まいより 小さい **連携の 数の 半分**（あまりは すてる。ログ「連携の 数の 半分：7 ÷ 2 ＝ 3 あまり 1」）を つかう
  - 白：あなたの クリーチャー1体は ターン終了時まで ＋半分/＋0（ブレイクは メインフェイズに つかう ので こうげきの まえ）
  - 青：パワーが 半分 いかの 敵の クリーチャー1体を タップ（つぎの 敵の ターンに アンタップしない）
  - 黒：敵の クリーチャー1体は ターン終了時まで −半分/−半分
  - 赤：敵の クリーチャー1体に 半分の ダメージ（この クリーチャーが あたえる ので 紊乱も おきる）
  - 緑：あなたの クリーチャー1体に ＋1/＋1カウンターを 半分の 数
  - 白は はじめ「連携の 数の ライフ」に したが、ボスの エレボス（ライフの けずりあい）で とても きいて 強すぎた（6.1）
  - ねらいかたは もとの 連携と 同じ：レア・レジェンドは 人が えらぶ、アンコモンは パワーが いちばん 大きい 敵、コモンは ランダム（緑・白の じぶんの クリーチャーは レア・レジェンドだけ 人が えらぶ。ほかは AI と 同じ）
- **おなじ 色だけで 連携**（ユーザーの 案。2026-11-04 に ためした）：`set12.js` の `CHAIN_SAME_COLOR.on` を true に すると、あいては この クリーチャーと 色が 1つ いじょう 同じ エージェント だけに なり、いなければ 連携しない（ログ「おなじ 色の エージェントが いないので 連携スキルは おきない」）。**いまは off**（だれとでも 連携。あいてが いなければ じぶんの パワーだけ）。わけは 6.1
- 紊乱は **よく おきる 2倍**。「赤の 異常が ついた 敵を、青の クリーチャーで なぐると 2倍」。ログ「紊乱（びんらん）！ 3 × 2 ＝ 6」。タフネス 5 の 敵に 3点 では たおせないが、紊乱なら 6点で たおせる（**くらべる**）
- 第1弾の カードでも、色の ある クリーチャーなら 紊乱を おこせる（異常を つけるのは 第2弾の カード）
- 紊乱を おこすのは **あなたの クリーチャーが あたえる ダメージ だけ**（戦闘・攻撃したとき などの 能力・連携スキル）。呪文・ブレイク・ビビアンの 1点 の ような「クリーチャーで ない」 ダメージと、色の ない クリーチャー（ボンプ）は おこさない
- 紊乱の 2倍に 回数の 上限は つけない（6章：1戦 0.4回 くらいで 強すぎない）。紊乱で ブレイクカウンターは たまらない
- **命破（めいは）**（儀玄・イドリー・狛野真斗・スターライト・ビリーの「HP を つかう」）は 新しい しくみに しない。「ライフを 2点 うしなう：＋3/＋0」の ような **ライフの ひき算**（20 − 2 ＝ 18）を する 起動型能力に した（エンジンの `hurt` で できる）

- **おなじ 色だけで 連携（c）**：強さは ほとんど かわらない（off より −1〜−2 ポイント）。かわるのは 回数：ゼンゼロだけの デッキで 連携が 28〜35% へり、1戦 1回 くらい「おなじ 色が いない」で おきない。いつもの パックに まぜた デッキでは 0.5 → 0.2回（連携が ある たたかいは 24% → 8%）で、ほとんど 見られなく なる。→ **強さの ためには いらない。たし算・わり算を する 回数が へって、ルールも むずかしく なる ので off に した**（`CHAIN_SAME_COLOR.on = false`）。色を いかしたい なら「おなじ 色の あいてだと ＋1」の ような ごほうびの ほうが よい（まだ ためして いない）
- 人が 遊ぶ ときは、ブレイクの たびに 連携スキルを もつ クリーチャー ごとに「だれと 連携する？」（エージェントが 2人 いじょう）と レア・レジェンドの 対象を えらぶ。エージェントが 3人 いると 3回 えらぶ ことに なる
- ついでに 直した こと：英雄譚が さいごの 章の あと 墓地に いく まえ（AI の 章が まち）に 増殖されると エラーで とまって いた（`kit.js` の `saga`。`SETS=1,2,5 EMBLEM=pZZZ` の シード 1 で おきた）

### 6.2 ブレイクの「ぜんたい」を「かいふく」に（2026-11-05）

ユーザーが きめた：ブレイクの 3つの えらびの うち **ぜんたい（敵の クリーチャー ぜんぶに 3点）を かいふく（ライフ ＋6）** に かえる。のこりは その まま（たんたい：敵の クリーチャー 1体に 6点・本体に 5点、かいしゅう：マナゾーンの カード 1まいを 手札に）。

- うごき：`game.js` の `BREAK_HEAL = 6`・`useBreak(s, 'heal')`（ふつうの `gainLife`。「ライフを 得たとき」も おきる・ライフを 得られない ときは なにも おきない。`s.inBreak` の あいだ なので 白の 属性ブレイクは たまらない）。ログ「ブレイク！ ライフ ＋6（11 ＋ 6 ＝ 17）」。連携スキルは まえと 同じく ブレイクの あと
- 画面（`battle.js` の `showBreak`）：ボタン「かいふく：ライフ ＋6（11 ＋ 6 ＝ 17）」（ライフを 得られない ときは 灰色）。チュートリアル 4-3 と 長おし（`glossary.js` の ブレイク）の 文も かえた
- AI（`ai.js` の `aiBreak`）：本体で かてる → 本体、ライフが **10 いか**（`BREAK_HEAL_AT`）→ かいふく、あとは まえと 同じ（たおせる パワー 3 いじょう → 本体 → たおせる 敵 → かいしゅう）。さいごの のこりも ぜんたい では なく かいふく（ライフを 得られない ときは いちばん つよい 敵に たんたい）
