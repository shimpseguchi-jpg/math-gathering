## 4. うごきの きまり（実装メモ）

- 青子の「好きな 対象に 1点」：人が あそぶ ときは、呪文の あとに 画面で あいて（敵の クリーチャーか 敵）を えらぶ。えらぶ まえに 戦闘・ターンの おわりが 来たら、AI と おなじ えらびかた（たおせる あいて → 敵）
- 青子の ダメージは ぜんぶ かぞえる：魔弾の 1点・戦闘ダメージ・マジックガンナーの ダメージ（あいて 1つに つき 1回）。マジックガンナーは 1ターンに 1回
- 有珠：カウンターが 5こに なった ときに すぐ うごく。グレートスリーも トークンなので、出ると 有珠に 1こ 乗る（薔薇の猟犬は 有珠が いなくなる）
- 草十郎：人は 取りのぞく たびに 3つから えらぶ（接死・呪禁は もう あれば えらべない）。AI は 接死 → 呪禁 → ＋1/＋1 の じゅん。3こめを 取りのぞくと、カウンターを もらった あとで 墓地へ
- ロスト・ロビン・ロンドの 空蝉：トークンでない クリーチャーが 死亡する ときだけ（椋鳥の 身代わりには ならない）。まもられた クリーチャーの ダメージは きえる
