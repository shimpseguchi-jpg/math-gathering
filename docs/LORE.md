# カードの せりふ（LORE）

- 状態：**実装ずみ**（2026-10-27）。ここが もと。`python3 mathtcg/tools/gen_texts.py` で `js/data/lore.js` に なる
- RPG の ように、キャラクターが じぶんで しゃべる。低学年が「なぜ？」と おもう ルールを、キャラの ことばで つたえる
- **とき**：しゃべる タイミング。その カードの 能力が **ゲームの 中で ほんとうに うごいた とき** に しゃべる（1ターンに 1回まで）
  - 出た（場に 出た とき）・攻撃（攻撃するたびの 能力）・能力（起動型の 能力・戦技・宝具・プレインズウォーカー）・ダメージ（ダメージを あたえたときの 能力）・たおれた・たおした・ターン（ターンの はじめの 能力）・戦闘（戦闘の はじめの 能力）・なかま（なかまが 出た／たおれた ときの 能力）・唱えた（呪文を 唱えたときの 能力）・撃破・引いた・ブロック・ねらわれた・ねらえない（あいてが ねらおうと して ねらえなかった とき）
  - 能力が うごいても なにも おきなかった とき（ログが ふえない とき）は しゃべらない
- **せりふ**：キャラクターらしい ひとこと。その「とき」の 能力に あう ことばに する。**しくみ**：ゲームの ルール（とくべつな ルールの カード だけ）
- 出る ところ
  - カードの せつめい（いつでも）
  - 「とき」の 能力が うごいた とき：**ふきだし**（数びょう。たたかいは とまらない）
  - しくみの ある カードは、あいての 場に 出た とき・ねらえなかった とき **ポップアップ**（とまって 読む。1回の たたかいで 1回）
- 書きかた：ひらがな 中心。3年生より 上の 漢字は「漢字（よみ）」。1つ 40字くらいまで。ほかの 会社の キャラクター（FGO・スターレイル・ゼンゼロ）は、ゲームの セリフを そのまま つかわず、その キャラらしい オリジナルの ことばに する
- 対象：クリーチャーと プレインズウォーカーの 伝説、第1弾・第2弾の レア・レジェンドの クリーチャー（祠・誓い・アーティファクト などの「もの」は のぞく）
