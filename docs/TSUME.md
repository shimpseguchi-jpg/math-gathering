# つめマス（この ターンで かて）

つめ将棋の ように、きまった 場と てふだから **この ターンの うちに てきの ライフを 0に する** 手じゅんを さがす パズル。

- 状態：**実装ずみ**（2026-11-11。ユーザーが きめた：新しい モードの 案 1）
- ねらい：REQUIREMENTS 5章「勝つために 考えると、自然に 計算する」を、1ターンに しぼって くりかえし あそべる ように する（たし算・ひき算・10の まとまり・ぴったり・マナの やりくり）
- ファイル：`js/engine/tsume.js`（階・盤面・探索）、`js/data/tsume.js`（問題。自動生成）、`js/ui/tsume.js`（画面）、`tools/gen_tsume.mjs`（問題を つくる・たしかめる）

## 1. あそびかた

- タイトルの「つめマス」→ レベル 1〜5（12問ずつ・60問）と「きょうの 1問」
- 場・てふだ・マナゾーン・てきの クリーチャーと ライフが きまって いる。山札は ない（引かない）
- たたかいは **ほんものの ルールと ほんものの カード**（`battle.js`・`game.js` そのまま）。マナに おく（1ターンに 1まい）・じゅもん・こうげき（1回）・コンバットトリック・こうげきの あとの じゅもん
- てきは なにも しない。**ターンを おわると まけ**（`floor.endTurn`）。なんどでも やりなおせる
- てきの ブロックは いつもの きまり（REQUIREMENTS 8.11）：本体への こうげきは「たおせるか、たおされない ときだけ」ブロック。こうげき された てきは ほかの ブロックに 出られない
- **てきの ライフ ＝ その 盤面で 本体に あたえられる いちばん 大きい ダメージ**。だから かならず「ちょうど 0」で 勝つ（むだな 手は ゆるされるが、たりない 手は 1点でも まけ）
- まけた とき：「てきの ライフが 2 のこった（5 − 3 ＝ 2）。あと 2点！」と ひき算を 見せる → もう いちど・ヒント（こたえの 考えかたから 1つずつ）・こたえ（2回 しっぱいで 出る。いちばん みじかい 手じゅん）
- ほし：★★★（ヒントなし・しっぱい 2回まで）、★★（ヒントを 見た か 3回 いじょう しっぱい）、★（こたえを 見た）
- レベルは まえの レベルを **6問** クリアすると ひらく（デバッグの「ぜんぶ あそべる」で ぜんぶ）
- ごほうび（もんしょうポイント）：レベルを ぜんぶ クリア ＋2（5レベルで 10）、きょうの 1問 ＋1（1日 1回。日づけで きまる 問題。みんな おなじ）
- セーブ：`mtg-tsume`（done：ほしの 数、tries：しっぱいの 回数、daily、lvPaid）

## 3. 問題の つくりかた（自動）

`node tools/gen_tsume.mjs`（40秒 くらい。レベルごとに 子プロセス）

1. レベルの 材料（じぶんの 場・てき・てふだ・マナ）から ランダムに 盤面を つくる
2. **ぜんぶの 手を しらべる**（`solve`）：てきの ライフを 99 に して、本体に あたえられる いちばん 大きい ダメージを 出す → てきの ライフを その 数に する
3. もう いちど しらべて、こたえの 数・いちばん みじかい 手じゅん・考えかた（tags）を 出す
4. 「ぜんぶで 本体を こうげき → のこった じゅもんを 本体へ」で 勝てるか（`naiveWins`）、でたらめに 手を えらんで 勝てる わりあい（`randomWinRate`。300回）を はかる
5. レベルの 条件に あう もの だけ のこす。こたえの 形が にた 問題は 2つまで。手札に つかわない カードが 2まい いじょう ある 問題は すてる
6. `node tools/gen_tsume.mjs --check`：いまの 問題を ぜんぶ ときなおす（ライフ ＝ いちばん 大きい ダメージ か）

### 探索（`js/engine/tsume.js`）

- 人が 画面で できる ことと おなじ 手だけ：マナに おく・クリーチャーを 出す・じゅもん（対象・X・キッカー・激励）・こうげき（クリーチャーごとに「しない・本体・てきの クリーチャー」）・コンバットトリック・ダメージ
- うごかすのは 画面と おなじ 関数（`castCard`・`declareAttack`・`finishCombat`・カードの `apply`・`singleRun`）。状態は `cloneState` で コピーして 1手ずつ すすめる。おなじ 状態は 1回だけ（`sig`）
- ねらいかたが きまって いる カード（アンコモン：いちばん 大きい）は `game.js` の `autoTargets`（画面の `autoPick` と きょうゆう）。**ランダムに ねらう カード（コモン）は 問題に 入れない**（`tsumeCardOk`）
- おなじ てきを 2体で こうげきする くみあわせは しらべない（1体で ブロックを とめられる）。この はぶきで こたえを 見のがしても、問題が とける ことは かわらない（ライフが 少し 小さく なるだけ）
- あつかわない カード：モード・追加コスト・待機・出来事・授与・割り振り・召集・引く カード（山札が ない）
