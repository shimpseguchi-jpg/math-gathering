## 2. 新しい能力

キーワードは第1弾と同じく **MTG の名前のまま**（REQUIREMENTS 3.2）。長押しの説明文の案も書く。

| キーワード（読み） | 英語 | 説明（長押しで出す文の案） | 意識する数 | カード |
|---|---|---|---|---|
| 暴勇（ぼうゆう） | Hellbent | 自分の 手札が 0まい なら、効果が 出る | ひき算（のこり 何まい？） | U31・R36・UR03・UR04 |
| 英雄譚（えいゆうたん） | Saga | 出たときと、自分のターンのはじめに 伝承（でんしょう）カウンターが 1個 のる。のった 数の 章（I・II・III）が 起きる。さいごの 章の あと 墓地へ | 1・2・3 の じゅんばん、「あと 何ターン？」 | W32・W35・U32・U35・U37・G33・R32 |
| 集会（しゅうかい） | Coven | 自分の クリーチャーに、パワーが ちがう ものが 3体 いじょう いるなら、効果が 出る | 同じ数・ちがう数を 見分ける（2・2・3 は 2しゅるい） | W29・G27・G34・WG03・WG04 |
| 喊声（かんせい） | Battle cry | これが 攻撃するたび、ほかの 攻撃している クリーチャーは みんな ＋1/＋0 | かけ算（ほかに 3体 なら ＋3） | W27・R27・R33・RW03 |
| 消失（しょうしつ） N | Vanishing | 時間カウンター N個で 出る。自分の ターンの はじめに 1個 へる。さいごの 1個が なくなったら 墓地へ | ひき算・カウントダウン | W28・W33・U33・U34・WU03 |
| 宝物（たからもの） | Treasure | 宝物トークン：「タップ・これを 墓地に 置く：好きな 色の マナを 1つ 出す」。とっておいて あとで 使える | マナの 先読み（いま 使う？ つぎの ターン？） | R37・C13・C14 |
| 適応（てきおう） N | Adapt | ＋1/＋1カウンターが 1つも のっていないなら、N個 置く | 0 の いみ・たし算 | U28・G32・GU03 |
| 脱出（だっしゅつ） | Escape | 墓地から 唱えられる。コストと いっしょに、墓地の ほかの カードを N まい 追放する | 墓地の 枚数を 数える・ひき算 | G28・R28・R29・R34・R35・RG04・GU04 |
| サイコロ（6面） | Roll a die | 1〜6 の サイコロを ふる。「2〜3 なら」のように 出た目で 効果が かわる | 大小比較・はんい（4〜5 は どれ？） | R31・C14 |

- **奇数・偶数** はキーワードにしない。「コストが 奇数の 呪文を 唱えるたび」のように カードの文章に書く（U30）
- **湧血（ゆうけつ）**（第1弾）と **手札を 捨てる コスト**（稲妻の 斧・怪物化）も 緑赤・赤で ふやす（G29・RG03・R30・C16）
- **サイコロ** は MTG では「フォーゴトン・レルム探訪」の 20面（d20）。本作は小学生向けに **6面** にする【提案】
### 2.1 手札の 補充（ラッシュデュエル形式）との 相性

毎ターン 手札が 5まいに もどるので、MTG と 同じ 強さに しても 意味が かわる カードが ある。

| カード | このゲームでは | 第2弾の あつかい |
|---|---|---|
| 「カードを 引く」が ごほうび | 弱い（つぎの ターンの 補充が へるだけ） | へらした（G34・WG04・UR04 を ちがう ごほうびに） |
| 引いた 数を 数える（あやしい 海・夢さらい） | 強い（補充で 毎ターン 何まいも 引く） | そのまま。「何まい 引いた？」を 数える |
| 手札を 捨てる コスト（湧血・稲妻の 斧・怪物化） | 軽い（つぎの ターンに 5まいに もどる） | ふやした。捨てた カードは 墓地に たまって 脱出に 使える |
| 暴勇（手札 0まい） | ターン中に 使いきれば とどく | 赤青の 新しい 能力に した |
| 手札を ぜんぶ 捨てる（ケルドの 炎・アゴナスの 雄牛） | ほぼ デメリットなし ＋ 暴勇が すぐ 出る | そのまま（暴勇と なかよし） |

- 第1弾の 怪物化（ネシアンの アスプ・嵐息吹の ドラゴン）も、マナでは 間に合わなかったので「1マナ ＋ 手札を 2まい 捨てる」に かえた（SIMULATION.md）
- **脱出** と 山札（やまふだ）の ルール：墓地は 山札が なくなったときに まぜて もどすので、脱出で 追放すると、つぎの 山札が へる（ライフ −2・−4… が はやく 来る）。「いま 強くするか、山札を のこすか」の 取引になる

## 6. エンジンの しくみ（データ化 2026-10）

| しくみ | どう 作ったか |
|---|---|
| 英雄譚 | `saga([...章])`。出たときと、自分の ターンの はじめ（**手札の 補充の 前**。ケルドの 炎 I で 捨てても すぐ 5まいに もどる）に 伝承カウンターを 1個 足して その章を 起こす。さいごの 章の あと 墓地へ。人が 遊ぶ ときは 章ごとに シートで 見せ、対象が ある 章は えらぶ |
| 消失 | `vanish(n)`。時間カウンター（`p.time`）を 自分の ターンの はじめに 1個 へらし、0で 墓地へ（死亡あつかい。クロノゾア） |
| 宝物 | アーティファクト・トークン。マナを 払う とき さいごに 使う（とっておける）。使うと 墓地へ。金づかいの ドラゴンが いると 2マナ |
| 脱出 | 「ぼち」の 画面から 唱える。墓地の ほかの カードを 古い ものから 追放。脱出で 唱えた ソーサリーは また 墓地に もどる |
| 集会・暴勇 | `coven(s)`（パワーの しゅるいが 3いじょう）・`hellbent(s)`（手札 0まい）。暴勇の 能力が 出ている ときは カードに「ぼうゆう」 |
| 喊声・適応 | 攻撃の 誘発・カウンターの しくみ。カウンターが 置かれたときの 能力は `onCounters` |
| 手札を 捨てる コスト | 起動型は `acts` の `discard`、呪文は `discardCost`。人が 遊ぶ ときは 捨てる カードを えらぶ |
| サイコロ | `rollDie(s)`（シード つき）。人が 遊ぶ ときは 出た目を シートで 見せる |
| X を 2回 払う | `xMul: 2`（歩く バリスタ） |
| 敵との きまり | 追放（W35 I・U37 III）は 各階の `cantLeave`・`untargetable` で ボスの 本体を ふせぐ |
