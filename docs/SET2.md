- 状態：**第1案**（数値はバランス調整前。ルールエンジンに入れてから、シミュレーションで直す）
- ここは案なので、`docs/cards/` には まだ入れていない（`gen_texts.py`・`check_cards.py` は `docs/cards/*.md` を読むため）。決まったら アーキタイプごとのファイルに 移す
- 書き方（ID・コスト・レアリティ・ふりがな）は第1弾と同じ。元のカードは実在の MTG カード（英語名）

## 2. 新しい能力

キーワードは第1弾と同じく **MTG の名前のまま**（REQUIREMENTS 3.2）。長押しの説明文の案も書く。

| キーワード（読み） | 英語 | 説明（長押しで出す文の案） | 意識する数 | カード |
|---|---|---|---|---|
| 英雄譚（えいゆうたん） | Saga | 出たときと、自分のターンのはじめに 伝承（でんしょう）カウンターが 1個 のる。のった 数の 章（I・II・III）が 起きる。さいごの 章の あと 墓地へ | 1・2・3 の じゅんばん、「あと 何ターン？」 | W32・W35・U32・U35・U37・G33・R32・RG03 |
| 集会（しゅうかい） | Coven | 自分の クリーチャーに、パワーが ちがう ものが 3体 いじょう いるなら、効果が 出る | 同じ数・ちがう数を 見分ける（2・2・3 は 2しゅるい） | W29・G27・G34・WG03・WG04 |
| 喊声（かんせい） | Battle cry | これが 攻撃するたび、ほかの 攻撃している クリーチャーは みんな ＋1/＋0 | かけ算（ほかに 3体 なら ＋3） | W27・R27・R33・RW03 |
| 消失（しょうしつ） N | Vanishing | 時間カウンター N個で 出る。自分の ターンの はじめに 1個 へる。さいごの 1個が なくなったら 墓地へ | ひき算・カウントダウン | W28・W33・U33・U34・WU03 |
| 宝物（たからもの） | Treasure | 宝物トークン：「タップ・これを 墓地に 置く：好きな 色の マナを 1つ 出す」。とっておいて あとで 使える | マナの 先読み（いま 使う？ つぎの ターン？） | U27・U31・R30・R36・R37・C13・C14 |
| 適応（てきおう） N | Adapt | ＋1/＋1カウンターが 1つも のっていないなら、N個 置く | 0 の いみ・たし算 | U28・G29・G32・GU03 |
| 脱出（だっしゅつ） | Escape | 墓地から 唱えられる。コストと いっしょに、墓地の ほかの カードを N まい 追放する | 墓地の 枚数を 数える・ひき算 | G28・R28・R29・R34・R35・RG04・GU04 |
| サイコロ（6面） | Roll a die | 1〜6 の サイコロを ふる。「2〜3 なら」のように 出た目で 効果が かわる | 大小比較・はんい（4〜5 は どれ？） | R31・C14 |

- **奇数・偶数** はキーワードにしない。「コストが 奇数の 呪文を 唱えるたび」のように カードの文章に書く（UR03）
- **サイコロ** は MTG では「フォーゴトン・レルム探訪」の 20面（d20）。本作は小学生向けに **6面** にする【提案】
- **脱出** と 山札（やまふだ）の ルール：墓地は 山札が なくなったときに まぜて もどすので、脱出で 追放すると、つぎの 山札が へる（ライフ −2・−4… が はやく 来る）。「いま 強くするか、山札を のこすか」の 取引になる
