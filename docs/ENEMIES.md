# 敵（てき）のデッキ

マスマティック・ザ・ギャザリングの塔の敵。要件は [`REQUIREMENTS.md`](REQUIREMENTS.md) の7章、プレイヤーのカードは [`cards/README.md`](cards/README.md)。

- 状態：**第2案**（シミュレーションで数値を調整ずみ。結果は [`SIMULATION.md`](SIMULATION.md)。データは `mathtcg/js/data/enemies.js`）
- 1・2・4階は MTG の **チャレンジ・デッキ**（テーロス・ブロックの「ハイドラとの対峙」「大群との戦い」「神を討て」）をもとにした。元のデッキは60枚なので、1戦 5〜8分 に収まるよう **20〜24枚** に縮めた
- 元のデッキのカード名を借りている。元のテキストが分かっているカードはそれに合わせ、それ以外は **カード名から作った本作オリジナルの効果**（「元のカード」欄に（名前だけ）と書く）

## 0. 敵の共通ルール

### 0.1 チャレンジ・デッキのルール（全部の階で共通）

| ルール | 内容 |
|---|---|
| マナ | 敵はマナを使わない。敵のカードはすべて無色・コスト0 |
| 先攻 | プレイヤーが先攻。プレイヤーの最初のターンはカードを引かない |
| 敵のターン | ① 敵のパーマネントをアンタップ → ② ライブラリーの一番上から決まった枚数を公開して唱える → ③ 攻撃・ダメージ |
| 英雄（えいゆう）の報酬（ほうしゅう） | 敵のカードの一部は、戦場を離れたとき（墓地に置かれたとき）にプレイヤーにごほうびがある |
| できないこと | 敵にカードを引かせる・捨てさせる効果は何もしない |
| ほかの領域 | 敵のパーマネントが手札・ライブラリーにもどるときは、かわりに敵の墓地に置く |
| ライブラリー切れ | 敵はライブラリーが0枚になっても負けない（大群は勝利条件の一部） |

### 0.2 小学生向けに足したルール

| ルール | 内容 |
|---|---|
| 敵のブロック | 敵のクリーチャーは、ブロックすると **攻撃してきたクリーチャーを倒せる** か **自分が倒されない** ときだけ、1対1でブロックする。頭・神（ゼナゴス・エレボス）はブロックしない。毎ターン攻撃するクリーチャーは自分のターンにタップしているので、ふつうはブロックできない |
| 攻撃先 | プレイヤーは攻撃するクリーチャーごとに、攻撃先を選ぶ（階ごとに選べるものが決まっている）。1つの攻撃先に何体で攻撃してもよい |
| 敵の対象の選び方 | 敵の呪文がプレイヤーのクリーチャーを選ぶときは、テキストに書いてある決まり（「いちばんパワーの大きい」など）で選ぶ。同じなら いちばん左 |
| ブロック | 敵のクリーチャーが攻撃してきたら、プレイヤーは1対1でブロックできる（REQUIREMENTS 2.1） |
| 戦場の上限 | 戦場のクリーチャーは、プレイヤー・敵それぞれ **30体まで**（画面に並べられる数）。こえるトークンは出ない |
| ほっとカード | 敵のデッキには、敵にとって「はずれ」のカード（頭がダメージを与えない、など）が少し入っている。小学生がひと息つけるように |

### 0.3 敵のターンの算数（決定：問題は出さない）

画面の「つぎの 敵」に、敵の 次のターンの 予定を **数を ならべて** 出す（合計は 出さない）。

```
頭が ダメージ（1・1・2）　／　3体で 攻撃（パワー 3・2・4）
```

- 子どもは「ぜんぶで 4点 くる。ライフは 5。ブロックは いらないかな？」と 自分で 足して 考える
- ブロックの きめかたも 数の くらべっこ（「パワー 3 の 敵を、タフネス 4 で うけとめれば 生きのこる」）

### 0.4 むずかしさ【提案】

| むずかしさ | 選び方 | 変わるところ |
|---|---|---|
| かんたん | 1〜2年生のはじめの設定 | 敵の最初の数・公開する枚数が少ない |
| ふつう | 3〜5年生のはじめの設定 | 下の各表の「ふつう」 |
| むずかしい | 一度クリアすると選べる | 敵の最初の数・公開する枚数・ボスのライフが多い。スコア ＋20% |
