# パック＆バトル

ぼうけん（とう）・こうちく・次元渡りとは べつの モード（2026-11-17）。買い切りの デジタルカードゲームの ように、**もんだい → ショップ → デッキ → バトル** を ぐるぐる まわす。

- 状態：**実装ずみ**（`js/ui/packbattle.js`・`js/data/packbattle.js`）。なまえは 仮（`PB_NAME` の 1か所で かえられる）
- エンジン・カード・てき・しゅぎょうの 問題・パックの 演出・デッキの 画面は いまの ものを そのまま つかう。ほかの モードの うごきは かえて いない
- 2026-11-17 に 足した：**きそデッキ**（3章）・**カードは デッキの あいだで わけあえない**（5章）・**ドットの みため**（8章）
- 入口：タイトルの タイル「パック＆バトル」。はじめての 子（証を もらう まえ）は チュートリアルを おえると 出る

## 1. ながれ

| | すること | つかう もの |
|---|---|---|
| ① もんだい | 60びょうの 問題を といて **ポイント（P）** を ためる | しゅぎょう（`js/ui/study.js`・`js/data/quiz.js`）。問題の しゅるいも えらべる |
| ② ショップ | ポイントで パックを あける。出た カードは この モードの もちものに 入る | パックの 演出（`js/ui/gacha.js`）・`openPack`（4まい もって いる カードは 出ない） |
| ③ デッキ | **もって いる カードだけ** で デッキを くむ（いくつも のこせる。バトルには「つかう デッキ」で 出る） | デッキの 画面（`deckBuilder`）。こうちくモードの ノーマルと おなじ きまり |
| ④ バトル | てきを 1体ずつ じゅんばんに たおす。かつと ポイント | たたかいの 画面（`js/ui/battle.js`）・とうの てき。「ぴったり！」も そのまま |

ホームには ポイント・カードの まい数・つかう デッキ（かんせい／まだ）・たおした てきの 数が いつも 出る。はじめから きそデッキが あるので、どこからでも はじめられる。つぎに する ことの ボタンに「つぎは ここ」の しるし（はじめては もんだい → ショップ → デッキ → バトル）。

## 2. ポイント（`PB`：`js/data/packbattle.js`）

| | ポイント |
|---|---|
| はじめに もって いる | **200P**（すぐ パックを 2つ あけられる） |
| もんだい 1もん せいかい | **＋10P**（まちがえても へらない。せいかいの たびに すぐ のこる。とちゅうで やめても もらえる） |
| れんぞく ボーナス | 5もん れんぞくで せいかいする たびに **＋10P** |
| パック 1つ | **100P**（8まい：コモン 4・アンコモン 3・レア 1。レジェンドは ときどき） |
| てきを たおした | **＋50P**（段の さいごの ボスは **＋100P**） |
| ぴったり | 1回ごとに **＋10P**（1回の たたかいで 5回ぶんまで） |
| まけた・やめた | ±0（ポイントと カードは なくならない） |

- きめかた：しゅぎょうは「ごうかく 1回 ＝ パックけん 1まい ＝ パック 1つ」。60びょうで 10もん せいかい ≒ 100P ＝ パック 1つ に あわせた。もんだいは 1日の かぎり なし（いつでも ためなおせる ＝ つまない）
- もんしょうポイント・パックけん・トロフィーは この モードの もんだい・たたかいでは ふえない（あけた パックは ずかんと パックの トロフィーに のる）

## 3. きそデッキ（`PB_STARTER`）

はじめに 1つ もらう、きまった 中身の デッキ。さいしょから バトルに 出られる。**白・緑の コモン 14まい（14点）＋ きほんカード 6まい**（1年生の カードプールから。チュートリアルと おなじ 2色）。

| カード | まい数 | やくわり |
|---|---|---|
| いやしの 鷹（W10） 1/1 飛行・絆魂 | 2 | かるい クリーチャー |
| おともの 騎士（W02） 2/2 先制攻撃・兵士 1体 | 2 | 数を ならべる |
| ニクスの 毛皮の ひつじ（W03） 0/5 防衛 | 1 | まもり |
| 天の 矢（W31） 4点 | 1 | ぴったりで たおす |
| カラメトラの 祝福（W101） ＋2/＋2 | 1 | たし算 |
| 森の ちいさな エルフ（G01） | 2 | マナ |
| 巨大化（G09） ＋4/＋4 | 1 | たし算 |
| ふみならす 大鹿の むれ（G11） 5/5 圧倒 | 2 | 大きい クリーチャー |
| わらの 魔女（C18） 3/1 | 2 | 無色 |

- 中の カードは **もちものに 入る**（もって いる まい数に かぞえる。5章の きまりも おなじ）
- ふつうの デッキと おなじ：なおせる・けせる。つかう デッキを けす ときは「バトルに 出られなく なる」と 出る（ほかに かんせいした デッキが あれば、それが つかう デッキに なる）
- AI の しらべ（100回ずつ）：1〜8たいめに 76〜100% かてる
- まえの 形の セーブ（きそデッキ なし）を ひらくと、いまの デッキは そのままで、きそデッキと その カードが ふえる

## 5. デッキの きまり（こうちくモードの ノーマルと おなじ）

- 20まい（たりない ぶんは きほんカード）・30点・2色まで・同じ カードは 4まいまで
- バトルに 出るには カードが **6まい いじょう**（きほんカードは のぞく。パック 2つで かならず とどく 数）
- **デッキは 5こまで のこせる**。バトルに 出るのは「つかう デッキ」（デッキの いちらんで えらぶ）
- **カードは デッキの あいだで わけあえない**（ほんものの カードと おなじ）：もって いる まい数が 在庫。1つの デッキに 入れた ぶんは、ほかの デッキでは つかえない。
  例：4まい もって いる カードを デッキ A に 3まい 入れると、デッキ B には あと 1まいまで
- デッキを くむ 画面：カードの 下に「**もち 4・ほか 3・あと 1**」（もって いる・ほかの デッキで つかって いる・この デッキに 入れられる）。カードの せつめいにも 同じ 数。
  入れられない ときは「ほかの デッキで 3まい つかって いる（もって いるのは 4まい）」と 出る。ぜんぶ ほかの デッキに 入って いる カードも うすく 見せる
- しくみ：デッキごとに、カードの ならびを「もって いる まい数 − ほかの デッキの まい数」（4まいまで）で つくる（`poolFor`）。ほかで つかって いる カードには「入れられない 1まい」を 足して わけを 出す（`deckBuilder` の `stock`・`phantom`）。たたかう まえにも 数えなおす（`deckInfo`）
- デッキを けすと、入れて いた カードは もちものに もどる
- きまりに あわない ときは「たたかう」が おせず、たりない ことが 出る（「カードが あと 2まい たりない」など。`deckProblems`）

## 7. セーブ

- `localStorage` の `mtg-packbattle-v1`：ポイント・カード（ID ごとの まい数）・デッキ（いくつも）・つかう デッキ・たおした てきの 数・てきを きめる 数・もんだいの きろく
- ぼうけん（`mtg-adventure-v1`）・こうちく（`mtg-collection`）・次元渡り（`mtg-spire-v1`）とは べつ。かわる たびに 自動で のこす（GAS 版の ひきつぎは `mtg-` の キーを まとめて はこぶので、いっしょに うつる）

## 8. みため：ドット（GBA ふう）で そろえる

- この モードに 入ると、せっていの みためが 何でも **ドット（GBA ふう）** に なる（`look`：`data-theme="gba"`）。タイトルに もどると せっていの みために もどる。せっていの 中身（`mtg-theme`）は かえないので、ほかの モードの みためは そのまま
- はんい：ホーム・もんだい・ショップ・パックを あける 画面・デッキの いちらん・デッキを くむ 画面・バトルの 画面と たたかい・まど（シート）
- つかう もの：いまの「ドット」の しくみ（DotGothic16・RPG の まど・ドットの ふち）。この モードの 画面（`.pb`）は 字も ドットの 書体、わくと ボタンは まどの かたち。ホームの 4つの ボタンには ドットの 絵（9×9 の ます）。もんだいの 画面は この モードの あいだだけ ドットの わく・ボタン（`:root.pb-on`。ほかの モードの しゅぎょうは かえない）
- 見やすい「くっきり」が いる 子の ために、ホームの 下の「みため」で せっていの みための ままにも できる（はじめは ドット）
