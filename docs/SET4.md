# 第4弾 カード案「星（ほし）めぐりの 夜（よる）」（120種）

マスマティック・ザ・ギャザリングの第4弾（拡張）の案。第1弾〜第3弾は [`CARDLIST.md`](CARDLIST.md)・[`SET2.md`](SET2.md)・[`SET3.md`](SET3.md)、弾の 一覧は [`ROADMAP.md`](ROADMAP.md)、要件は [`REQUIREMENTS.md`](REQUIREMENTS.md)。

- 状態：**開発中**（2026-10-24 データ化。WEB版の 開発モードで えらぶと パックに 入る。うごきは `js/data/set4.js`、名前・コスト・P/T は この 表から `js/data/skel.js` に 自動で 入る。数値は バランス調整前。ゲームで かんたんに した ところは [`ROADMAP.md`](ROADMAP.md) 6章）
- 第3弾で 黒が 入って **5色** に なった あとの 弾として 書いて いる（黒が 入らない ときは 黒の 12種と 黒の 2色を けずる）
- 書き方（コスト・レアリティ・ふりがな）は 第1弾〜第3弾と 同じ。元のカードは 実在の MTG カード（英語名）。オリジナルの ものは そう 書く

## 2. 新しい 能力

キーワードは MTG の 名前の まま（REQUIREMENTS 3.2）。

| キーワード（読み） | 英語 | 説明（長おしで 出す 文の 案） | 意識する 数 | おもな 色 |

## 8. 作るときの メモ

| もの | すること |
|---|---|
| オーラ | 装備品の「つける」しくみ（`attached`）を つかう。つけた クリーチャーが いなく なったら 墓地へ（授与は クリーチャーに もどる） |
| 授与 | 唱える ときに「クリーチャー」か「オーラ（授与の コスト）」を えらぶ シート。もどる ときは あたらしい クリーチャーとして 出る（召喚酔い あり） |
| 出来事 | 手札の カードに 2つの 名前。出来事で 使ったら `s.P.adventure`（追放）へ。そこからは クリーチャー だけ 唱えられる |
| 星座 | `onOtherEnter` で エンチャントを 見る（第2弾の アルコン W38 と おなじ）。自分が エンチャント・クリーチャーなら 自分が 出たときも |
| 祠 | タイプに `shrine`。X ＝ 自分の 戦場の 祠の 数 |
| 食物 | トークン（第2弾の 宝物と おなじ しくみ）。「2、タップ、墓地に 置く：3点 回復」 |
| コストが 安くなる | 第2弾の `costLess`（ガルタ）を つかう。炎の 宝剣は「攻撃中」に 唱えるので、ブロックの あとの 呪文の 場面で 出せる ように する |
| 瞬速の エンチャント | 前兆は てきの ターンにも 唱えられる（いまは 瞬速の クリーチャーだけ）。はじめは「自分の ターンだけ」でも よい |
| てきが なかまに なる | 歌う セイレーン：てきの パーマネントを 自分の 側へ 移す（`side` を かえる）。授与が はずれたら もとに もどす |
| ふりがな | `node tools/kanji_drafts.mjs` で しらべる |
