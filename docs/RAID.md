# レイドイベント（案）

みんなで 1つの もくひょうに いどむ **期間限定の イベント**。1人 1人の たたかいと しゅぎょうは いつもと 同じで、けっかの 数を サーバー（REQUIREMENTS 11章の GAS）で **たし算** する。弾の 地図は [`ROADMAP.md`](ROADMAP.md) 7章。

- 状態：**案**（2026-10-25）。じゅんばんは ①ボーラス（アモンケット）→ タルキール大戦 → ②ボーラス（灯争大戦）の **3部作**。どれも さいごに ニコル・ボーラスが しゃべって、つぎの イベントに つながる
- **数える もの**は 2つ：**たおした 数**（レイドの てきに かった 回数）と **といた 問題の 数**（しゅぎょうで せいかいした 問題。ぼうけんの まえ・おわりの しゅぎょうも ふくむ）
- 勉強の アプリ なので、**問題を とく ことが そのまま イベントの ちから** に なる（たたかいが にがてな 子も、問題で 参加できる）

レイドは 弾の 発売じゅん（メイン → サブ → メイン → サブ…。[`ROADMAP.md`](ROADMAP.md)）の あいだに はさむ。**すぐ まえの 弾で 手に 入れた カードが、そのまま レイドの てきや 切り札（きりふだ）に なる** ように する。

| 3 | 第3弾「冥界の 門」 | **① 王神の 帰還** | 第3弾の 五神（オケチラ・ケフネト・バントゥ・ハゾレト・ロナス）が てきの ボス。信心・−1/−1カウンターが 有利 |

## 2. ① 王神の 帰還（アモンケット）

### 2.1 ながれ

1. **神々の だんかい**：アモンケットの 5柱の 神と たたかう。毎日 1柱ずつ 入れかわる（1日目 オケチラ → ケフネト → バントゥ → ハゾレト → ロナス）。みんなで **たおした 数** と **といた 問題の 数** を たして、もくひょうに とどいたら つぎへ
2. **王神の だんかい**：ニコル・ボーラスが 出る。ボーラスの ライフは **みんなで 1つ**（たたかいで あたえた ダメージと、といた 問題の 数を ひき算 する）。0に なったら クリア → セリフ

### 2.2 神々（第3弾「門の 五神」の カードと 同じ 神。てきの 階に する）

| 神 | 色 | 階の きまり（案） | 算数 |
|---|---|---|---|
| 団結の神 オケチラ | 白 | てきの クリーチャーが 死ぬと、1/1 の 「永遠（えいえん）の しもべ」が 出る | ふえる 数・へる 数 |
| 知識の神 ケフネト | 青 | てきの 番に「問題」を 出す 呪文を めくる（きみの 手札の 数が 3まい いじょうだと 1まい 引かれる） | 3 いじょう |
| 野心の神 バントゥ | 黒 | てきの クリーチャーが 4体 いじょう 死ぬと 本体に 攻撃 できる | 4つ かぞえる |
| 熱意の神 ハゾレト | 赤 | てきの 手札が 0まいの とき パワー ＋2（暴勇） | 0 |
| 力の神 ロナス | 緑 | てきに パワー 4 いじょうの クリーチャーが いないと 攻撃 できない | 4 いじょう |
| **王神 ニコル・ボーラス** | 青黒赤 | 3だんかい（青：手札を 1まい すてさせる／黒：いちばん つよい クリーチャーを はかい／赤：毎ターン 3点）。ライフは みんなで 1つ | **4けたの ひき算**（10000 − 37 − 52 …） |

### 2.3 数（れい。参加 人数で きめる）

| もくひょう | 数 | 画面 |
|---|---|---|
| 神々を たおす | みんなで 500回 | 「あと 123回」の ぼうグラフ |
| 問題を とく | みんなで 10000問 | 「あと 4321問」 |
| ボーラスの ライフ | 10000 | ダメージ 1点・せいかい 1問で 1 へる |

## 3. タルキール大戦（龍族 vs 人間）

- 状態：**実装ずみ**（2026-10-26。タイトルの「レイド」。`js/ui/raid.js`・`js/ui/raidstore.js`・サーバーは `tools/gas_Code.gs` の `mtgRaid*`）。リアルタイムでは なく、ほかの 陣営の 人の デッキ（ゴースト）を AI が うごかす（オンライン バトルと 同じ）
- 点：かち ＋10・統率者で とどめ ＋5・しゅぎょうで せいかいした 問題 1もん ＋1（レイドに 参加中なら どの しゅぎょうでも）。まけても へらない
- 画面：陣営の ぼうグラフと「人間が 7点 多い（7 − 0 ＝ 7）」・じぶんの 点「3 × 10 ＋ 57 ＋ 1 × 5 ＝ 92点」・5つの 対決（統率者 ごとの 点）
- サーバー：`mtgRaidSubmit`（参加した とき 統率者デッキを ゴーストに。陣営 ごとに 20人まで）・`mtgRaidGhost`（ちがう 陣営から 1人）・`mtgRaidAdd`（点を たす。問題は 1回 200まで）・`mtgRaidState`（陣営と 統率者の 点）。サーバーが ない ときは じぶんの 点だけで、あいては CPU（5つの 対決の あいて）
- 期間：`RAID.ends`（raidstore.js）に おわる 時刻を 入れると、すぎた あとは「たたかう」が おせなく なり、勝った 陣営と ボーラスの セリフが 出る。**1回め：2026年11月1日（日）20時（日本時間）まで**。**WEB版（サーバーなし）は 仮（かり）モード**：期間を 気に せず いつでも あそべる（点は その 端末だけ）

### 3.1 ながれ

1. イベントの はじめに **陣営を えらぶ**（期間中は かえられない）
   - **龍族**：龍王（アタルカ・ドロモカ・オジュタイ・シルムガル・コラガン）の 下で たたかう。デッキに **ドラゴンが 1体 いじょう**
   - **人間**：5つの 氏族（アブザン・ジェスカイ・スゥルタイ・マルドゥ・ティムール）の 旗の 下で たたかう。デッキに **人間が 3体 いじょう**
   - 統率者戦の かたち（3.2）に するなら、この 条件の かわりに **統率者を 1人 えらぶ**
2. あいては **ちがう 陣営の 人の ゴースト**（いなければ 見本の 龍族・人間 デッキ）
3. **陣営の 点 ＝ たおした 数 × 10 ＋ といた 問題の 数**（1日ごとに 画面に 出る）
4. 1週間で 点の 多い 陣営の 勝ち → ボーラスの セリフ（勝った 陣営で かわる）

### 3.2 統率者戦（とうそつしゃせん）の かたち（2026-10-26）

- 状態：**れんしゅうモードを 実装ずみ**（オンライン バトルの 画面の「統率者戦 れんしゅう」。陣営と 統率者を えらんで、ちがう 陣営の CPU と たたかう。`js/ui/commander.js`）。サーバーで 点を あつめる レイド本体は まだ

MTG の **統率者戦（Commander）** を まねる。**陣営を えらぶ ときに、統率者を 1人 えらぶ**。

| 陣営 | えらべる 統率者 | 色 |
|---|---|---|
| 龍族 | 龍王 アタルカ・ドロモカ・コラガン・オジュタイ・シルムガル（RG07・WG07・KR07・WU07・UK07） | 2色 |
| 人間 | 氏族の 長 アナフェンザ・ナーセット・シディシ・ズルゴ・スーラク（AB02・JE02・SU02・MA02・TE02） | 3色（**旗が なくても 3色デッキ**） |

| きまり | 中身 |
|---|---|
| 統率領域（とうそつりょういき） | 統率者は デッキとは 別の 場所に いて、マナが あれば **いつでも 唱えられる**（画面の はしに いつも 見える） |
| 色 | デッキは **統率者の 色だけ**。人間の 長なら 3色、龍王なら 2色 |
| 統率者税（とうそつしゃぜい） | 統率者が 墓地か 追放に いく ときは、かわりに 統率領域に もどせる。**唱える たびに ＋2マナ**（アタルカ 7 → 9 → 11。**2の だん**） |
| 点数 | 統率者は デッキの 点数（キャパシティ）に 数えない |
| ライフ | 30（ふつうは 20） |
| デッキ | 統率者の 色で 20まい（いつもの デッキと 同じ まい数）。れんしゅうでは 第1〜6弾の カードから 自動で 組む（3色の 統率者は 2色を 中心に 3色めを 4まいまで）。レイドでは もって いる カードから |
| マナ | マナゾーンの カードは どれも **統率者の 色の マナ** を 出せる（統率者の 加護） |
| あいて | ちがう 陣営の 人の ゴースト（統率者つき）。ゴーストの AI も 統率者を 唱える |
| 点 | たおした 数 × 10 ＋ といた 問題の 数（3.1 と 同じ）。**統率者で とどめを さすと ＋5** |
| 画面の おまけ | 統率者 ごとの 点も 出す。龍王と 氏族の 長の **5つの 対決**（ドロモカ vs アナフェンザ・オジュタイ vs ナーセット・シルムガル vs シディシ・コラガン vs ズルゴ・アタルカ vs スーラク）で どちらが 多いか |

- 統率者 ごとに 人数が かたよったら、すくない 統率者を えらんだ 人の 点を すこし ふやす（案）
- しくみ（実装）：統率領域 `s.P.cmd`・統率者税 `cmdTax`（`game.js`）。墓地・追放・手札・やまふだに いく ときは 統率領域へ（`leave`）。AI も 統率領域から 唱える（`ai.js` の `main`）。画面は ぼちの となりに「とうそつ」の 札（タップで せつめいと「となえる（7 ＋ 2 ＝ 9マナ）」）
- **バランス**（AI どうし 100戦。龍王 5 × 長 5 × 4戦）：3色の デッキを 3色 そろえて 組むと 龍族 91%（統率者なしでも 86%。3色の デッキが よわい）→ 2色 中心 ＋ 3色め 4まいに して 68% → 人間の ライフ 40 で 59% → 三つの 旗の 版図・収斂を「長の なかま」11種に 入れかえて（[`SET6.md`](SET6.md) 4.5）、**ライフ どちらも 30 で 龍族 47%**（人間 40 だと 41% なので 30 に もどした）。アタルカが つよく（18/20）、ナーセット（2/20）・シルムガル（4/20）が よわい ← つぎの 調整
- まだ：レイドの 点の あつめかた（サーバー）・もって いる カードで 組む デッキ構築・統率者で とどめの ＋5

### 3.3 画面

- 陣営の ぼうグラフ と「龍族 12840点・人間 13020点。人間が 180点 多い」（**大きな 数の ひき算・くらべる**）
- 自分の 点：「きみは 3回 たおして 57問 といた。3 × 10 ＋ 57 ＝ 87点」（**かけ算・たし算**）
- カードは サブセット「三つの 旗」（50種。2026-10-26 に タルキールに よせた：龍王の 一族 10・氏族の 戦士 10。[`SET6.md`](SET6.md)）

## 5. 作る もの

| もの | 中身 | いまの しくみ |
|---|---|---|
| サーバー（GAS） | イベントの 期間・もくひょう・みんなの 合計（たおした 数・問題の 数・陣営ごとの 点）。1人の 1日の 上限（問題 300問 など。ずるを ふせぐ） | ゴースト・点・ランキング（11章）に 足す |
| 画面 | タイトルの「レイド」ボタン → イベントの 画面（もくひょうの ぼうグラフ・のこりの 数・自分の 点）→ たたかう／しゅぎょう する | オンライン バトル・しゅぎょうの 画面 |
| てきの 階 | 神々（5）・王神・配下の プレインズウォーカー（4）・龍神 | 塔の 階と 同じ 書きかた（`js/data/ravnica.js` の `lifeFloor`・セリフ） |
| サーバー なしの とき | 「れんしゅう」：自分 1人で 小さい もくひょう（神々 5回・問題 100問）。オンライン バトルの れんしゅうと 同じ | あり |

- **じゅんばん（おすすめ）**：①の 神々の 階と セリフ（サーバー なしの れんしゅうで 遊べる）→ サーバーの 合計 → タルキール大戦（陣営）→ ②
- ずるを ふせぐ：問題の 数は しゅぎょうの けっか（といた 数・せいかい）を その まま 送る。1日の 上限を こえた ぶんは 数えない
