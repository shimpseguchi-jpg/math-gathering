# レイドイベント（案）

みんなで 1つの もくひょうに いどむ **期間限定の イベント**。1人 1人の たたかいと しゅぎょうは いつもと 同じで、けっかの 数を サーバー（REQUIREMENTS 11章の GAS）で **たし算** する。弾の 地図は [`ROADMAP.md`](ROADMAP.md) 7章。

- 状態：**案**（2026-10-25）。じゅんばんは ①ボーラス（アモンケット）→ タルキール大戦 → ②ボーラス（灯争大戦）の **3部作**。どれも さいごに ニコル・ボーラスが しゃべって、つぎの イベントに つながる
- **数える もの**は 2つ：**たおした 数**（レイドの てきに かった 回数）と **といた 問題の 数**（しゅぎょうで せいかいした 問題。ぼうけんの まえ・おわりの しゅぎょうも ふくむ）
- 勉強の アプリ なので、**問題を とく ことが そのまま イベントの ちから** に なる（たたかいが にがてな 子も、問題で 参加できる）

## 1. 3つの イベント

| | ① 王神（おうしん）の 帰還（きかん） | タルキール大戦 | ② 灯争（とうそう）大戦 |
|---|---|---|---|
| せかい | アモンケット | タルキール | ラヴニカ |
| かたち | **協力**：みんなで 決められた 数を めざす | **対抗**：龍族 か 人間の 陣営に ついて きそう | **協力**：①と 同じ しくみ |
| てき | アモンケットの 5柱（はしら）の 神 ＋ 王神 ニコル・ボーラス | ちがう 陣営の 人の デッキ（ゴースト） | ボーラスの 配下（はいか）の プレインズウォーカー ＋ ニコル・ボーラス |
| もくひょう | 神々を みんなで N回 たおす ＋ 問題を みんなで M問 とく → ボーラスが 出る → ボーラスを たおす | 1週間で 点の 多い 陣営の 勝ち（点 ＝ たおした 数 ＋ といた 問題の 数） | ①と 同じ |
| さいごの セリフ（ボーラス） | 「我（われ）の 計画（けいかく）は これからだ……ふるえて 待つが よい。ははははは……」 | 人間の 勝ち：「龍（りゅう）を たおして くれて、感謝（かんしゃ）しよう。おかげで 我の 力が より 強まった。ははははは……」／龍族の 勝ち：「龍を 育（そだ）てて くれて、感謝しよう。おかげで 我の 力が より 強まった。ははははは……」 | 「どこまで じゃまを すれば 気が すむのか……次は おまえたちから ねらう と しよう」 |

## 2. ① 王神の 帰還（アモンケット）

### 2.1 ながれ

1. **神々の だんかい**：アモンケットの 5柱の 神と たたかう。毎日 1柱ずつ 入れかわる（1日目 オケチラ → ケフネト → バントゥ → ハゾレト → ロナス）。みんなで **たおした 数** と **といた 問題の 数** を たして、もくひょうに とどいたら つぎへ
2. **王神の だんかい**：ニコル・ボーラスが 出る。ボーラスの ライフは **みんなで 1つ**（たたかいで あたえた ダメージと、といた 問題の 数を ひき算 する）。0に なったら クリア → セリフ

### 2.2 神々（第3弾「門の 五神」の カードと 同じ 神。てきの 階に する）

| 神 | 色 | 階の きまり（案） | 算数 |
|---|---|---|---|
| 団結の神 オケチラ | 白 | てきの クリーチャーが 死ぬと、1/1 の 「永遠（えいえん）の しもべ」が 出る | ふえる 数・へる 数 |
| 知識の神 ケフネト | 青 | てきの 番に「問題」を 出す 呪文を めくる（きみの 手札の 数が 3まい いじょうだと 1まい 引かれる） | 3 いじょう |
| 野心の神 バントゥ | 黒 | てきの クリーチャーが 4体 いじょう 死ぬと 本体に 攻撃 できる | 4つ かぞえる |
| 熱意の神 ハゾレト | 赤 | てきの 手札が 0まいの とき パワー ＋2（暴勇） | 0 |
| 力の神 ロナス | 緑 | てきに パワー 4 いじょうの クリーチャーが いないと 攻撃 できない | 4 いじょう |
| **王神 ニコル・ボーラス** | 青黒赤 | 3だんかい（青：手札を 1まい すてさせる／黒：いちばん つよい クリーチャーを はかい／赤：毎ターン 3点）。ライフは みんなで 1つ | **4けたの ひき算**（10000 − 37 − 52 …） |

### 2.3 数（れい。参加 人数で きめる）

| もくひょう | 数 | 画面 |
|---|---|---|
| 神々を たおす | みんなで 500回 | 「あと 123回」の ぼうグラフ |
| 問題を とく | みんなで 10000問 | 「あと 4321問」 |
| ボーラスの ライフ | 10000 | ダメージ 1点・せいかい 1問で 1 へる |

## 3. タルキール大戦（龍族 vs 人間）

### 3.1 ながれ

1. イベントの はじめに **陣営を えらぶ**（期間中は かえられない）
   - **龍族**：龍王（アタルカ・ドロモカ・オジュタイ・シルムガル・コラガン）の 下で たたかう。デッキに **ドラゴンが 1体 いじょう**
   - **人間**：5つの 氏族（アブザン・ジェスカイ・スゥルタイ・マルドゥ・ティムール）の 旗の 下で たたかう。デッキに **人間が 3体 いじょう**
2. あいては **ちがう 陣営の 人の ゴースト**（いなければ 見本の 龍族・人間 デッキ）
3. **陣営の 点 ＝ たおした 数 × 10 ＋ といた 問題の 数**（1日ごとに 画面に 出る）
4. 1週間で 点の 多い 陣営の 勝ち → ボーラスの セリフ（勝った 陣営で かわる）

### 3.2 画面

- 陣営の ぼうグラフ と「龍族 12840点・人間 13020点。人間が 180点 多い」（**大きな 数の ひき算・くらべる**）
- 自分の 点：「きみは 3回 たおして 57問 といた。3 × 10 ＋ 57 ＝ 87点」（**かけ算・たし算**）
- 新しい カードは いらない（第6弾「三つの 旗」が タルキール）

## 4. ② 灯争大戦（ラヴニカ）

①と 同じ しくみ（協力・たおした 数 ＋ といた 問題の 数）。てきは ボーラスの 配下の プレインズウォーカー。

| てき | 色 | 階の きまり（案）。プレインズウォーカーは **ちゅうせい** が ライフ（3.6 の しくみ） |
|---|---|---|
| 永遠衆（えいえんしゅう）の 将軍 リリアナ | 黒 | 毎ターン 2/2 の ゾンビ「永遠衆」を 出す。ちゅうせい 6 |
| 名工（めいこう） テゼレット | 青 | アーティファクトの てきが 2倍 出る。ちゅうせい 5 |
| 法の 魔道士（まどうし） ドビン・バーン | 白青 | きみの カードの コスト ＋1（アゾリウスの 法と 同じ）。ちゅうせい 5 |
| 女王（じょおう） ヴラスカ | 黒緑 | いちばん つよい クリーチャーを 石に する（メドゥーサと 同じ）。ちゅうせい 6 |
| **ニコル・ボーラス**（龍神（りゅうじん）） | 青黒赤 | ①より つよい 3だんかい。ライフは みんなで 1つ |

- ラヴニカの 塔（[`RAVNICA.md`](RAVNICA.md)）と プレインズウォーカーの カード（[`PLANESWALKERS.md`](PLANESWALKERS.md)）を そのまま 使える
- 灯争大戦の 結末（けつまつ）で ボーラスは とじこめられる。セリフ「次は おまえたちから ねらう」で つづきの イベント（エムラクール など）へ

## 5. 作る もの

| もの | 中身 | いまの しくみ |
|---|---|---|
| サーバー（GAS） | イベントの 期間・もくひょう・みんなの 合計（たおした 数・問題の 数・陣営ごとの 点）。1人の 1日の 上限（問題 300問 など。ずるを ふせぐ） | ゴースト・点・ランキング（11章）に 足す |
| 画面 | タイトルの「レイド」ボタン → イベントの 画面（もくひょうの ぼうグラフ・のこりの 数・自分の 点）→ たたかう／しゅぎょう する | オンライン バトル・しゅぎょうの 画面 |
| てきの 階 | 神々（5）・王神・配下の プレインズウォーカー（4）・龍神 | 塔の 階と 同じ 書きかた（`js/data/ravnica.js` の `lifeFloor`・セリフ） |
| サーバー なしの とき | 「れんしゅう」：自分 1人で 小さい もくひょう（神々 5回・問題 100問）。オンライン バトルの れんしゅうと 同じ | あり |

- **じゅんばん（おすすめ）**：①の 神々の 階と セリフ（サーバー なしの れんしゅうで 遊べる）→ サーバーの 合計 → タルキール大戦（陣営）→ ②
- ずるを ふせぐ：問題の 数は しゅぎょうの けっか（といた 数・せいかい）を その まま 送る。1日の 上限を こえた ぶんは 数えない
