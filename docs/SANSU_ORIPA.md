- 土台は パック＆バトル 単体版（[`PACKBATTLE.md`](PACKBATTLE.md)）。学習面は けいさんオリパ、ゲーム面は パック＆バトルの 設計が 正

## 1. ひとまわり

ホーム → **がくしゅう**（たんげんを えらんで 計算。せいかいで コイン）→ **せいちょう**（パックと たんげんを ひらく）→ **ショップ**（ひらいた パックを 100コイン）→ かいふう → **デッキ** → **バトル** → ごほうびで また がくしゅうへ

- ホーム：コインと せいちょうポイントが いつも 見える。入口は がくしゅう・せいちょう・ショップ・デッキ・バトル・もんだい（まえからの 60びょう もんだい）
- **ショップ・デッキ・せいちょうは はじめから あいて いる**（パック＆バトル 単体版は「きそデッキで 1たい たおすと あく」。合体版では がくしゅう → かいほう → 買う の ながれに すぐ 入れる ように、はじめから あけた。2026-11-28 に ユーザーが きめた）
- リアルタイムたいせんの 入口は 出さない（フェーズ 1 の 対象外）

## 2. がくしゅう（けいさんオリパと おなじ きまり）

`js/data/learn.js`（もんだいづくり。けいさんオリパの 出題エンジンを そのまま うつした）・`js/ui/learn.js`（画面と えんしゅつ）

- たんげん 4つ：たしざん（くりあがり）・ひきざん（くりさがり）・まぜまぜ・ぶんしょうもんだい
- 2つの かず：たしざんは ひとけた ＋ ひとけた ＝ 11〜18、ひきざんは 11〜18 − ひとけた ＝ 2〜9。同じ もんだいは つづけない
- 3つの かず（a＋b＋c・a＋b−c・a−b＋c・a−b−c。左から じゅんに）：とちゅうも さいごも 0〜18、マイナス なし。25% で まざる
  - 式の もんだい：その たんげんの **4もんめ から**。たしざんは ＋＋ だけ、ひきざんは −− だけ、まぜまぜは 4つ とも
  - 文しょう題：その たんげんで **5もん せいかい してから**
  - この 数えかたは たんげんに **入る たびに 0 から**（けいさんオリパと おなじ。セーブしない。2026-11-28 に ユーザーが きめた）
- 文しょう題：① ことばを みつける → ② たす？ ひく？ → ③ けいさん。3つの かずは ② を 2回（1つめ・2つめ）
- ヒント：1回 まちがえると 出る（10の まとまり。3つの かずは とちゅうの 計算も）
- パス：**はんいの そとの もんだい（スーパーフィーバー中の 2けた・3けた・九九）で 2回 まちがえた とき だけ**。ふつうの もんだいには 出ない（けいさんオリパの いまの コードと おなじ。2026-11-28 に ユーザーが きめた）
- フィーバー：5もん れんぞくで コイン 2ばい、10もん れんぞくで 3ばい。ばいりつは かさねず、いちばん 大きい もの だけ（ラッキー 3ばい・ゾロめ 3ばい・はんいの そと 4〜10ばい も おなじ）
- ラッキーもんだい（12%）・ゾロめ（7＋7 など）：コイン 3ばい
- スーパーフィーバー：5もん れんぞくで「はいる？／はいらない」を **1回 だけ** きく（同じ フィーバーの あいだは もう きかない。式の たんげん だけ）。入った とき だけ、30% で はんいの そとが まざる
  - 2けた＋1けた 4ばい（40%）・2けた＋2けた 6ばい（30%）・九九 10ばい（20%）・3けた 10ばい（10%）
  - **3けたは 20もん れんぞく いじょうの とき だけ**（それまでは ほかの 3つに ふりわける）
  - おわり：まちがえる・パスする・「ふつうに もどる」
- れんぞく せいかいは たんげんを またいで つづく（セーブにも のこる）。まちがえる・パスすると 0

### かえた ところ（見た目 だけ）

- 画面：けいさんオリパは 横長の 1画面（1024×640）。合体版は パック＆バトルと おなじ たて長・ドットの わく。式と 文は 大きい 字（式 40〜84px、文 19〜26px）

## 3. コインと せいちょうポイント

- **コイン**（セーブの `pts`。パック＆バトルの ポイントと 同じ もの）：がくしゅう・バトル・もんだいで ふえて、パックで へる
  - がくしゅう：式の せいかい 10 × ばいりつ。文しょう題は ①②が 10ずつ（**ばいりつは かけない**）、③ が 10 × ばいりつ（けいさんオリパの いまの コードと おなじ。2026-11-28 に ユーザーが きめた）
  - バトル：かち 50・ボス 100・ぴったり ＋10（5回まで）。もんだい：1もん 10・5もん れんぞくごとに ＋10。パック 100。はじめ 200（パック＆バトルの 数の まま）
  - がくしゅうでは「5もんごとに ＋10」は つかわない（フィーバーの ばいりつ）。まえからの「もんだい」は いままでの きまりの まま
- 画面の ことば：合体版では「ポイント」「P」を「コイン」と 出す（`packbattle.js` の `c()`。「せいちょうポイント」は そのまま）
- **せいちょうポイント**（`gp`）：バトル（かち ＋1・ステージ クリア ＋3）と、がくしゅうの ごほうび（それぞれ 1回 だけ）
  - たんげんの 初クリア ＋3（その たんげんで あわせて 10もん せいかい。4つ）
  - 3つの かずの 初かいほう ＋2（たんげんごと。3つの かずが まざる じょうけんを はじめて みたした とき。4つ）
  - スーパーフィーバー 初とつにゅう ＋2・20もん れんぞくの 初たっせい ＋3
  - あわせて さいだい 25

## 6. えんしゅつ

- えんしゅつの そう（`#lfx`）は いつも いちばん 手前（さわれない）
- せいかい（れんぞくの 数で）：1〜2 小さい 表示「できた！」／3〜4 まんなかに 大きい 字（0.85びょう。ナイス！・いいね！）／5〜7 大きい 字 ＋ ほし・かみふぶき・ひかりの すじ（フィーバー！！・すごい！！）／8〜 と スーパーフィーバー中 とくだいの にじいろの 字 ＋ 画面 ぜんたいの ひかり（すごすぎる！！！・さいこう！！！！・でんせつ！！！！！）
- スーパーフィーバーの 入口：えらぶ 画面は おちついた まど（うごく えんしゅつ なし）。「はいる」の すぐ あと、あんてん → ひかりの すじ → とくだいの 字（やく 1.5びょう）
- ゆれは さいだい 3ピクセル・0.25びょう。まちがえた ときは 小さく やさしい 表示 だけ（大きい 字・ゆれ・かみふぶき なし）
- パックの かいふうと バトルの えんしゅつは いままでの まま（ぜんめんてきに そろえるのは フェーズ 2）
