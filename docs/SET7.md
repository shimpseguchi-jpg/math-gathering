# 第7弾 カード案「ラヴニカ：ギルドの 都（みやこ）」（50種）

マスマティック・ザ・ギャザリングの第7弾（拡張）。**10の ギルド** の 弾。塔の 敵（[`RAVNICA.md`](RAVNICA.md)）と 同じ ギルドの リーダーが カードに なる。弾の 一覧は [`ROADMAP.md`](ROADMAP.md)。

- 状態：**開発中**（2026-10-24 データ化。WEB版の 開発モードで えらぶと パックに 入る。うごきは `js/data/set9.js`、名前・コスト・P/T は この 表から `js/data/skel.js` に 自動で 入る）
- 5色（第3弾で 黒が 入った あと）として 書いて いる。2色の 組み合わせ **10**（ギルド）を 5まいずつ
- 書き方は 第1弾〜第6弾と 同じ。元のカードは 実在の MTG カード（英語名）。ゲームで かんたんに した ところは テキストに そのまま 書く
- **ニコル・ボーラス** は この 弾に 入れない（いつかの レイドバトルの ボス。RAVNICA.md 6章）

## 2. 新しい 能力

| キーワード（読み） | 英語 | 説明（長おしで 出す 文の 案） | 意識する 数 | ギルド |
|---|---|---|---|---|
| 居住（きょじゅう） | Populate | あなたの トークン 1体を えらび、それと 同じ トークンを 1体 出す（いちばん つよい ものを えらぶ と よい） | **同じ ものを ふやす** | セレズニア |
| 留置（りゅうち） | Detain | 敵（てき）の クリーチャー1体を タップし、それは つぎの 敵の ターンに アンタップしない（攻撃も ブロックも できない） | − | アゾリウス |
| 絢爛（けんらん） | Spectacle | この ターンに 敵（てき）が ダメージを うけて いれば、書いて ある 数だけ 安く 唱（とな）えられる | **ひき算**（5 − 2 ＝ 3マナ） | ラクドス |
| 暴動（ぼうどう） | Riot | 出る とき、**速攻** か **＋1/＋1カウンター1個** の どちらかを えらぶ | **くらべる**（いま 攻撃 する？ あとで 大きく？） | グルール |
| 諜報（ちょうほう） | Surveil | ライブラリーの 上から N枚を 見て、1枚ずつ「上に のこす」か「墓地（ぼち）へ」を えらぶ | − | ディミーア |
| 宿根（しゅっこん） | Undergrowth | あなたの 墓地（ぼち）の **クリーチャー・カードの 数** を 使う | **数える** | ゴルガリ |

- 前の 弾に ある 能力も 使う：大隊（第1弾）・召集（第1弾）・進化（第1弾）・適応（第2弾）・強請（第3弾）・来世（第3弾）
- MTG の 暴動は「出る とき えらぶ」。この ゲームでは **出す 前に** 画面で えらぶ（AI は 攻撃 できる ときは 速攻）

## 6. 作るときの メモ

- 印鑑は 第6弾の 旗と 同じ しくみ（タップで マナ）。点数は ふつうの コモン。この ゲームは どの カードも マナに できるので、マナを 出す だけ だと 弱い（デッキの 1まいを つかう だけ）。出たとき 1まい 引く ように した（7章）
- 居住：あなたの トークンの うち いちばん パワーの 大きい もの（同じなら タフネス）の コピー。トークンが なければ なにも しない
- 留置：第1弾の「こおりつかせる」と 同じ（タップ ＋ つぎの アンタップを しない）
- 絢爛：エンジンの「この ターンに 敵が うけた ダメージ」（第3弾の ラクドスと 同じ）を 使う
- 暴動：人が 出す ときは 画面で「速攻／＋1/＋1カウンター」を えらぶ。AI は そのターンに 攻撃 できる ときは 速攻
- 諜報：人は 画面で 1枚ずつ（占術と 同じ 画面で「ぼちへ」）。AI は 占術と 同じ きじゅんで のこす
- ジャラドと 宿根は 墓地の クリーチャー・カードを 数える（第3弾の 昂揚と 同じ 道具）

`SETS=1,2,9 node mathtcg/tools/sim.mjs runs` のように 弾を えらんで しらべる（9 が この 弾）。

|---|---|
| 第1弾＋第2弾 | 61% |
| 第1弾＋第2弾＋**ラヴニカ** | 48%（印鑑が マナを 出す だけ の ときは 45%） |
| 第1弾〜第3弾 | 45% |
| 第1弾〜第3弾＋**ラヴニカ** | 38% |
| 開発中の 弾 ぜんぶ（ラヴニカ なし → あり） | 38% → 35% |

- 下がるのは、パックが 10の ギルドに **ばらける** から（黒が 入った 第3弾と 同じ）。デッキに ラヴニカの カードが 2まい でも 4まい いじょう でも クリアは 47〜48% で、カードが 弱い わけでは ない
- デッキに 入りやすいのは 印鑑（どの デッキにも 入る）。勝ちに つながるのは 稲妻の らせん・軍勢の 戦親分・ボロスの 精鋭（ボロス）、弱いのは シミック（もともと 青緑は いちばん 弱い 2色）
- バランス調整は まだ（ほかの 開発中の 弾と 同じ）
