# ラヴニカの 塔

2つめの せかい（プレーン）。タイトルの「せかい」で **テーロス** か **ラヴニカ** を えらんで ぼうけんを はじめる。要件は [`REQUIREMENTS.md`](REQUIREMENTS.md) 7.4。

- 状態：**実装ずみ**（2026-10-24。塔だけ。ラヴニカの カード（パック）は これから）
- うごき：`js/data/ravnica.js`（階の きまり・てきの デッキ・セリフ）
- 1〜4階は **10の ギルドの リーダー**、5階（頂上）は **ギルドパクトの ジェイス**
- **ニコル・ボーラスは とっておく**。いつか みんなで たおす **レイドバトル** の ボスに する（8章）

## 1. 階の くみあわせ（ぼうけんの はじめに ランダム）

| 階 | 出る ギルド（ランダム） |
|---|---|
| 1階 | ボロス（アウレリア） ／ セレズニア（トロスターニ） ／ シミック（ヴォレル） |
| 2階 | イゼット（ニヴ＝ミゼット） ／ ゴルガリ（ジャラド） ／ アゾリウス（イスペリア） |
| 3階 | ラクドス（ラクドス） ／ オルゾフ（テイサ） |
| 4階 | グルール（ボルボルグミ） ／ ディミーア（ラザーヴ） |
| 5階 | ギルドパクトの ジェイス |

- 1〜3階と ジェイスは **リーダーに ライフが ある**（メドゥーサと 同じ）。クリーチャーで リーダーを こうげきしたり、じゅもんで ダメージを あたえたり して ライフを 0に する
- 4階の 2人は **クリーチャー**。たおすと かち
- てきは テーロスの 塔と 同じく マナを 使わず、毎ターン やまふだの 上を めくって 使う（7.1）

## 2. 階ごとの きまり

ライフは かんたん／ふつう／むずかしい。

| ギルド | リーダー | ライフ | きまり（ギルドの メカニズム） | 算数 |
|---|---|---|---|---|
| ボロス | アウレリア | 9／11／14 | てきが **3体 いじょう** で こうげき すると、ぜんぶ パワー ＋1（大隊） | 3 いじょうを かぞえる |
| セレズニア | トロスターニ | 8／10／13 | てきの ターンの はじめに 苗木（1/1）が 1体 ふえて、苗木の かずだけ ライフが ふえる（3まで。居住） | ふえる 数と へらす 数の くらべっこ |
| シミック | ヴォレル | 7／9／12 | てきの ターンの はじめに、てきの ＋1/＋1カウンターが **2ばい**（なければ 1こ。8まで。進化） | 2ばい（1→2→4→8） |
| イゼット | ニヴ＝ミゼット | 13／16／20 | てきが じゅもんを めくる たびに きみに 1点。めくる まいすうは 1／1.5／2（1まい・2まいを かわりばんこ） | なんまい めくるか |
| ゴルガリ | ジャラド | 11／13／17 | てきの クリーチャーが しぬ たびに ジャラドの ライフ ＋1（活用） | ひき算と たし算の さしひき |
| アゾリウス | イスペリア | 10／12／15 | きみの カードは **コスト ＋1**（きほんカードは そのまま。留置） | コストの たし算 |
| ラクドス | ラクドス | 12／15／19 | 2ターンめ から、きみの ターンに てきへの ダメージが **3点より すくない** と、つぎの てきの ターンに 2点（ブーイング。暴勇） | 3 いじょうに する |
| オルゾフ | テイサ | 11／14／18 | てきが じゅもんを めくる たびに きみ −1・テイサ ＋1（強請）。めくる まいすうは 1／1.5／2 | 1点の いったり きたり |
| グルール | ボルボルグミ | 3/5／3/5／4/7（トランプル） | ダメージは ターンの おわりに なくなる。**1ターンで タフネス ぶん** あてる | たし算で タフネスに とどかせる |
| ディミーア | ラザーヴ | 3/3 いじょう | いつも きみの いちばん パワーの 大きい クリーチャーと **おなじ P/T**。1かいめは にせもの（2かい たおす） | おなじ 数・くらべる |

## 3. 5階：ギルドパクトの ジェイス（3だんかい）

ライフ 30／38／45。ライフが 3分の2・3分の1 を きると つぎの だんかいへ（場は そのまま）。

| だんかい | きまり |
|---|---|
| 1 | きみの カードは コスト ＋1（アゾリウス） |
| 2 | 毎ターン ギルドの まもり手（3/3。10ギルドの どれか）が 出る |
| 3 | 毎ターン きみの いちばん つよい クリーチャーを てふだに もどして、きみに 2／3／3点（ディミーアと イゼット） |

## 4. セリフ（バトルの すすみぐあい）

てきの ふきだしが **画面の 上**（かちかた の 下）に 出る。かわる ときは ログにも 出る。おなじ セリフは 1かい だけ。

| いつ | れい（アウレリア） |
|---|---|
| はじめ | ボロスの 軍よ、すすめ！ 3体 そろえば もっと つよいぞ |
| リーダーの ライフが はんぶん（4階は はじめて ダメージを うけた とき） | くっ、なかなかの こうげきだ！ |
| ライフが 4分の1 | ボロスは さいごまで たたかう！ |
| きみの ライフが 5 いか | もう ひと おし だ！ |
| かった とき（けっかの 画面） | みごとだ。きみの ゆうきを みとめよう |
| まけた とき（けっかの 画面） | まだまだ くんれんが たりないぞ！ |

- ジェイスは だんかいが かわる とき・ライフ 6分の1・きみの ピンチ・かち／まけ で しゃべる
- ディミーアは にせものが たおれた とき「それは にせものさ。ほんものの わたしは ここだ」

## 5. シミュレーション（ふつう・見本 デッキ／ぼうけん 400回）

`PLANE=ravnica node mathtcg/tools/sim.mjs runs`（`fights` で 階ごと）。

| | テーロス | ラヴニカ |
|---|---|---|
| ぼうけんの クリア | 61% | 66% |
| ボス（勝率・コンティニューこみ） | エレボス 62% | ジェイス 76% |
| 1〜4階 | 75〜93% | 74〜93% |

- 2つめの せかいなので、テーロスより 少し やさしく した。いちばん むずかしいのは グルール（74%）と シミック（76%）
- ライフを ふやしても あまり かわらない（AI は 1ターンに たくさん あてる）。むずかしさは「めくる まいすう」と てきの デッキで きめた

## 6. これから

- **ラヴニカの パック**（ギルドの カード。10の 2色の くみあわせ・ギルドの メカニズム）
- **ニコル・ボーラスの レイドバトル**：みんなの ダメージを あわせて たおす 大きな ボス（オンライン。11章の しくみを 使う）
- テーロスの 塔と ラヴニカの 塔を どちらも クリアした ときの トロフィー
