# 番外編（ばんがいへん）パック 案：FGO・スターレイル・ゼンゼロ

MTG の「ユニバース・ビヨンド」（ほかの 作品との コラボ）の ように、ゲームの せかいを カードに した **番外編** の パック。3つ（各 20種）。弾の 一覧は [`ROADMAP.md`](ROADMAP.md)。

- 状態：**FGO は 開発中**（2026-10-25 データ化・40種。開発モードの せっていで えらぶと FGO だけの パック）。スターレイル・ゼンゼロは **案**（カードの 表まで）
- 書き方は 第3弾〜第7弾と 同じ（この 表から `js/data/skel.js` に 名前・コスト・P/T が 入る ように して ある）。「元のカード」の 列は **元に した キャラクター・もの**
- 色は MTG の 5色に あてはめた。どの パックも 5色 ぜんぶ ある ので、いつもの パックと まぜても 2色の デッキが くめる
- **だいじ**：どれも ほかの 会社の 作品（Fate/Grand Order：TYPE-MOON・アニプレックス・ディライトワークス、崩壊：スターレイル と ゼンレスゾーンゼロ：HoYoverse）。家の 中の 試作・開発モードで 遊ぶ ぶんには よいが、**公開・配布する ときは 権利者の 許可が いる**（MTG の カードを 元に して いる 本体も 同じ）。絵は 使わない（カードは 文字と 色だけ）
