# 番外編（ばんがいへん）パック 案：FGO・スターレイル・ゼンゼロ

MTG の「ユニバース・ビヨンド」（ほかの 作品との コラボ）の ように、ゲームの せかいを カードに した **番外編** の パック。3つ（各 20種）。弾の 一覧は [`ROADMAP.md`](ROADMAP.md)。

- 状態：**FGO・スターレイル・ゼンゼロは 開発中**（2026-10-25 データ化。FGO 70種・スターレイル 80種・ゼンゼロ 80種。もんしょう「番外編」で いつもの パックに まざる）。ゼンゼロも データ化ずみ（80種）
- 書き方は 第3弾〜第7弾と 同じ（この 表から `js/data/skel.js` に 名前・コスト・P/T が 入る ように して ある）。「元のカード」の 列は **元に した キャラクター・もの**
- 色は MTG の 5色に あてはめた。どの パックも 5色 ぜんぶ ある ので、いつもの パックと まぜても 2色の デッキが くめる
- **だいじ**：どれも ほかの 会社の 作品（Fate/Grand Order：TYPE-MOON・アニプレックス・ディライトワークス、崩壊：スターレイル と ゼンレスゾーンゼロ：HoYoverse）。家の 中の 試作・開発モードで 遊ぶ ぶんには よいが、**公開・配布する ときは 権利者の 許可が いる**（MTG の カードを 元に して いる 本体も 同じ）。絵は 使わない（カードは 文字と 色だけ）

## 2. Fate/Grand Order「英霊召喚」（70種・データ化ずみ）

クラスは サブタイプ（セイバー・アーチャー・ランサー・ライダー・キャスター・アサシン・バーサーカー・ルーラー・シールダー・アヴェンジャー）。サーヴァントは みんな「サーヴァント」。

- 状態：**開発中**（2026-10-25 データ化。うごきは `js/data/set10.js`）。**もんしょう「番外編 Fate/Grand Order」（パックの もんしょう・1ポイント）** を つけると、いつもの パックに FGO の カードが **まざる**（せっていの「しゅうろくする 弾」では えらばない）。さいしょは「FGO だけの パック」に したが、デッキの はばが せまいので まぜる 形に した
- 20種では コモンが 2種しか なく パックが かたよるので **40種** に、まぜると シナジーが できにくいので さらに **70種**（コモン 32・アンコモン 18・レア 12・レジェンド 8。各色 6種 ＋ NP を ためる コモン）に した（FG21〜FG70）
- NP は 1回の 攻撃で **40 いじょう**（2026-10-25 に 30 の ものを 40 に。30 だと 4回 攻撃が いって、たたかいが おわるまでに ほぼ 出なかった）。イスカンダルは 出たとき NP ＋20 で、2回の 攻撃で 宝具。NP は 場（ば）を はなれると 0 に もどる
- 宝具は **じぶんで つかう**（2026-10-25 に 自動から かえた）：NP が 100 いじょう あれば、じぶんの **メインフェイズ**（ソーサリーと 同じ タイミング）に サーヴァントを タップして「ほうぐ（NP − 100）」。NP は **300 まで** ためられる（100 を こえても のこる。3回 れんぞくで つかう ことも できる）。あいては 自動で えらぶ（いちばん たおしやすい てき）。カードに「NP 40・あと2回」、100 いじょうで「NP 120・ほうぐOK」（赤く ひかる）。タップすると「120 − 100 ＝ 20」の ように ひき算が 出る。AI と てきがわの サーヴァントは たまったら すぐ つかう
- もんしょうで まぜた ときの 出やすさ：FGO の カードは **3ばい**（第1弾＋第2弾に まぜると 1パックの はんぶん くらい、4.2まい。70種に ふやした ので いろいろな サーヴァントが 出る）
- シミュレーション（ふつう・冒険 300回・70種）：まぜると 第1弾＋第2弾 63% → 52%（FGO に 黒が ある ため）、第1弾＋第2弾＋ラヴニカ 50% → 46%。FGO だけの パックは 40種の とき 35% → 70種で 42% → NP 30 を 40 に して 45%。つよく する もんしょう では なく **カードの しゅるいを ふやす** もんしょう なので 1ポイント
- シミュレーション（ふつう・冒険 200回、FGO だけの パック）：クリア **35%**（小さい 弾 だけの パックは 第6弾 20%・アルケミー 20% くらい）。AI は 20戦で 宝具を 47回 使った。`SETS=10 node mathtcg/tools/sim.mjs runs`

### 4.3 シミュレーション

- ふつう・冒険 200回：ゼンゼロ だけの パック **44%**（FGO だけ 45%）。もんしょうで 第1弾＋第2弾に まぜると **57%**（まぜない とき 63%）
- さいしょは だけ 20%・まぜて 40% だった。**装備品が 8まい** あって、AI の デッキが 装備品で うまり クリーチャーが へっていた → 装備品は 3まいに して、5まいを トークンを 出す 呪文などに かえた（32%）。さらに デッキを くむ AI が 装備品を すこし ひくく 見る ように した（`run.js` の `cardValue`。スターレイル だけも 56% → 65%、ふつうの パックは 63% の まま）
- AI は 24戦で エネルギーを 50回 くらい つかい、交代（忍術）を 13回 した
- 交代を ブロックでも、終結スキルを タップした 敵で 安く した あと（2026-10-25）：ゼンゼロ だけ 44% → **49%**、まぜて **58%**。AI は ブロックした ものが たおれる とき、たおれない か あいてを たおせる エージェントと 交代する
