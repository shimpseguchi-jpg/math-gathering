# シミュレーション（バランス調整）

マスマティック・ザ・ギャザリングのルールをプログラムにして、AI に何千回も遊ばせて敵の強さを調整した記録。

- ルールエンジン：`mathtcg/js/engine/game.js`（画面と分離。本番の画面からもそのまま使う予定）
- AI：`mathtcg/js/engine/ai.js`（プレイヤー側）、敵は各階のルールどおりに自動で動く（`mathtcg/js/data/enemies.js`）
- カードのデータ：`mathtcg/js/data/cards.js`（第1弾 126種＋第2弾 62種＋きほんカード5種）
- 冒険の流れ（パック・デッキ構築・5階）：`mathtcg/js/engine/run.js`

## 動かし方

```sh
node mathtcg/tools/sim.mjs runs      # パックからの冒険を N回（クリア率・階ごとの勝率）
node mathtcg/tools/sim.mjs floors    # 各階を、その階で組めるデッキ（1階は3パック〜ボスは7パック）で N回
node mathtcg/tools/sim.mjs fights    # 各アーキタイプの見本デッキ × 各階
node mathtcg/tools/sim.mjs log RG hydra   # 1戦のログ
# 環境変数：N（回数）DIFF（easy/normal/hard）RESHUFFLE（0 で山札切れ負け）SEED FLOOR
```

1000回の冒険が数十秒で終わる。

## AI のしくみ（かんたんに）

| 場面 | やること |
|---|---|
| マナチャージ | きほんカード → 足りない色のカード → 当分使えない重いカード の順にマナゾーンへ |
| 唱える | 唱えられるカードのうち、いちばん点の高いもの（クリーチャーは重いほど高い、除去は倒せる敵が強いほど高い）から順に |
| 召集 | 戦闘の前は「出たばかりで攻撃できないクリーチャー」だけで払い、戦闘のあとは残りのクリーチャーも使う |
| 攻撃 | 倒せる敵から順に、ちょうど足りるクリーチャーを当てる。ブロックされて負けるだけの攻撃はやめる。工場は「ちょうど鍵の数」になる組み合わせをさがす |
| 戦闘中の呪文 | ブロックが決まったあと、強化の呪文で倒せる数・本体へのダメージがふえるなら使う |
| ブロック | 生き残れるか、相手を倒せるならブロック。死にそうなら身代わりにする |
| 数を決める能力 | X は「倒せるいちばん小さい数」（ぴったりになりやすい）。激励・増呪・キッカーは、払えるだけ対象やモードをふやす。待機はマナが足りないときに使う。Lvアップはマナが余ったら |
| デッキ構築 | 2色の組み合わせ6通りそれぞれで、キャパシティ30点・20枚の中で価値の合計がいちばん大きくなるように選ぶ（ナップサック） |

AI は小学生よりうまいところ（計算をまちがえない）も、へたなところ（先の読みが浅い）もある。数値は「AI がこのくらい勝つなら、こどもにはちょうどよい」の目安。

## 調整の結果（ふつう）

2026-10：けいさんボーナスを やめて（算数は遊びの中で自然に）、数を意識する能力（圧倒・激励・鼓舞・集団戦術・教導・訓練・キッカー・増呪・待機・Lvアップ・ぴったり）を入れたので、調整しなおした。
さらに **手札の補充（毎ターン 5枚まで引く。ラッシュデュエル式）** にしたので、敵を強くして もういちど 調整した（下の「手札の補充」）。
さらに **山札を まぜて もどす たびに ライフ −2・−4・−6…** に したので、敵を すこし やさしくした（下の「山札を もどす コスト」）。
いまの 数字は **第2弾（62種）を パックに まぜた あと**（下の「第2弾を まぜた」）。

### 冒険のクリア率（1000回ずつ）

| むずかしさ | クリア率 | 目標 |
|---|---|---|
| かんたん | **80%** | 75〜85% |
| ふつう | **58%** | 50〜70% |
| むずかしい | **20%** | 20〜30% |

けいさんボーナスを やめた直後は ふつう 45%（ボーナスで 毎ターンの ダメージが 1 へっていたぶん）。エレボスを少しやさしくし、弱い色を少し強くして もどした（下の「2026-10 の調整」）。

### 各階：その階で組めるデッキで、1回目で勝つ率（1000回ずつ）

| 階 | デッキ | 勝つ率 | 勝ったときの平均ターン | 目標 |
|---|---|---|---|---|
| 1 ハイドラ | 3パック | 87% | 6.2 | 85% |
| 2 大群 | 4パック | 88% | 7.3 | 85% |
| 3A ゴーレム工場 | 5パック | 89% | 6.7 | 75〜80% |
| 3B ふえるスライム | 5パック | 72% | 7.8 | 75〜80% |
| 4 ゼナゴス | 6パック | 81% | 8.3 | 70% |
| 5 エレボス | 7パック | 59% | 9.2 | 60〜65% |

上の階ほど少しずつむずかしく、ボスがいちばんむずかしい。コンティニュー1回をふくめると、ふつうで約半分がクリアできる。

### アーキタイプ（ふつう・パックから組んだ最後のデッキ）

| 2色 | えらばれた回数（1000回中） | クリア率 |
|---|---|---|
| 赤白 | 149 | 81% |
| 緑赤 | 108 | 69% |
| 青白 | 239 | 62% |
| 白緑 | 181 | 61% |
| 赤青 | 142 | 51% |
| 青緑 | 181 | 29% |

青緑が いちばん弱い（29%）。AI のデッキ構築は「2色のカードの点が高い」ので、青緑は ジモーネ（2色アンコモン）があるだけで 青と緑の ばらばらな カードの デッキに なりやすい。人が組めば もう少し強くなる はず。

### 手札の補充（2026-10）

初手5枚・毎ターン1枚引く だと、手札が すぐ なくなる。初手7枚と、毎ターン5枚まで補充（遊戯王ラッシュデュエル式）を くらべて、**補充** に した（決定）。

| ルール | ふつうの クリア率（敵は そのまま） | 山札切れ |
|---|---|---|
| 初手5枚・毎ターン1枚 | 56% | 20% |
| 初手7枚・毎ターン1枚 | 86% | 20% |
| **毎ターン5枚まで補充** | 91% | 40% |

補充で とても かんたんに なったので、敵を 強くした：

| 階 | 前 | 後 |
|---|---|---|
| ハイドラ | 頭 かんたん1・ふつう2・むずかしい2本、新生で 1・1・2枚 | 頭 **2・2・3本**、新生で **2枚** |
| 大群 | 追加ターン 2回 | **1回** |
| ゴーレム工場 | 鍵 4・6・7、ゴーレム 1/1 を2体まで | 鍵 **5・7・8**、ゴーレム ふつう・むずかしいは **2/2**（むずかしいは 3体まで） |
| スライム | 3/3・4/4・5/5 | **5/5・6/6・8/8** |
| ゼナゴス | 群れ 1・2・3体 | **3・3・5体** |
| エレボス 段階3 | ライフ 15・26・35、毎ターン 2・2・3点 | ライフ **30・44・52**、毎ターン **2・3・3点** |

山札切れ（墓地を まぜて もどす）は 多く なる（ボス戦の 8割）。画面では 山札が 5枚より 少ないと「やまふだ」に 小さく「もうすぐ なくなる（まぜると ライフ −2）」と 出す。

### 山札を もどす コスト（2026-10）

ライブラリーアウトの 緊張感は ほしいが、20枚デッキで「引けなければ 負け」は きびしすぎる（補充ルールでは ふつうの クリア率 1%）。そこで **墓地を まぜて もどす たびに ライフを 2・4・6…（2の倍数ずつ）失う** ことに した（決定）。2回 もどすと 合計 6、3回で 12。長い 戦いほど 早く 決着を つけたく なる。

コストを 入れて ボス戦が むずかしく なったので、敵を すこし もどした：

| 階 | 前 | 後 |
|---|---|---|
| ハイドラ | 新生で 2枚 | 新生で **1・1・2枚** |
| 大群 | 追加ターン 1回 | かんたんは **2回** |
| ゴーレム工場 | 鍵 5・7・8、ゴーレム ふつうも 2/2 | 鍵 **5・6・8**、ゴーレム ふつうは **1/1**（2/2 は むずかしいだけ）、かんたんは 2体まで・ほかは 3体まで |
| スライム | 5/5・6/6・8/8 | **4/4・6/6・7/7** |
| ゼナゴス | 群れ 3・3・5体 | **2・2・3体** |
| エレボス 段階3 | ライフ 30・44・52、毎ターン 2・3・3点 | ライフ **16・24・32**、毎ターン **2・2・3点** |

### 決着までの ターン数と 怪物化（2026-10）

緑赤の 見本デッキで 塔の 各階を 200回ずつ（`怪物化` の しらべ）。

- 決着は **平均 6.8 ターン**（中央 7）。8割が 4〜8 ターンめ。おわる ときの マナは 平均 6
- 階ごと：ハイドラ 5.8・大群 6.0・工場 6.6・スライム 6.8・ゼナゴス 7.2・エレボス 8.3・オンライン 6.8

怪物化は「出す 5マナ ＋ 怪物化 6〜7マナ」で、ほとんど 間に合わなかった。マナを 4 に 下げても ほぼ かわらない（手札の 補充で 毎ターン 唱える カードが あるので、マナを 怪物化に まわさない）。手札は あまっているので、**コストを「1マナ ＋ 手札を 2まい 捨てる」** に した（決定）。

| | 怪物化できた 戦い（アスプ） | 怪物化できた 戦い（嵐息吹の ドラゴン） | 緑赤の 見本デッキの 勝率 |
|---|---|---|---|
| 前（アスプ 7マナ・ドラゴン 6マナ） | 0% | 0% | 90% |
| マナを 4 に 下げた ためし | 1% | 1% | 90% |
| **1マナ ＋ 手札 2まい（いま）** | 22%（出した 戦いの 約半分。出した つぎの ターン） | 31% | 90% |

冒険の クリア率は かんたん 79%・ふつう 59%・むずかしい 21%（前と ほぼ 同じ）。世界を喰らう者 ポルクラノス（X を 決める 怪物化）は そのまま。

### 第2弾を まぜた（2026-10）

パックは 第1弾と 第2弾を まぜて 188種から 出す（決定）。数値は 第2弾の 案の まま（調整なし）。

| むずかしさ | 第1弾だけ | 第2弾も まぜた |
|---|---|---|
| かんたん | 79% | **80%** |
| ふつう | 59% | **58%** |
| むずかしい | 21% | **20%** |

- ボス前の デッキ（7パック）に 入る カードの **33%** が 第2弾（188種の うち 62種 ＝ 33% と 同じ）。強すぎも 弱すぎも しない
- 第2弾の カードだけの 2色デッキで 1800戦：62種 すべて 使われた。新しい 能力も ぜんぶ 起きた（英雄譚・消失・脱出・喊声・サイコロ・コピー など）。天の 矢（てきが こうげきしてきた ときだけ）と 爆発（X）は AI が あまり 使わない
- 青緑は 24% → 29% に 少し 上がった（シャークトクラブ・ウーロ）

## 調整で変えたこと

最初の案のままでは、ふつうのクリア率が **0%** だった。DM のマナ（1ターンに1枚）は立ち上がりがゆっくりなので、最初の数ターンに敵が強すぎた。

| 階 | 最初の案 | 調整後（ふつう） | 理由 |
|---|---|---|---|
| ハイドラ | 頭 0/3 が3本、新生で2枚公開 | 頭 **0/2** が **2本**、新生で **1枚** | 最初のデッキのクリーチャー（パワー1〜2）で頭を倒せるように |
| 大群 | 毎ターン2枚公開 | **1枚** | 2枚だと 41% |
| 工場 | 2/2 のゴーレムを毎ターン、番人3枚 | **1/1** のゴーレムを **2体まで**、番人1枚、「点検」を追加 | ゴーレムがふえ続けて止められなかった |
| スライム | 6/6 から、成長・合体あり | **4/4** から、成長なし、**最初のターンは攻撃しない** | 2ターンめから 4点ずつ受けていた |
| ゼナゴス | 毎ターン2枚公開、笛吹き7枚 | **1枚**、笛吹き **5枚** | 2枚だと数％しか勝てない（元は英雄カードありの調整） |
| エレボス | 段階3：ライフ15、2枚公開 | 段階1：頭1本（0/3・2点）、段階3：**ライフ30**、**毎ターン3点ライフを失う** | 段階1・2で準備ができてしまい、段階3が一瞬で終わっていた |

ルールも3つ足した：

1. **敵のブロック**：最初は「敵はブロックしない」にしていたが、それだと 飛行・トランプル・「ブロックされない」に意味がなくなり、青白の飛行デッキが成り立たない。敵は「倒せるか、倒されないときだけブロックする」にした
2. **戦場の上限 30体**：軍団の集結＋増殖でトークンが何百体にもなり、画面にも並ばないので
3. **工場の鍵は戦闘のはじめの数でくらべる**：同じ戦闘でゴーレムを倒すと鍵がへって、ちょうどの数が合わなくなっていた

## シミュレーションで省いていること

- インスタントは、相手のターンの「ブロックのとき」「相手が呪文を唱えたとき」以外には使わない（ルールどおり）
- 予言のプリズムは「色の条件を満たすため」だけに使う
- 敵の呪文が選ぶ対象は ENEMIES.md の決まり（いちばんパワーの大きいもの など）
- 英雄カード（おまもり）はまだ入れていない
