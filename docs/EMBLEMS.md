# もんしょう（紋章）と しゅぎょう

教育アプリとしての 側面を つよく する しくみ。**たたかいの そと** の「しゅぎょうの へや」で **90秒** 問題を とき、7割より 多く 正解すると **もんしょうポイント** が もらえる。ポイントで スキルツリーの もんしょうを えらぶと、**12時間** 冒険の たたかいで 有利に なる。要件は [`REQUIREMENTS.md`](REQUIREMENTS.md) 12章。

- 状態：**実装ずみ**（2026-10-24。WEB 版・GAS 版）。問題は `js/data/quiz.js`、もんしょうは `js/data/emblems.js`、画面は `js/ui/study.js`（しゅぎょう）・`js/ui/emblem.js`（ツリー）
- たたかいの 中では これまで どおり 問題を 出さない（REQUIREMENTS 5章）。しゅぎょうは タイトルの「もんしょう」から 自分で 行く
- いまは **1年生の 問題**。2〜5年生は 7章の 案

---

## 1. ながれ

1. タイトルの「もんしょう」→「しゅぎょうを する（90びょう）」。**チュートリアルを クリアした あと** に「かてなく なったら もんしょうを てに いれよう」の 画面で 案内する（「もんしょうを 見る」で そのまま 行ける）。冒険で まけた とき（コンティニューの 画面・冒険の おわり）も、もんしょうが ついて いなければ 1行で すすめる
2. 問題の しゅるいを えらぶ（学校で まだ ならって いない ものは はずせる。はずした ものは おぼえて おく）
3. **90秒** で できるだけ たくさん とく（2026-10-24 に 3分 → 90秒。1年生には 3分は 長い）。のこりは「のこり 90びょう」と 秒で 出す（さいごの 15秒は 赤）。1問ずつ、答えると すぐ ○ か ×（× の ときは 答えを 1.3秒 見せる）
4. おわると けっか：正解の 数・しゅるいごとの 正解・**まちがえた 問題と 答え**
5. **5問 いじょう といて、7割より 多く 正解**（ちょうど 7割は だめ。10問なら 8問）→ もんしょうポイント **＋3**。ぜんぶ 正解なら **＋4**
6. ポイントで もんしょうを えらぶ。えらんだ ときから **12時間** つづく（画面に「のこり 11じかん 20ぷん」）
7. 12時間の あいだ、**冒険の たたかい** で つよく なる。塔の 画面と たたかいの はじめの「かちかた」に「もんしょう：❤ はじめの ライフ 22・☀ たいようの ゆびわ」と 出る

| きまり | 内容 |
|---|---|
| ポイント | なくならない（つぎの 日に つかっても よい） |
| もんしょう | えらんだ ときから 12時間。きれたら また ポイントで えらべる。ついて いる あいだは もう いちど えらべない |
| ツリー | レベル2・3 は、その まえの レベルが **いま ついて いる** ときに えらべる。まえの レベルが さきに きれても、えらんだ レベルは 12時間 のこる |
| つく たたかい | 冒険（塔）の たたかい だけ。オンライン バトルと チュートリアルには つかない（ほかの 人の ゴーストと 公平に する） |
| 保存 | ブラウザの `localStorage`（`mtg-emblem-v1`）。ポイント・もんしょうの きれる 時刻・えらんだ しゅるい・きろく（新しい 20回）・しゅるいごとの 正解 |
| 1年生の 字 | 画面は ひらがなと 1年生の 漢字。レベルは「レベル1」（ローマ数字は つかわない） |

## 2. 問題（1年生）

1回の しゅぎょうで、えらんだ しゅるいを 下の 重さで まぜて 出す（たし算・ひき算は 2、ほかは 1）。同じ 問題は 12問の あいだ 出さない。

| しゅるい | 例 | 作り方 | 答え方 |
|---|---|---|---|
| くりあがりの たしざん | 8 ＋ 5 | 2〜9 ＋ 2〜9 で 11〜18 | 数字ボタン |
| くりさがりの ひきざん | 13 − 6 | 11〜18 − 2〜9 で 一の位から ひけない もの | 数字ボタン |
| 3つの かずの けいさん | 4 ＋ 6 ＋ 3、10 − 3 − 2、14 − 5 ＋ 6 | とちゅうも 答えも 0〜20。半分は とちゅうで 10に なる（教科書と 同じ 形） | 数字ボタン |
| 10の まとまり | 10は 7と □、□と 4で 10 | 7割は 10、のこりは 5〜9 | 数字ボタン |
| とけい | （とけいの 絵）→ 6じはん | なんじ・なんじはん。短い はりは 半の とき 2つの 数の まん中 | 4つから えらぶ。「はん」の ときは「つぎの じ はん」（はりが 近い ほうを 読む まちがい）を かならず 入れる |
| かんじの よみ | ［林］の なかを あるく。 | 1年生の 漢字 93語（1字・2字の ことば・送りがな・〜つ・〜か・ようび）。文の ほかの 字は ひらがなか 1年生の 漢字 | 同じ なかまの 読みから 4つ（みっつ・よっつ・むっつ・やっつ など） |
| てにをは | わたし□ 一ねんせいです。 | 36文。「は・わ」「へ・え」「を・お」の 書き方 21文と、が・に・で・と・を 15文 | 2つか 3つから えらぶ。**どちらでも よい もの（は と が など）は えらびに 入れない** |

- ぜんぶ `node mathtcg/tools/check_quiz.mjs` で しらべて いる（2万1000問：答えが 正しい・くりあがり／くりさがりが ある・とちゅうが 0〜20・えらびが 4つ ちがう・漢字の 文に 2年生 いじょうの 漢字が ない・てにをはの 答えが えらびに ある・ごうかくの さかい目）
- 画面：数字ボタンは 7 8 9／4 5 6／1 2 3／けす 0 こたえる。キーボードの 数字・Enter・Backspace も つかえる。とけいは 60の 目もりと 1〜12、長い はりは 青
- 時計の 時間は `Date.now()` で はかる（タブを うしろに しても ずれない）

## 3. ごうかくと ポイント

| | 内容 |
|---|---|
| ごうかく | 5問 いじょう、正解 × 10 ＞ とけた 数 × 7（7割より 多い。整数で くらべる） |
| ポイント | ごうかくで ＋3、ぜんぶ 正解なら ＋4 |
| やめる | とちゅうで やめると ポイントは なし |
| 5問の わけ | 1問だけ といて まつと 100% に なって しまうため（90秒で ふつう 8〜15問）。問題は じゅんばんに 出て えらべないので、やさしい 問題だけ とく ことは できない |

## 4. もんしょうの ツリー

4つの 枝。レベル1 は 1ポイント（はじまりの レベル2 だけ 3ポイント）。ぜんぶで **16ポイント**（ごうかく 4〜6回）。

| 枝 | レベル | ポイント | こうか |
|---|---|---|---|
| 🌱 きほんの もんしょう | 1 | 1 | きほんカードが 1つ つよく なる：白 ライフ 2 → **3**・青 占術 1 → **2**・黒 −1/−1 → **−2/−2**・赤 1点 → **2点**・緑 1/1 → **1/2** の 苗木・無色 2マナ → **1マナ**（カードの 文にも「（もんしょう ＋1）」と 出る） |
| | 2 | 2 | きほんカードが **2つ** つよく なり（白 4・青 3・黒 −3/−3・赤 3点・緑 2/2）、**マナゾーンに おいた ときも その こうかが おきる**（あいては じどうで えらぶ。占術は 自分で えらぶ） |
| ❤ いのちの もんしょう | 1 | 1 | はじめの ライフ 20 ＋ 2 ＝ **22** |
| | 2 | 2 | 20 ＋ 4 ＝ **24** |
| | 3 | 3 | 20 ＋ 6 ＝ **26** |
| ☀ はじまりの もんしょう | 1 | 1 | さいしょから マナゾーンに きほんカードが 1まい（やまふだから さがす） |
| | 2 | 3 | はじめの てふだに **「たいようの ゆびわ」**（6まいめ）。1マナの アーティファクト、タップで 無色の マナが **2つ**（MTG の Sol Ring）。パックには 入らない |
| ✦ ぴったりの もんしょう | 1 | 1 | ぴったりで たおすと ライフ ＋1 |
| | 2 | 2 | ぴったりで たおすと ライフ ＋2（レベル1 と あわせても ＋2） |

- 数は ひき算・たし算で 見せる：「はじめの ライフ 20 ＋ 2 ＝ 22」、えらぶ ときは「ポイント 3 − 1 ＝ 2 に なる」
- **きほんカードの レベル2 を「マナに おいても こうか」に した わけ**：シミュレーションでは きほんカードは ほぼ マナに おかれ、唱えるのは 1戦 0.04回。数字を 上げる だけでは ほとんど きかなかった（クリア率 61% → 61%）
- **やめた 案**（シミュレーションで 弱かった）：「ぴったりで 1まい 引く」は 山札が 早く へって もどす ときの ライフが へり、61% → 58%。「はじめの てふだに デッキで いちばん つよい カード」は 重い カードが 来て 出せず 57%（3マナ いかに しても 60%）

## 5. シミュレーション

`EMBLEM=life1,basic1 node mathtcg/tools/sim.mjs runs`（`EMBLEM=all` で ぜんぶ）。冒険 1000回ずつ（ぶれは ±1.5% くらい）。もんしょう なしは かんたん 84%・ふつう 61%・むずかしい 23%。

| もんしょう | ポイント | ふつう | ちがい |
|---|---|---|---|
| なし | 0 | 61% | − |
| 🌱 レベル1 | 1 | 61% | ±0（きほんカードは ほぼ マナに おかれる） |
| 🌱 レベル1 ＋ 2 | 3 | 64% | ＋3 |
| ❤ レベル1（ライフ 22） | 1 | 69% | ＋8 |
| ❤ レベル1 ＋ 2（24） | 3 | 74% | ＋13 |
| ❤ レベル1〜3（26） | 6 | 80% | ＋19 |
| ☀ レベル1（さいしょから マナ 1つ） | 1 | 65% | ＋4 |
| ☀ レベル1 ＋ 2（たいようの ゆびわ） | 4 | 81% | ＋20 |
| ✦ レベル1（ぴったりで ＋1） | 1 | 68% | ＋7 |
| ✦ レベル1 ＋ 2（＋2） | 3 | 74% | ＋13 |
| 1回 ごうかく（3ポイント）の 例：❤1・🌱1・✦1 | 3 | 74% | ＋13（むずかしい 23% → 40%） |
| 〃：☀1・❤1・✦1 | 3 | 78% | ＋17 |
| ぜんぶ | 16 | **92%** | ＋31（かんたん 98%・むずかしい 84%） |

- 1回の ごうかくで ふつうが 7割 くらい（目標の 50〜70% の 上の はし）、毎日 しっかり しゅぎょうすると 9割。たくさん とくほど つよく なる
- きめる まえに ためした 数（ふつう）：ライフ ＋3／＋6／＋10 は 72%／80%／87%（＋10 は つよすぎ）。たいようの ゆびわ（1マナで マナ 2つ）だけで 80%、2マナに すると 66%、1マナで 好きな 色 1つ 79%、1マナで 無色 1つ 76%。ゆびわは MTG の Sol Ring の まま、4ポイント（ぜんぶ 正解の しゅぎょう 1回）に した。「デッキで いちばん つよい カード」57%（3マナ いかでも 60%）、「ぴったりで 1まい 引く」58%、ぴったりで ライフ ＋3 は 77%

## 6. 画面

- タイトル：「✦ もんしょう」（ついて いる 数・ポイント）
- もんしょうの 画面：ポイント、「しゅぎょうを する（90びょう）」、4つの 枝（レベル1 → 2 → 3。ついて いる ものは 金色で「のこり ○じかん」、えらべる ものは 緑、まだの ものは うすい）、しゅぎょうの きろく（新しい 5回）、しゅるいごとの 正解
- しゅぎょう：のこり時間（秒。さいごの 15秒は 赤）と バー、正解の 数、問題（紙の 色の カード）、数字ボタンか えらぶ ボタン。「やめる」は たしかめてから
- けっか：ごうかく／あと すこし、正解の 数と %、ごうかくの きまり（「12もんなら 9もん いじょう」）、ポイント、しゅるいごと、**まちがえた 問題と 答え**、「もう いちど」
