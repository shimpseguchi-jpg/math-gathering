# マスマティック・ザ・ギャザリング 要件定義

小学1〜5年生むけの **算数 × デジタルTCG × デッキ構築型ローグライク**。
カードのテキストは Magic: The Gathering（以下 MTG）、マナの仕組みは デュエル・マスターズ（以下 DM）をベースにする。

- 状態：**要件定義 第1版**（主な未決事項はすべて決定。【提案】と書いたところは、変更がなければその内容で作る）
- 置き場所：このリポジトリ（既存の かずまほ・アルカナンバー と同じく、ブラウザだけで動く素の JavaScript を想定）

## 0. 決定事項（ここまでに決まったこと）

| 項目 | 決定 |
|---|---|
| 対象 | 小学1〜5年生 |
| ジャンル | 算数のデジタルTCG、デッキ構築型ローグライク |
| カードテキスト | MTG がベース。キーワード能力・カードタイプ・用語は **MTG の名前のまま**、漢字には読み（ふりがな）をつける |
| マナシステム | DM がベース |
| 色 | 赤・青・白・緑の4色 ＋ 無色 |
| アーキタイプ（2色） | 赤青・青白・白緑・緑赤・赤白・青緑 の6種類（4色の2色組み合わせすべて） |
| 白緑 | **召集**（Convoke） |
| ほかの5アーキタイプ | 4.2 の案で決定（赤青＝X呪文＋果敢、青白＝飛行＋割り振り、緑赤＝獰猛、赤白＝大隊、青緑＝カウンター＋マナブースト） |
| 算数の入れ方 | **たたかいの中では 問題は出さない。勝つために考えると、自然に計算する**（5章）。けいさんボーナス（A）は やめた（2026-10）。たたかいの そとの **しゅぎょう**（60秒の 問題）で もんしょうを もらう（12章。2026-10-24 追加） |
| 数を意識する能力 | 各アーキタイプに MTG の能力（圧倒・激励・鼓舞・集団戦術・教導・訓練・キッカー・増呪・待機・Lvアップ）と、オリジナルの **ぴったり** を入れる（3.2）。英雄譚は第2弾の候補 |
| 画面が計算しない | 攻撃を選んでいる最中は、合計を **出さない**（攻撃のあとに「3 ＋ 2 ＝ 5点」と結果だけ見せる）。敵の予定も数を ならべて出し、合計は出さない |
| 4色か5色か | **4色版** で作る。5色版（黒）は将来の拡張の候補として 4.3 に残す |
| 開始時 | 3パック公開。1パック5枚 |
| デッキの制限 | **2色まで（無色は自由）＋ デッキキャパシティ**（レアリティ点数の合計30点程度）（6.2） |
| 塔 | 5階建て。1階ずつ敵が出る。頂上（5階）にボス |
| 1〜4階の敵 | MTG の **チャレンジ・デッキ** を参考にする |
| ライフ | **20**。DM のシールドはなし |
| タイトル | **マスマティック・ザ・ギャザリング** |
| 世界観 | **MTG と同じ**（1.1） |
| カードの種類数 | 第1弾 **126種** ＋ 第2弾 **120種**（2026-10-28 に 74種から ふやした。4.4・[`SET2.md`](SET2.md)）。パックは まぜて 出す |
| 冒険をまたいで残るもの | **ずかん**・**トロフィー**（8.1・8.3）と **もんしょうポイント**。もんしょうは えらんでから **12時間** だけ（12章）。カードの解放はなし |
| 負けたとき | **1回だけコンティニュー** できる（1.2） |
| 報酬 | 1〜4階の敵を倒すたびに **1パック開封**、**デッキ構築をやり直せる** |
| デッキ構築の「デッキ」 | 「カードを えらぶ」と「デッキ ○まい」の タブ。デッキの タブは 同じ カードを 1行に まとめて マナコストの じゅん（−／＋で 1まいずつ、なまえで せつめい）と、マナコストごとの まい数・クリーチャーの まい数（2026-10-28。冒険・レイド・こうちくモード） |
| デッキ構築の「こまかく」 | ならべかえ（いろ・マナコスト・しゅるい・レアリティ・パワー・てんすう・てに いれた じゅん、↑↓）と しぼりこみ（なまえ・**テキスト**・弾・マナコスト・いろ・しゅるい・しゅぞく・レアリティ・のうりょく・デッキに 入れた／入れて いない／いま 入れられる。なまえと テキストは 漢字でも ふりがなでも さがせる。2026-10-28 に テキスト・弾を 追加）。せっていは 端末に のこる（`js/ui/deckfilter.js`） |

## 1. ゲームの流れ（コアループ）

```
タイトル → 学年（またはうでだめし）を選ぶ
  → 3パック公開（15枚）→ デッキ構築（制限は 6.2）
  → 1階 たたかい → 勝ち → 1パック開封 → デッキ組み直し
  → 2階 → … → 4階 → 1パック開封 → デッキ組み直し
  → 5階 ボス → クリア（スコア・ずかん・きろく）
負けたら：1回だけコンティニュー（1.2）。2回目に負けたら冒険おわり。次の冒険はまた3パックから
```

- 1回の冒険：**30〜45分** を目安（1戦 5〜8分 × 5戦 ＋ 構築）【提案】
- 冒険の途中で中断・再開できる（オートセーブ）【提案】

### 1.1 世界観（決定：MTG と同じ）

- プレイヤーは **プレインズウォーカー**。次元を渡り歩く魔法使いとして塔に挑む
- 舞台の次元は **テーロス** を推奨【提案】。1・2・4階の元ネタのチャレンジ・デッキ（ハイドラ・ミノタウルスの大群・ゼナゴス）がすべてテーロスのものなので、そのままつながる
- 4色（赤青白緑）のカラーパイ・カードの雰囲気・フレーバーテキストも MTG に合わせる。**用語は原作のまま**（決定）。ただし、グロテスク・残酷な用語だけは言いかえる（3.5）
- **注意**：タイトル・世界観・キャラクター名は Wizards of the Coast の MTG を下敷きにした **非公式のファンメイド** になる。アイドル迷宮（仮）と同じく **個人・身内で楽しむ範囲** で作る前提とし、一般公開や学校での配布をするときは、名前・固有名詞をオリジナルに差しかえる（カード名・敵の名前はデータで差しかえられるようにしておく）

### 1.2 コンティニュー（決定：1回だけ）

| 項目 | 内容 |
|---|---|
| 回数 | 冒険1回につき **1回だけ**（全学年共通） |
| どこから | 負けた階の **はじめから**（ボスは1段階めから）【提案】 |
| 状態 | ライフ20に戻る。デッキの組み直しもできる。持っているカードは減らない【提案】 |
| 敵 | 同じ敵（3階はランダムを引き直さない） |
| スコア | コンティニューすると減点（例：最終スコア −20%）【提案】 |
| 表示 | 塔のマップに「のこり コンティニュー ○回」を表示 |

## 2. マナシステム（DM ベース）

| ルール | 内容 |
|---|---|
| マナチャージ | 自分のターンに1回、手札のカードを1枚 **マナゾーン** に置ける（どのカードでも置ける） |
| マナの色 | マナゾーンのカードは、そのカードの色のマナを1つ出す。無色カードは無色マナ |
| コストの払い方 | コストの数だけマナゾーンのカードをタップする。**そのカードの色のマナを最低1つ** 含める必要がある（DM の文明条件） |
| 2色カード | マナゾーンに **タップして** 置かれる（DM と同じ。置いたターンは使えない） |
| アンタップ | ターンのはじめに、マナゾーンのカードをすべてアンタップ |
| 土地 | **ない**。すべてのカードが呪文・クリーチャーであり、同時にマナにもなる |
| マナを ふやす カード | MTG の「基本土地を さがして 戦場に 出す」は、**やまふだから きほんカードを さがして、タップして マナゾーンに 置く**（その あと やまふだを 切りなおす）。やまふだの 上の カードを そのまま マナに すると、強い カードが マナに 行って もどせない ため（2026-10-24。豊かな成長・耕作・カラメトラ・空身像・原始の タイタン など） |

> ねらい：「どのカードをマナにして、どれを使うか」という DM らしい悩みを残しつつ、MTG の土地事故をなくす。

### 2.1 対戦の基本ルール【提案】

- ライフ：プレイヤー **20**（決定。MTG・チャレンジ・デッキに合わせる）。DM のシールド・S・トリガーは **なし**（決定）
- 手札：初期手札5枚。**自分のターンのはじめに、手札が5枚になるまで引く**（遊戯王ラッシュデュエルと同じ。決定）。山札が残り5枚より少なくなると、画面の「やまふだ」に小さく「もうすぐ なくなる」と出る
- カードタイプ：MTG と同じ。クリーチャー／インスタント／ソーサリー／エンチャント／アーティファクト（土地はない）
- 戦闘：MTG と同じく「攻撃 → ブロック → ダメージ」。小学生向けに **ブロックの割り振りは1対1のみ**（複数ブロックなし）にして簡単にする
- インスタントのタイミング：相手ターンに使えるのは「ブロック宣言のとき」「相手が呪文を唱えたとき」の2つの決まった場面だけにして、UI で「つかう？」と聞く（スタックの理解を要求しない）
- 山札切れ（決定）：ライブラリーが0枚のときにカードを引くなら、**墓地をシャッフルしてライブラリーにする**。そのたびに **ライフを 2・4・6…（2の倍数ずつ）失う**（ライブラリーアウトの緊張感は残し、20枚デッキでも いきなり負けにはしない）。MTG どおり「引けなければ負け」は、手札の補充と20枚デッキでは ふつうのクリア率が 1% になるので使わない（[`SIMULATION.md`](SIMULATION.md)）
- たたかいの とちゅうの メニュー（決定）：上の「≡ メニュー」で いつでも（てきの ターン中を のぞく）たたかいを やめられる。冒険は つづきが のこり、その 階は「つづきから」で はじめから。チュートリアルは タイトルへ。オンライン バトルは **こうさん**（まけ・デッキの 点 −1）
- 戦場の上限：クリーチャーは各陣営30体まで（画面に並べられる数。こえるトークンは出ない）

## 3. カードテキスト（MTG ベース）

### 3.1 表記ルール

- 文の形は MTG の日本語テキストに合わせる（例：「〜が戦場に出たとき、カードを1枚引く。」）
- **漢字（決定）**：3年生までに習う漢字（学年別漢字配当表の1〜3年・440字）だけを使う。それ以外の漢字は
  - 画面のことば（ボタン・説明・コーチ・ログ・ことばの説明の文）は **ひらがな**（ことばごと：戦場 → せんじょう、攻撃 → こうげき）
  - カードの文章（名前・タイプ・テキスト・敵のカード）は **ふりがな**（「与（あた）える」「墓地（ぼち）」。小さいカードの名前・ログの名前にもつける）
  - チェック：`node tools/kanji.mjs`（ふりがなのない習わない漢字を出す）
- 文字表示は既存アプリと同じ3モード：**ひらがな／漢字（ふりがな）／漢字**【将来の候補】
- キーワード能力・カードタイプ・用語は **MTG の名前のまま**（決定）。漢字には **ふりがな** をつける（ゲーム内はルビ、ドキュメントでは「飛行（ひこう）」のように（）で読みを書く）
- キーワードにはアイコンもつけ、長押しで説明を出す

|---|---|---|---|
| 飛行（ひこう） | Flying | 青白 | 飛行か到達を持つクリーチャーでしかブロックできない |
| 到達（とうたつ） | Reach | 緑 | 飛行を持つクリーチャーをブロックできる |
| 速攻（そっこう） | Haste | 赤 | 出たターンから攻撃できる |

| トランプル | Trample | 緑 | ブロックしたクリーチャーを倒して余ったダメージを、相手に与える |

| 召集（しょうしゅう） | Convoke | 白緑 | クリーチャーをタップしてコストを払える |

| 果敢（かかん） | Prowess | 赤青 | クリーチャーでない呪文を唱えるたび、ターン終了時まで ＋1/＋1 |
| 獰猛（どうもう） | Ferocious | 緑赤 | パワー4以上のクリーチャーがいるなら、効果が出る |
| 怪物化（かいぶつか） | Monstrosity | 緑赤・青緑 | コストを払うと ＋1/＋1カウンターが置かれて「怪物」になる（1回だけ）。本作のコストは **少しのマナ ＋ 手札を捨てる**（手札は毎ターン補充されて余るため。2026-10） |
| 湧血（ゆうけつ） | Bloodrush | 緑赤 | 手札から捨てて、攻撃しているクリーチャーを強くする |
| 進化（しんか） | Evolve | 青緑 | パワーかタフネスが これより大きいクリーチャーが出るたび、＋1/＋1カウンターを置く |

| 装備（そうび） | Equip | 無色 | コストを払って、装備品を自分のクリーチャーにつける |

| 増呪（ぞうじゅ） | Escalate | 赤青・赤白 | モードを好きな数だけ選べる。2つめからのモード1つにつき、マナが多くかかる |
| 待機（たいき） | Suspend | 赤青・青緑 | 少しのマナで手札から待機させる。時間カウンターが毎ターン1つへり、0で ただで唱える |

### 3.3 用語の読み

| 用語（読み） | 意味 |
|---|---|
| 戦場（せんじょう） | カードを出して置いておく場所 |
| 手札（てふだ） | 手に持っているカード |
| 墓地（ぼち） | 使い終わったカード・倒れたクリーチャーを置く場所 |
| 追放（ついほう） | ゲームの外にカードを出す（もどってこない） |
| 対象（たいしょう） | 呪文や能力で選ぶもの |
| 修整（しゅうせい） | パワー・タフネスを上げ下げすること |
| 唱える（となえる） | 呪文を使うこと |

### 3.5 言いかえる言葉（決定）

用語・カード名・クリーチャー・タイプは **原作（MTG 日本語版）のまま** にする。グロテスク・残酷で小学生に不適切な言葉だけ、次のように言いかえる。

| 原作 | 本作 | 理由 |
|---|---|---|
| 生け贄（いけにえ）に捧（ささ）げる（sacrifice） | 墓地（ぼち）に置く | 残酷 |

### 4.2 アーキタイプ（4色版・決定）

## 5. 算数の入れ方（決定：たたかいの中では 問題は出さない。2026-10 に変更）

たたかいの そとの「しゅぎょう」（60秒の 問題で もんしょうを もらう）は 12章（2026-10-24 追加）。

ゲームの途中に計算問題を出すのではなく、**勝つために考えると、自然に計算する** ゲームにする。MTG や DM で子どもが頭の中でやっていることを、そのまま算数にする。

| 場面 | 頭の中でしていること |
|---|---|
| 敵のライフは のこり10。手もとに パワー 5・2・3・4 | 足して10になる組み合わせ探し（10のまとまり・繰り上がり） |
| マナが4つ使える。手札には 5マナのカードが2枚 | どれをマナに置けば、次のターンに何が出せるか（たし算・先読み） |
| 4/3 で 2/5 に攻撃するとどうなる？ | 大小比較・ひき算 |
| トランプル 7 で、タフネス 3 にブロックされた | のこり 7 − 3 ＝ 4 が届く（ひき算） |
| 6点を3体に割り振る | わり算・等分 |
| ゴーレム工場の鍵 7（ちょうど同じ数で壊れる） | ぴったりの組み合わせ探し |

### 5.1 きまり

- **たたかいの中に 問題の画面は出さない**（けいさんボーナス・抜き打ちテストは やめた）。問題を とくのは たたかいの そとの しゅぎょう だけ（12章）
- **画面が かわりに計算しない**：攻撃するクリーチャーを選んでいる最中は、パワーの合計を出さない（決定：A）。攻撃のあとに「3 ＋ 2 ＝ 5点」「ぴったり！」と **結果だけ** 見せる
- 敵の予定は、数を ならべて出す（「3体で 攻撃（パワー 3・2・4）」）。合計は出さない
- X・割り振り・激励・増呪・キッカー は、子どもが **自分で数を決める**（X は −／＋ で選ぶ。マナが足りなければ「マナが たりない」とだけ言う）
- **数を意識する能力** をアーキタイプごとに入れる（3.2・4.2・`cards/README.md`）
- **ぴったり**：敵のクリーチャーを タフネスと ちょうど同じダメージで倒すと「ぴったり！」。ぴったりで得をするカードもある。回数は冒険の きろく に残る

### 5.2 学年

- 学年の設定は いったん なくした（問題を出さないため）。しゅぎょう（12章）は **1年生の 問題** から。2〜5年生の 問題と 学年の せっていは [`EMBLEMS.md`](EMBLEMS.md) 7章の 案
- 将来の案：学年で **出てくる数の大きさ** を変える（1年はライフ20・パワー1〜5、高学年は「×2」「半分」「割り振る」が多い色、など）。ゲームバランスが変わるので、やるときはシミュレーションで確かめる

| 学年 | 自然に出てくる算数 |
|---|---|
| 1年 | 20までのたし算・ひき算、大小比較、10のまとまり（召集・圧倒） |
| 2年 | 2けたのたし算・ひき算、九九（全体強化・大隊） |
| 3年 | わり算、□を使った式、あまり（割り振る・X呪文） |
| 4年 | 大きな数（原初のハイドラ） |
| 5年 | 倍数・偶数・奇数（どんどん2ばい・クルフィックス） |

## 6. パックとデッキ構築

### 6.1 パックの中身（決定：1パック8枚）

#### 5枚で足りるか（シミュレーション）

「2色まで」の制限があると、パックから出たカードのうち **デッキに入れられるのは半分くらい** になる。
1パックの枚数ごとに、いちばん多く集まった2色（＋無色）の枚数と点数を出した（4色が各20%・2色カード10%・無色10%、レアは各パック1枚（5枚＝C2・U2・R1、6枚＝C3・U2・R1、8枚＝C4・U3・R1、10枚＝C5・U4・R1）、4000回の平均。サプライズ・レジェンドを入れても数字はほぼ変わらない。`tools/packsim.py`）。

| 1パックの枚数 | 開始時（3パック） | 2階クリア後（5パック） | ボス戦の前（7パック） |
|---|---|---|---|
| **5枚** | 10枚・19点 | 16枚・30点 | 22枚・40点 |
| 6枚 | 12枚・20点 | 19枚・32点 | 26枚・44点 |
| **8枚** | 15枚・26点 | 25枚・41点 | 34枚・55点 |
| 10枚 | 19枚・31点 | 30枚・49点 | 41枚・67点 |

5枚だと：

- **開始時に使えるカードが10枚しかない**。デッキ20枚のうち半分が きほんカード になり、最初の戦いが単調になる
- キャパシティ30点に届くのが **3階になってから**。それまでは「選ぶ」悩みがほとんどない
- ボス前でも 22枚・40点 から 30点ぶんを選ぶだけで、悩みは小さい

#### 決定：1パック8枚

| レアリティ | 枚数 |
|---|---|
| コモン | 4 |
| アンコモン | 3 |
| レア | 1（8パックに1回、レジェンドになる） |

**サプライズ・レジェンド**：低い確率で、コモン1枚がレジェンドに変わる（MTG のフォイル枠のようなおまけ）。

| 項目 | 内容 |
|---|---|
| 確率 | **1パックにつき 1/20（5%）**（決定） |
| 冒険1回（7パック）で1回以上出る確率 | 約30% |
| 冒険1回で出るレジェンドの平均 | 約1.2枚（コモンが変わらない場合は約0.9枚） |
| レアもレジェンドになり、1パックに2枚出る確率 | 約0.6%（160パックに1回） |
| 演出 | コモンのはずのカードをめくると光って変わる「！？」演出 |

- 確率の候補：1/16 なら冒険1回で約36%、1/30 なら約21%
- レジェンドは4点なので、キャパシティ30点のなかで「入れるか」の悩みが増える（強すぎるだけのおまけにはならない）

#### 塔の ごほうびパック（決定）

1〜4階を倒して あけるパックは、少しずつ 良くなる（`js/engine/run.js` の `REWARD`・`openPack`）。最初の3パックは ふつう。

| 項目 | 内容 |
|---|---|
| レアリティが 上がる | クリアした階 1つにつき：コモン枠が アンコモンに +5%、アンコモン枠が レアに +4%、レアが レジェンドに +4%、サプライズ +1% |
| 例：4階クリア後 | レジェンドの出る率（レア枠）12.5% → 28.5%、サプライズ 5% → 9% |
| よく使う色 | デッキで いちばん多い色（きほんカードを のぞく）の カードが **4倍** 出やすい（2026-10-24 に 2倍 → 4倍。黒が 入って 5色に なっても 2色に しぼれるように） |
| 表示 | パックを あける前に「レジェンド ○%・○色が 出やすい」を出す |

シミュレーション（ふつう）：クリア率 55% → 約60%。

- 開始時に 約15枚・26点 → **最初のデッキはほぼ全部入る**（最初から悩ませすぎない）
- 1階クリア後（4パック）にキャパシティ30点をこえ、**そこから毎回「選ぶ」悩みが出る**
- ボス前は 約34枚・55点 から30点ぶんを選ぶ → しっかり取捨選択になる
- 開封は1枚ずつめくる演出が基本。8枚は長いので「ぜんぶ めくる」ボタンもつける
- パックは **色が偏りすぎない** ように抽選（1パックに4色すべてを最低1枚）【提案】

### 6.2 デッキの制限（決定：2色まで ＋ デッキキャパシティ）

| ルール | 内容 |
|---|---|
| 色 | デッキに入れられる色は **2色まで**。無色は自由。2色カードは、その2色を選んだときだけ入る |
| デッキキャパシティ | レアリティ点数（コモン1／アンコモン2／レア3／レジェンド4）の合計が **30点以下** |
| きほんカード | 0点。キャパシティを使わない |

- 色を決めると持っているカードの半分くらいが入らなくなり、残りから30点ぶんを選ぶ、という2段階の取捨選択になる
- 2色の制限は MTG のドラフト・アーキタイプと一致し、DM のマナの色条件とも相性が良い（色が少ないほどマナが安定する）
- 点数の合計はたし算の練習にもなる。画面では「のこり ○点」のメーターと、カードを入れる前に「入れると のこり ○点」を見せて、1〜2年生でも選べるようにする
- 検討したほかの方式（レアリティ枠、コストの合計、パックから選んで取る、持てる枚数の上限）は不採用

共通のルール：

- デッキは **20枚ちょうど**（決定）。足りない分は0点の「きほんカード」（各色＋無色、小さな効果つきのマナ用カード）で自動的に埋める（DM は全カードがマナになるので、土地の代わり）
- 同じカードは、パックから出た枚数まで入れてよい
- 「おまかせ」ボタン：いちばん多い2色で自動で組む（1〜2年生向け）

## 7. 塔（5階）

### 7.1 敵の仕組み（MTG チャレンジ・デッキ共通ルール）

- 敵は **マナを使わない**。敵のターンにライブラリーの一番上を公開して、そのまま唱える（自動で動くので AI が不要・子どもにも先が読みやすい）
- 敵のカードはすべて無色・マナ総量0
- 敵に「カードを引かせる・捨てさせる」など実行できない効果は無視
- **英雄カード**：プレイヤーは開始時に英雄カード（補助のエンチャント）を最大2枚出せる → 本作では **冒険の最初に選ぶ「おまもり」** に置きかえる【提案】
- **英雄の報酬**：敵のパーマネントを倒すとプレイヤーにご褒美（ライフ回復など）がある → そのまま採用（倒すと嬉しい）

チャレンジ・デッキは3種類しかないので、3階と5階はオリジナル。

### 7.3 5階：ボス「エレボス」（3段階、決定）

ボスは テーロスの死者の神 **エレボス**（決定）。塔の頂上は冥界につながっていて、1〜4階で出てきたルールを順番に使う。

- 本作のプレイヤーが使えるのは4色（黒なし）だが、エレボスは **黒の神**。チャレンジ・デッキのルールどおり敵のカードは無色扱いなので、ゲームとしては問題ない。「黒はまだ手に入らない色」として、将来の黒の拡張（4.3）への前ふりにもなる
- 4階のゼナゴス（赤緑の神）から、5階のエレボス（黒の神）へ「神をたおして、さらに上の神へ」の流れになる
- 用語は原作のまま（死者の神・冥界・ゾンビ など）。グロテスク・残酷な言葉だけ言いかえる（3.5）

| 段階 | 元にするルール | 勝利条件（次の段階に進む条件） | 内容 |
|---|---|---|---|
| 1 | ハイドラ | **冥界の番犬の頭が0** | 頭がたくさんある番犬がエレボスの門を守る。頭2本で始まり、頭が倒れるとライブラリーから新しい頭が出る |
| 2 | 神を討て | **エレボスの手下が0** | 冥界の住人たちが現れる。手下が1体でもいる限り、エレボスには攻撃もダメージもできない |
| 3 | 本体 | **エレボスのライフが0** | エレボスにライフ（例：15）がある。毎ターン2枚公開して唱える、いちばん強い段階。エレボスらしく「プレイヤーがライフを払う」「墓地のクリーチャーが敵として戻る」カードを入れる |

- **段階のあいだ**：プレイヤーの場・手札・マナゾーン・ライフはそのまま引きつぐ。ボスの場は段階ごとに入れかわる
- **段階が変わるときのごほうび**：ライフを3点得て、カードを1枚引く【提案】
- 段階が変わるたびに見た目・音楽を変え、「だい2だんかい！」の演出を入れる
- 長くなりすぎないように、ボス戦全体で 10〜12分 をめやすにする（ほかの階の1.5〜2倍）
- 負けたときは、どの段階まで進んだかを スコア に入れる（コンティニューすると1段階めからやり直し）

### 8.1 ずかん（決定：冒険をまたいで残す。2026-10-24 実装）

冒険をまたいで残るのは **ずかんだけ**（と トロフィー。8.3）。カードの解放・おまもりの解放のような「強くなって次の冒険が楽になる」要素は入れない（毎回同じ条件で遊ぶローグライクにする）。

- こうちくモード（2026-10-28 実装。[`CONSTRUCTED.md`](CONSTRUCTED.md)）は 冒険とは べつの モード。パックけんで あつめた カードは そこでだけ 使い、冒険には もちこまないので、この きまりは かわらない

| タブ | 中身 |
|---|---|
| カード | 200種（第1弾＋第2弾）＋きほんカード。パックから出たことのあるカードは絵と説明が見られる。まだのカードは「？」（色・レアリティだけ見える）。集めた数／126 を表示 |
| てき | 倒したことのある敵（各階・3階のA/B・エレボスの各段階） |
| アーキタイプ | 6つのアーキタイプのそれぞれで、クリアしたことがあるかのしるし |
| きろく | クリア回数、最高スコア（上位10件）、ぴったりの回数 |

- サプライズ・レジェンド（コモンから変わったもの）を引いたことも、ずかんに特別なしるし（「！？」）で残す

実装（`js/ui/zukan.js`、`localStorage` の `mtg-zukan`）：

- タイトルの「ずかん」から。カードは 弾ごとに 色・コストの じゅんで ならぶ。まだの カードは 灰色の「？」で、色の 帯と 色の まる・レアリティだけ 見える。出た ことの ある カードは タップで せつめい（はじめて 出た 日・出た まいすう）。開発モードでは 開発中の 弾も 見られる（あつめた 数の 合計は 出ている 弾だけ）
- てき：1〜4階の 9しゅるいと、エレボスの 3つの だんかい。たおした 回数（まだの ものは「？？？」）
- アーキタイプ：2色の 10しゅるい（第3弾の 黒も ふくむ）。その 2色の デッキで のぼりきると ★ と クリア回数
- きろく：ぼうけんの 回数・クリア回数（むずかしさ ごと）・ぴったりの 合計・**さいこう スコア 上位10**。スコアは「**とどいた 階 × 100 ＋ ぴったり × 10**」（子どもが 自分で 計算できる 式。例：5階 ＋ ぴったり 7回 ＝ 570）

### 8.2 せってい と 開発モード（2026-10 追加）

WEB版（ブラウザ・GAS 版）は **開発モード**。タイトルに「開発モード」の しるしが 出て、「せってい」画面で 開発用の 項目を かえられる。

| 項目 | 中身 |
|---|---|
| おと | あり／なし |
| まぜる サブセット・番外編（2026-10-27。開発モード いがいでも 出る） | サブセット（三つの 旗・アルケミー・プレインズウォーカー・ラヴニカ）と 番外編（FGO・スターレイル・ゼンゼロ）を チェックで えらぶ。**パックの もんしょうで 解放（もんしょうが ついて いる あいだ）した ものだけ** えらべる。チェックを はずすと、もんしょうが ついて いても パックに まぜない（`localStorage` の `mtg-extra-off`。`emblem.js` の `activeEffects` で のぞく） |
| レイド（開発モード・WEB版だけ。2026-10-28） | タイトルに「レイド：タルキール」の 帯を 出す／出さない（`localStorage` の `mtg-raid-hide`。その 端末だけ。点は のこる）。GAS 版は 先生の 開発モードの 画面で 全員ぶん きめる |

- 開発モードを やめる（せいひん版）ときは `js/ui/settings.js` の `DEV` を `false` に する。開発用の 項目が かくれて、出ている 弾（`cards.js` の `SETS` で `released: true` の 弾）だけが パックに 入る
- 開発中の 弾の しくみと、ゲームに あわせて かんたんに した ところは [`ROADMAP.md`](ROADMAP.md) 6章
- シミュレーションも 同じ ように しぼれる：`SETS=1 node tools/sim.mjs runs`（[`SIMULATION.md`](SIMULATION.md)）

### 8.5 塔の 統率者戦（2026-10-26 追加）

レイド いがいでも 統率者戦が できる ように、塔の ぼうけんに ルール「統率者戦」を 足した（タイトルの「ルール」で えらぶ）。

1. 統率者を えらぶ：デモ なので、どの 弾の 伝説の クリーチャーでも えらべる（色で しぼりこめる。`commander.js` の `pickLegend`）
2. パックを あける：統率者の 色だけで できた カード（多色の 統率者なら その 色の くみあわせ ぜんぶ）が 3倍 出やすい（`run.js` の `CMD_FAVOR`）
3. デッキを くむ：統率者の 色の カード（と 無色）だけ 入れられる。2色まで・旗の きまりの かわり。おまかせも 統率者の 色で くむ
- 階を のぼって デッキを なおす ときに、統率者も かえられる（デッキ構築の「かえる」）。色が あわなく なった カードは デッキから はずれる
- たたかいでは 統率者は とうそつりょういきに いて、唱える たびに ＋2マナ（レイドと おなじ）。ライフは ふつうの まま

- **つよさの 調整**（2026-10-27）：統率者が いると 1戦ごとの 勝率が 76〜93% → 91〜100% に 上がった（ゼンゼロ いがいの 統率者でも おなじ。統率者が まいかい つかえる ことが 大きい。ブレイクの 色の きっかけを なくしても かわらなかった）。統率者の コストを 上げても あまり かわらない（＋2マナで 84〜98%）ので、**3階から 上は てきの クリーチャーが ＋1/＋1**（`app.js` の `CMD_BUFF_FROM`）。たたかいの はじめの 画面に「統率者が いるので、てきも 本気！」と 出す。ぜんぶの 階に つけると 69〜90%、3階から 上 だけで みつもり 79〜94%（統率者なし 76〜93%）

### 8.7 あそべる ものが ひらく じゅんばん（2026-10-29 追加）

はじめての 子が まよわない ように、タイトルに 道すじを つけた（`js/ui/unlock.js`）。

| ひらく もの | 条件 |
|---|---|
| テーロスの とう（あたらしい ぼうけん。かんたん・ふつう） | チュートリアルを クリア → ストーリー 1章「はじめの いっぽ」（1-1〜1-3）を クリア。まえから あそんで いる 子（ぼうけんの きろくが ある）は さいしょから |
| むずかしい | テーロスの とうを「ふつう」で のぼりきる |
| ラヴニカ | テーロスの とうを「ふつう」で のぼりきる |
| ストリクスヘイヴン | 第5弾が パックに 入る（先生・せってい）＋ テーロスの とうを「ふつう」で のぼりきる（[`STRIXHAVEN.md`](STRIXHAVEN.md)） |

- タイトルでは、まだの ものは うすい 字と かぎの マーク。タップすると フレーバーの ことば（「ラヴニカへの 門」「エレボスは まだ 本気を 出して いない」など）と、つぎに いく ところ（チュートリアルへ／ストーリーへ）の ボタンが 出る
- とうが まだ の あいだは「あたらしい ぼうけん」が うすく、いちばん 上の ボタンが「チュートリアル」か「ストーリーを すすめる」に なる。ストーリーの タイルに「つぎは ここ」の しるし。ぼうけんの せってい（せかい・むずかしさ…）は 出さない
- はじめての 子の むずかしさは「かんたん」。えらんで いた ものが まだ なら、あそべる ほうに もどす
- ひらいた ときは、つぎに タイトルを 見た ときに 1回だけ「ひらいた！」の まど（はじめて この 版を 見た ときは、いま ひらいて いる ものを おぼえるだけで 出さない）
- クリアの きろくは ずかんの `won`（`せかい:むずかしさ` → 回数）。まえの 版の `clears`（せかい なし）は テーロスと して うつす
- デバッグモードの せってい「ぜんぶ あそべる」で ぜんぶ ひらく（先生の たしかめ用。`tools/e2e.mjs` も これを つかう）

### 8.6 てきを ねらう 効果の ねらいかた（2026-10-27 追加）

低学年なので、さいしょから ぜんぶ 自分で えらぶ のでは なく、えらべる ところを しぼる。レアリティが 高いほど 自分で えらべる。

| レアリティ | てきを ねらう とき | カードの 書きかた |
|---|---|---|
| コモン | 🎲 ランダム | 「ランダムな 敵の クリーチャー1体に 3点」 |
| アンコモン・きほん | 👑 パワーが いちばん 大きい てき | 「パワーが いちばん 大きい 敵の クリーチャー1体を …」 |
| レア・レジェンド | 👆 自分で えらぶ（対象） | 「クリーチャー1体を 対象とする」 |

- 自分の クリーチャーを ねらう とき（＋の 修整・カウンター など）は、どの レアリティでも 自分で えらぶ
- ランダム・いちばんに しない もの（自分で えらぶ まま）：格闘・かみつき（ランダムだと つよい てきに あたって 自分が そんする）と、もともと よわい もの（1点・−1/−1 1こ・留置・1体を タップ）。`game.js` の `PICK_FREE`
- コモンの 呪文（インスタント・ソーサリー）で ランダムに なった ものは コスト −1（2 いじょうの とき）。クリーチャーの 出たとき などは そのまま。アンコモンは かえない
- ランダムの ときは 候補が じゅんばんに 光ってから とまり、「🎲 ランダムで ○○ に きまった」と 出る（`battle.js` の `autoPick`）。AI も おなじ きまりで えらぶ（`ai.js` の `burnTarget`）
- レアの 戦闘中の 効果も 自分で えらぶ（2026-10-27）：「攻撃したとき」は「こうげきする」を おした あと、「敵に 戦闘ダメージを あたえたとき」は ダメージの まえに、あいてを えらぶ（`def.trigTgt` → `battle.js` の `preTrig` → `game.js` の `takePick`）。星見雅・朱鳶・ライカン・エヴリン・ハパトラ・しずかな 刃の 鬼。えらばなかった ときは AI が えらぶ。レアの 宝具も 自分で えらべる
- 鏡流（SR07）の 撃破は いつ おきるか わからない ので、AI が えらぶ まま
- 冒険 200回の シミュレーション：クリア 63% → 61%

## 11. 非同期オンラインバトル（実装ずみ・GAS 版）

イメージは **Backpack Battles**（相手の「スナップショット」と戦う非同期対戦）。GAS 版（`gas/`）で動く。

### 11.1 流れ（決定）

1. 冒険が終わったとき（**クリアしたとき、または途中で負けたとき**）、そのときのデッキを「ゴースト」としてサーバー（GAS ＋ スプレッドシート）に保管する
2. 自分が使うデッキは、**冒険で構築したデッキを3つまで保管** したもの（決定）。保管がいっぱいのときは、冒険のおわりに「どれと入れかえるか／保管しないか」を選ぶ。保管しなくても、ゴーストとしてサーバーには あずける
3. タイトルの「オンライン バトル」で、保管したデッキを選び、ほかのプレイヤーのゴーストと対戦する。相手のデッキはAIが動かす（シミュレーション用のAI `js/engine/ai.js`）
4. 対戦相手は **ランダム**：サーバーにあずけられたゴースト全部から1人（自分のゴーストはのぞく）。データにゴーストがいないとき（つながらないときも）は、見本デッキの「れんしゅう あいて」がランダムに出る
5. 戦った **デッキに点がつく**（決定）：**かち ＋2・ひきわけ ＋1・まけ −1**。**0より下にはならない**。こうさんは まけ。点がつくのは ほかの人のゴーストと戦ったときだけ（れんしゅう あいては点なし）
6. **ランキング**（決定）：デッキの点の **上位20** を、オンライン バトルの画面に「〇〇な〇〇の 白緑デッキ」（持ち主のニックネーム＋2色）で出す。**毎日 7:00 と 17:00（日本時間）に更新**（その時刻のあとで最初に開いた人のときに作りなおす）。同じ点は同じ順位で、ならびは先にその点をとったデッキが上。自分のデッキには「きみの デッキ」
7. 自分のゴーストが勝つと、あとで「きみの ゴーストが ○回 かったよ」と知らせる

### 11.2 対戦のルール（決定）

| 項目 | 内容 |
|---|---|
| 形 | プレイヤー同士の1対1。両方 ライフ20・DM のマナ・MTG の戦闘。先攻はランダム（先攻は1ターンめに引かない） |
| 攻撃先 | 相手プレイヤー（MTG と同じ。塔のように相手のクリーチャーは攻撃できない）。相手はブロックする |
| ひきわけ | おたがい **15ターン** で決着がつかないとき（16ターンめのはじめ）、または 両方のライフが同時に0になったとき。画面のターンは「ターン 3/15」と出す（シミュレーションでは ニクスの嵐で ほぼ起きない） |
| ニクスの 嵐 | 自分の10ターンめから、ターンのはじめにライフを 1・2・3…と失う（盤面が止まって終わらないのを防ぐ。シミュレーションで 決着なし 9% → 0%） |
| ゴーストの動き | 相手のターンは P と E を入れかえて、プレイヤー用のAIとカードの効果をそのまま使う（`js/data/enemies.js` の `pvp`） |
| 画面 | 「あいての よてい」に、攻撃してくるかもしれないクリーチャーのパワーと、ニクスの嵐で失うライフを数で出す（合計は出さない） |

**試作版で省いていること**：ゴーストは、プレイヤーのターンにインスタントを使わない（ブロックだけする）。ゴーストの呪文はプレイヤーの打ち消し呪文で打ち消せない。ゴーストはブロックのあとの強化呪文を使わない。

### 11.3 サーバー（決定：GAS ＋ スプレッドシート。2026-10-27 に スクリプト プロパティから 移した）

| 項目 | 内容 |
|---|---|
| 保管するもの | デッキ20枚、とどいた階、ニックネーム、勝ち・負けの数、作った時刻。プレイヤー本人の情報は保管しない |
| ニックネーム | **自由入力にしない**。定型語を2つ組み合わせる：「〇〇な〇〇」（ゆうかんな ドラゴン）か「〇〇 〇〇」（ほのお ドラゴン）。1つめの言葉で形が決まる（20 × 20 通り）。オンライン バトルの画面の **プルダウン2つ** で選ぶ |
| 安全 | チャットなし。ゴーストだけのやりとりで、相手と直接つながらない |
| 不正 | デッキは「20枚・キャパシティ30点・2色まで・知っているカードだけ」をサーバーでもチェックする |
| 量 | とどいた階ごとに30人まで（古いものから消える。数は「せってい」シートで変えられる） |
| デッキの点 | 「デッキの点」シート（ID・点・ニックネーム・2色・更新時刻）。ゴーストが消えても点は残る。0点のまま30日たったものは消す |

### 11.4 シミュレーション（見本デッキどうし・100回ずつ）

## 12. しゅぎょうと もんしょう（2026-10-24 追加・実装ずみ）

教育アプリとしての 側面を つよく する。くわしくは [`EMBLEMS.md`](EMBLEMS.md)。

| 項目 | 決定 |
|---|---|
| しゅぎょう | タイトルの「もんしょう」から。**60秒** で（2026-10-24 に 3分 → 90秒 → 60秒）1年生の 問題を とく：くりあがりの たし算・くりさがりの ひき算・3つの 数の 計算・10の まとまり・とけい（なんじ・なんじはん）・漢字の 読み・てにをは。まだ ならって いない しゅるいは はずせる |
| ごうかく | **5問 いじょう といて、7割より 多く 正解**（ちょうど 7割は だめ）→ もんしょうポイント ＋3（ぜんぶ 正解なら ＋4）。まちがえた 問題は 答えと いっしょに 見せる |
| もんしょう | スキルツリー（4つの 枝 ＋ ヴァンガード）。🌱 きほんカードの 強化（白 ライフ 3・緑 1/2 など。レベル2 は マナに おいても こうか）、❤ はじめの ライフ（22・24・26）、☀ はじまり（**マリガン**・さいしょから マナ 1つ・はじめの てふだに「たいようの ゆびわ」）、✦ ぴったりで ライフ（＋1・＋2）、♛ **ヴァンガード**（テーロスの 神を 1つ：ライフ・てふだの 数と ターンの はじめの のうりょく）。ぜんぶで 19ポイント。🎴 **パック**（きまぐれな いろ・アンコモン ＋1まい・レジェンド 3ばい・はじめの 旗）と ◆ **いろ**（えらんだ 色が 3ばい 出やすい。2つまで）は パックに 出る カードを かえる。**ぼうけんの まえ**（神々や ジェイスの ことば ＋ 60びょう、ごうかくで ＋1 → もんしょうの 画面で 1かいだけ ボーナス ＋2）と **おわり**（「もっと つよく なりたいか？」ボーナス ＋2）にも しゅぎょうを はさむ（[`EMBLEMS.md`](EMBLEMS.md) 8章） |
| ふりなおし | ついて いる もんしょうを はずして ポイントを もどせる。もどった ポイントは もとの もんしょうが きれる ときまで（12時間は のびない） |
| 時間 | えらんでから **12時間**。ポイントは なくならない |
| あんない | チュートリアルを クリアした あとに「かてなく なったら もんしょうを てに いれよう」（もんしょうの 画面へ 行ける）。冒険で まけた とき、もんしょうが なければ 1行で すすめる |
| つく たたかい | 冒険（塔）の たたかい だけ。オンライン バトル・チュートリアルには つかない |
| つよさ | シミュレーションで きめた（EMBLEMS.md 5章）。1回の ごうかく（3ポイント）で ふつう 61% → 7割 くらい、ぜんぶで 9割 くらい |
| たたかいの 中 | これまで どおり 問題は 出さない（5章） |
