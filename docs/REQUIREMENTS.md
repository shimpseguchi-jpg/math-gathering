# さんすうTCG（仮） 要件定義（たたき台）

小学1〜5年生むけの **算数 × デジタルTCG × デッキ構築型ローグライク**。
カードのテキストは Magic: The Gathering（以下 MTG）、マナの仕組みは デュエル・マスターズ（以下 DM）をベースにする。

- 状態：要件定義中（このファイルは議論のたたき台。**決定** と **提案** と **未決** を分けて書く）
- 置き場所：`mathtcg/`（既存の かずまほ・アルカナンバー と同じく、ブラウザだけで動く素の JavaScript を想定）

---

## 0. 決定事項（ここまでに決まったこと）

| 項目 | 決定 |
|---|---|
| 対象 | 小学1〜5年生 |
| ジャンル | 算数のデジタルTCG、デッキ構築型ローグライク |
| カードテキスト | MTG がベース |
| マナシステム | DM がベース |
| 色 | 赤・青・白・緑の4色 ＋ 無色 |
| アーキタイプ（2色） | 赤青・青白・白緑・緑赤・赤白・青緑 の6種類（4色の2色組み合わせすべて） |
| 白緑 | **召集**（Convoke） |
| 開始時 | 3パック公開。1パック5枚 |
| デッキキャパシティ | レアリティごとの点数（コモン1／アンコモン2／レア3／レジェンド4）の合計が **30点程度** になるように選ぶ |
| 塔 | 5階建て。1階ずつ敵が出る。頂上（5階）にボス |
| 1〜4階の敵 | MTG の **チャレンジ・デッキ** を参考にする |
| 報酬 | 1〜4階の敵を倒すたびに **1パック開封**、**デッキ構築をやり直せる** |

## 1. ゲームの流れ（コアループ）

```
タイトル → 学年（またはうでだめし）を選ぶ
  → 3パック公開（15枚）→ デッキ構築（キャパ30点）
  → 1階 たたかい → 勝ち → 1パック開封 → デッキ組み直し
  → 2階 → … → 4階 → 1パック開封 → デッキ組み直し
  → 5階 ボス → クリア（スコア・ずかん・きろく）
負けたら：冒険おわり（ローグライク）。次の冒険はまた3パックから
```

- 1回の冒険：**30〜45分** を目安（1戦 5〜8分 × 5戦 ＋ 構築）【提案】
- 冒険の途中で中断・再開できる（オートセーブ）【提案】

## 2. マナシステム（DM ベース）

| ルール | 内容 |
|---|---|
| マナチャージ | 自分のターンに1回、手札のカードを1枚 **マナゾーン** に置ける（どのカードでも置ける） |
| マナの色 | マナゾーンのカードは、そのカードの色のマナを1つ出す。無色カードは無色マナ |
| コストの払い方 | コストの数だけマナゾーンのカードをタップする。**そのカードの色のマナを最低1つ** 含める必要がある（DM の文明条件） |
| 2色カード | マナゾーンに **タップして** 置かれる（DM と同じ。置いたターンは使えない） |
| アンタップ | ターンのはじめに、マナゾーンのカードをすべてアンタップ |
| 土地 | **ない**。すべてのカードが呪文・クリーチャーであり、同時にマナにもなる |

> ねらい：「どのカードをマナにして、どれを使うか」という DM らしい悩みを残しつつ、MTG の土地事故をなくす。

### 2.1 対戦の基本ルール【提案】

- ライフ：プレイヤー **20**（MTG・チャレンジ・デッキに合わせる）。DM のシールドは使わない
- 初期手札：5枚。先攻1ターン目はドローなし
- カードタイプ：クリーチャー／呪文（ソーサリー相当）／すばやい呪文（インスタント相当）／アイテム（アーティファクト・エンチャント相当）
- 戦闘：MTG と同じく「攻撃 → ブロック → ダメージ」。小学生向けに **ブロックの割り振りは1対1のみ**（複数ブロックなし）にして簡単にする
- インスタントのタイミング：相手ターンに使えるのは「ブロック宣言のとき」「相手が呪文を唱えたとき」の2つの決まった場面だけにして、UI で「つかう？」と聞く（スタックの理解を要求しない）

## 4. 色とアーキタイプ

### 4.1 色の役割（MTG のカラーパイを子ども向けに）

| 色 | 性格 | 得意なこと |
|---|---|---|
| 赤 | いきおい・ほのお | ダメージ呪文、速攻、パワーアップ |
| 青 | ちえ・みず・そら | カードを引く、飛行、タップ・とめる |
| 白 | なかま・ひかり | 小さいクリーチャーをたくさん、回復、守り |
| 緑 | しぜん・おおきさ | 大きいクリーチャー、マナをふやす、到達 |
| 無色 | どうぐ・きかい | どのデッキにも入る。マナの色条件を満たさないので入れすぎ注意 |

### 4.2 アーキタイプ案（白緑以外は提案）

算数の単元と結びつけて、**アーキタイプを使いこなすと算数の力も伸びる** 形にする。

| 2色 | アーキタイプ（MTG のメカニズム） | 遊び方 | 結びつく算数 |
|---|---|---|---|
| **白緑** | **召集**（決定） | 小さいクリーチャーを並べ、タップしてマナの代わりにし、重いカードを早く出す | たし算・**10のまとまり**（マナ＋クリーチャー数＝コスト） |
| 赤青 | **X呪文＋果敢** | 呪文を連続で唱えてクリーチャーを強化。X を決めて呪文を撃つ | **□を使った式**（Xはいくつ？）・たし算の積み重ね |
| 青白 | **飛行＋割り振り** | 空から攻める。ダメージやカウンターを「好きなように割り振る」呪文 | **わり算・等分**（6点を3体に分けると？） |
| 緑赤 | **獰猛（パワー4以上）** | 大きいクリーチャーで殴る。「パワーを2倍」などの呪文 | **大小比較**・**かけ算（倍）** |
| 赤白 | **大隊・横並び** | トークンをたくさん出して一斉攻撃。「攻撃しているクリーチャー1体につき＋1」 | **かけ算（同じ数ずつ）**・九九 |
| 青緑 | **＋1/＋1カウンター＋マナブースト** | マナゾーンを増やし、カウンターを積んで育てる（DM の緑ブーストとも相性◎） | **大きな数・くり返しのたし算**、5年：倍数 |

- 各アーキタイプに **アンコモンの2色「道しるべ」カード** を1枚ずつ（MTG のドラフト・サイクル）【提案】
- 単色でも組めるように、各色に単色で完結するコモンを入れる

## 5. 算数の入れ方（**最重要の未決事項**）

カードゲームとしての面白さを壊さずに算数を入れる方法の候補。

| 案 | 内容 | 長所 | 短所 |
|---|---|---|---|
| **A. けいさんボーナス**（推奨） | 攻撃・呪文の解決時に「なんてんダメージ？」と式が出る。正解するとボーナス（＋1点、ひらめき演出など）。**まちがえても普通に解決** | テンポを崩さない。かずまほ の「よそう」で実績あり | 計算をスキップする子もいる |
| B. カードの効果そのものが算数 | 「パワーを2倍」「X＝マナの数×2」「偶数のクリーチャーは…」など。答えを入力させず、自動計算して表示 | 自然に式に触れる | 計算する機会は受け身 |
| C. コストの支払いが算数 | マナに数字があり、ちょうどの組み合わせで払う | 毎ターン必ず計算する | DM のマナシステムと別物になる。テンポが悪い |
| D. 塔の階のあいだに算数イベント | パック開封前にクイズ（正解でパックが1枚増えるなど） | 実装が簡単 | ゲームと算数が分離する |

推奨：**B を土台に A を重ねる**（全カードの効果は数で書き、要所で計算を入力させる）。C は採用しない。

### 5.1 学年ごとの出題範囲【提案】

| 学年 | 主な内容 |
|---|---|
| 1年 | 20までのたし算・ひき算、大小比較、10のまとまり |
| 2年 | 2けた・3けたのたし算・ひき算、九九 |
| 3年 | わり算、□を使った式、あまり |
| 4年 | 大きな数、2けたでわるわり算、がい数 |
| 5年 | 倍数・約数、偶数・奇数、小数のかけ算 |

- カードの数値は学年で変えない（ゲームバランスを1つにする）。**出題の形** を学年で変える（例：同じ「3体×＋2」でも 1年は 2＋2＋2、2年以上は 3×2）
- 学年選択は アルカナンバー の「まほうの うでだめし」方式も流用できる

## 6. パックとデッキ構築

### 6.1 パックの中身（**未決**）

1パック5枚の内訳は未決。案：

| 案 | 内訳 | 1パックの点数 |
|---|---|---|
| A | コモン3・アンコモン1・レア1（8枚に1回レジェンド） | 8〜9点 |
| B | コモン2・アンコモン2・レア1（8枚に1回レジェンド） | 9〜10点 |

- B の場合、最初の3パックで約27〜30点。**最初はほぼ全部入る** → 開封が進むと「選ぶ」悩みが増えていく
- パックは **色が偏りすぎない** ように抽選（1パックに最低2色）【提案】

### 6.2 デッキの条件【提案】

- キャパシティ：**30点**（未決：階を上がるごとに＋3点など増やすか）
- 枚数：**20枚ちょうど**。点数で選んだカードが20枚に満たない分は、**0点の「きほんカード」**（各色＋無色、小さな効果つきのマナ用カード）で自動的に埋める
  - DM は全カードがマナになるので、きほんカードは「土地」の代わり
- 同じカードは何枚でも入れてよい（パックから出た枚数まで）
- 「おまかせ」ボタン：色の多い順に自動で組む（1〜2年生向け）

## 7. 塔（5階）

### 7.1 敵の仕組み（MTG チャレンジ・デッキ共通ルール）

- 敵は **マナを使わない**。敵のターンにライブラリーの一番上を公開して、そのまま唱える（自動で動くので AI が不要・子どもにも先が読みやすい）
- 敵のカードはすべて無色・マナ総量0
- 敵に「カードを引かせる・捨てさせる」など実行できない効果は無視
- **英雄カード**：プレイヤーは開始時に英雄カード（補助のエンチャント）を最大2枚出せる → 本作では **冒険の最初に選ぶ「おまもり」** に置きかえる【提案】
- **英雄の報酬**：敵のパーマネントを倒すとプレイヤーにご褒美（ライフ回復など）がある → そのまま採用（倒すと嬉しい）

### 7.2 階ごとの敵（案）

チャレンジ・デッキは3種類しかないので、4つめはオリジナル。

| 階 | 元ネタ | 勝利条件 | 特徴 | 子ども向けの調整 |
|---|---|---|---|---|
| 1階 | **ハイドラとの対峙** | ターン終了時に敵の **頭が0** | 開始時に頭2本（イージー）。頭が1本倒れるたび、ライブラリーから2枚公開して頭を出す | 頭2本スタート。わかりやすい「全部たおせ」 |
| 2階 | **大群との戦い**（ミノタウルス） | 敵のライブラリーが0 **かつ** クリーチャー0 | 敵はライフがなく、ダメージ1点ごとにライブラリーを1枚削る。敵のクリーチャーは速攻 | プレイヤーの最初の追加ターンを多めに。「のこり枚数」を大きく表示 |
| 3階 | **オリジナル**（例：ゴーレムの こうじょう） | 「工場」（アイテム）を壊す | 工場が毎ターン ゴーレムを作る。工場は数字の鍵（例：ちょうど6点のダメージ）でしか壊れない | 算数の「ぴったり」を勝利条件にする |
| 4階 | **神を討て**（ゼナゴス） | 神が戦場を離れる | 手下（歓楽者）が1体でもいる限り、神は戦場を離れない。手下を全部倒してから神を倒す | 手下の数を常に表示 |
| 5階 | **ボス（オリジナル）** | 未決 | 1〜4階のルールを組み合わせたフェーズ制（例：頭→大群→本体） | 未決 |

- 階ごとに **複数の候補からランダム**（例：1階は「ハイドラ」か「ちいさな大群」）にしてローグライク感を出す案もある【提案】
- 難易度（イージー／ノーマル／ハード）はチャレンジ・デッキと同じく「初期の頭の数」「公開枚数」で調整する
