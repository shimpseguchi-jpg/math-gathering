# マスマティック・ザ・ギャザリング 要件定義

小学1〜5年生むけの **算数 × デジタルTCG × デッキ構築型ローグライク**。
カードのテキストは Magic: The Gathering（以下 MTG）、マナの仕組みは デュエル・マスターズ（以下 DM）をベースにする。

- 状態：**要件定義 第1版**（主な未決事項はすべて決定。【提案】と書いたところは、変更がなければその内容で作る）
- 置き場所：`mathtcg/`（既存の かずまほ・アルカナンバー と同じく、ブラウザだけで動く素の JavaScript を想定）

---

## 0. 決定事項（ここまでに決まったこと）

| 項目 | 決定 |
|---|---|
| 対象 | 小学1〜5年生 |
| ジャンル | 算数のデジタルTCG、デッキ構築型ローグライク |
| カードテキスト | MTG がベース。キーワード能力・カードタイプ・用語は **MTG の名前のまま**、漢字には読み（ふりがな）をつける |
| マナシステム | DM がベース |
| 色 | 赤・青・白・緑の4色 ＋ 無色 |
| アーキタイプ（2色） | 赤青・青白・白緑・緑赤・赤白・青緑 の6種類（4色の2色組み合わせすべて） |
| 白緑 | **召集**（Convoke） |
| ほかの5アーキタイプ | 4.2 の案で決定（赤青＝X呪文＋果敢、青白＝飛行＋割り振り、緑赤＝獰猛、赤白＝大隊、青緑＝カウンター＋マナブースト） |
| 算数の入れ方 | **問題は出さない。勝つために考えると、自然に計算する**（5章）。けいさんボーナス（A）は やめた（2026-10） |
| 数を意識する能力 | 各アーキタイプに MTG の能力（圧倒・激励・鼓舞・集団戦術・教導・訓練・キッカー・増呪・待機・Lvアップ）と、オリジナルの **ぴったり** を入れる（3.2）。英雄譚は第2弾の候補 |
| 画面が計算しない | 攻撃を選んでいる最中は、合計を **出さない**（攻撃のあとに「3 ＋ 2 ＝ 5点」と結果だけ見せる）。敵の予定も数を ならべて出し、合計は出さない |
| 4色か5色か | **4色版** で作る。5色版（黒）は将来の拡張の候補として 4.3 に残す |
| 開始時 | 3パック公開。1パック5枚 |
| デッキの制限 | **2色まで（無色は自由）＋ デッキキャパシティ**（レアリティ点数の合計30点程度）（6.2） |
| 塔 | 5階建て。1階ずつ敵が出る。頂上（5階）にボス |
| 1〜4階の敵 | MTG の **チャレンジ・デッキ** を参考にする |
| ライフ | **20**。DM のシールドはなし |
| タイトル | **マスマティック・ザ・ギャザリング** |
| 世界観 | **MTG と同じ**（1.1） |
| カードの種類数 | 最初のリリースは **126種**（4.4） |
| 冒険をまたいで残るもの | **ずかん** だけ（8.1）。カードやおまもりの解放はなし |
| 負けたとき | **1回だけコンティニュー** できる（1.2） |
| 報酬 | 1〜4階の敵を倒すたびに **1パック開封**、**デッキ構築をやり直せる** |

## 1. ゲームの流れ（コアループ）

```
タイトル → 学年（またはうでだめし）を選ぶ
  → 3パック公開（15枚）→ デッキ構築（制限は 6.2）
  → 1階 たたかい → 勝ち → 1パック開封 → デッキ組み直し
  → 2階 → … → 4階 → 1パック開封 → デッキ組み直し
  → 5階 ボス → クリア（スコア・ずかん・きろく）
負けたら：1回だけコンティニュー（1.2）。2回目に負けたら冒険おわり。次の冒険はまた3パックから
```

- 1回の冒険：**30〜45分** を目安（1戦 5〜8分 × 5戦 ＋ 構築）【提案】
- 冒険の途中で中断・再開できる（オートセーブ）【提案】

### 1.1 世界観（決定：MTG と同じ）

- プレイヤーは **プレインズウォーカー**。次元を渡り歩く魔法使いとして塔に挑む
- 舞台の次元は **テーロス** を推奨【提案】。1・2・4階の元ネタのチャレンジ・デッキ（ハイドラ・ミノタウルスの大群・ゼナゴス）がすべてテーロスのものなので、そのままつながる
- 4色（赤青白緑）のカラーパイ・カードの雰囲気・フレーバーテキストも MTG に合わせる。**用語は原作のまま**（決定）。ただし、グロテスク・残酷な用語だけは言いかえる（3.5）
- **注意**：タイトル・世界観・キャラクター名は Wizards of the Coast の MTG を下敷きにした **非公式のファンメイド** になる。アイドル迷宮（仮）と同じく **個人・身内で楽しむ範囲** で作る前提とし、一般公開や学校での配布をするときは、名前・固有名詞をオリジナルに差しかえる（カード名・敵の名前はデータで差しかえられるようにしておく）

### 1.2 コンティニュー（決定：1回だけ）

| 項目 | 内容 |
|---|---|
| 回数 | 冒険1回につき **1回だけ**（全学年共通） |
| どこから | 負けた階の **はじめから**（ボスは1段階めから）【提案】 |
| 状態 | ライフ20に戻る。デッキの組み直しもできる。持っているカードは減らない【提案】 |
| 敵 | 同じ敵（3階はランダムを引き直さない） |
| スコア | コンティニューすると減点（例：最終スコア −20%）【提案】 |
| 表示 | 塔のマップに「のこり コンティニュー ○回」を表示 |

## 2. マナシステム（DM ベース）

| ルール | 内容 |
|---|---|
| マナチャージ | 自分のターンに1回、手札のカードを1枚 **マナゾーン** に置ける（どのカードでも置ける） |
| マナの色 | マナゾーンのカードは、そのカードの色のマナを1つ出す。無色カードは無色マナ |
| コストの払い方 | コストの数だけマナゾーンのカードをタップする。**そのカードの色のマナを最低1つ** 含める必要がある（DM の文明条件） |
| 2色カード | マナゾーンに **タップして** 置かれる（DM と同じ。置いたターンは使えない） |
| アンタップ | ターンのはじめに、マナゾーンのカードをすべてアンタップ |
| 土地 | **ない**。すべてのカードが呪文・クリーチャーであり、同時にマナにもなる |

> ねらい：「どのカードをマナにして、どれを使うか」という DM らしい悩みを残しつつ、MTG の土地事故をなくす。

### 2.1 対戦の基本ルール【提案】

- ライフ：プレイヤー **20**（決定。MTG・チャレンジ・デッキに合わせる）。DM のシールド・S・トリガーは **なし**（決定）
- 手札：初期手札5枚。**自分のターンのはじめに、手札が5枚になるまで引く**（遊戯王ラッシュデュエルと同じ。決定）。山札が残り5枚より少なくなると、画面の「やまふだ」に小さく「もうすぐ なくなる」と出る
- カードタイプ：MTG と同じ。クリーチャー／インスタント／ソーサリー／エンチャント／アーティファクト（土地はない）
- 戦闘：MTG と同じく「攻撃 → ブロック → ダメージ」。小学生向けに **ブロックの割り振りは1対1のみ**（複数ブロックなし）にして簡単にする
- インスタントのタイミング：相手ターンに使えるのは「ブロック宣言のとき」「相手が呪文を唱えたとき」の2つの決まった場面だけにして、UI で「つかう？」と聞く（スタックの理解を要求しない）
- 山札切れ【提案・要決定】：ライブラリーが0枚のときにカードを引くなら、**墓地をシャッフルしてライブラリーにする**（負けにしない）。デッキが20枚と少ないため。MTG どおり「引けなければ負け」にすると、ふつうのクリア率が 55% → 22% に下がる（[`SIMULATION.md`](SIMULATION.md)）
- 戦場の上限：クリーチャーは各陣営30体まで（画面に並べられる数。こえるトークンは出ない）

## 3. カードテキスト（MTG ベース）

### 3.1 表記ルール

- 文の形は MTG の日本語テキストに合わせる（例：「〜が戦場に出たとき、カードを1枚引く。」）
- **漢字（決定）**：3年生までに習う漢字（学年別漢字配当表の1〜3年・440字）だけを使う。それ以外の漢字は
  - 画面のことば（ボタン・説明・コーチ・ログ・ことばの説明の文）は **ひらがな**（ことばごと：戦場 → せんじょう、攻撃 → こうげき）
  - カードの文章（名前・タイプ・テキスト・敵のカード）は **ふりがな**（「与（あた）える」「墓地（ぼち）」。小さいカードの名前・ログの名前にもつける）
  - チェック：`node mathtcg/tools/kanji.mjs`（ふりがなのない習わない漢字を出す）
- 文字表示は既存アプリと同じ3モード：**ひらがな／漢字（ふりがな）／漢字**【将来の候補】
- キーワード能力・カードタイプ・用語は **MTG の名前のまま**（決定）。漢字には **ふりがな** をつける（ゲーム内はルビ、ドキュメントでは「飛行（ひこう）」のように（）で読みを書く）
- キーワードにはアイコンもつけ、長押しで説明を出す

### 3.2 キーワード能力（決定：MTG のまま）

| キーワード（読み） | 英語 | 主に使うアーキタイプ | 説明（長押しで出す文） |
|---|---|---|---|
| 飛行（ひこう） | Flying | 青白 | 飛行か到達を持つクリーチャーでしかブロックできない |
| 到達（とうたつ） | Reach | 緑 | 飛行を持つクリーチャーをブロックできる |
| 速攻（そっこう） | Haste | 赤 | 出たターンから攻撃できる |
| 警戒（けいかい） | Vigilance | 白 | 攻撃してもタップしない |
| 先制攻撃（せんせいこうげき） | First strike | 白・赤 | ふつうのクリーチャーより先にダメージを与える |
| 二段攻撃（にだんこうげき） | Double strike | 赤白・緑赤 | 先制攻撃とふつうのダメージの2回ダメージを与える（パワー × 2） |
| トランプル | Trample | 緑 | ブロックしたクリーチャーを倒して余ったダメージを、相手に与える |
| 防衛（ぼうえい） | Defender | 白 | 攻撃できない |
| 絆魂（はんこん） | Lifelink | 白 | 与えたダメージと同じだけライフを得る |
| 接死（せっし） | Deathtouch | 緑 | 1点でもダメージを与えたクリーチャーを破壊する |
| 瞬速（しゅんそく） | Flash | 青 | インスタントと同じタイミングで出せる |
| 破壊不能（はかいふのう） | Indestructible | 神 | 破壊されない（ダメージでも倒れない） |
| 召集（しょうしゅう） | Convoke | 白緑 | クリーチャーをタップしてコストを払える |
| 割り振る（わりふる） | Divide | 青白 | 合計の数を、選んだ対象に分ける |
| 勇壮（ゆうそう） | Heroic | 青白・赤白 | このクリーチャーを対象にする呪文を唱えるたび、効果が出る |
| 占術（せんじゅつ） | Scry | 青 | ライブラリーの上を見て、いらないカードを一番下に置く |
| 大隊（だいたい） | Battalion | 赤白 | これとほかの2体以上が一緒に攻撃するたび、効果が出る |
| 果敢（かかん） | Prowess | 赤青 | クリーチャーでない呪文を唱えるたび、ターン終了時まで ＋1/＋1 |
| 獰猛（どうもう） | Ferocious | 緑赤 | パワー4以上のクリーチャーがいるなら、効果が出る |
| 怪物化（かいぶつか） | Monstrosity | 緑赤・青緑 | コストを払うと ＋1/＋1カウンターが置かれて「怪物」になる（1回だけ） |
| 湧血（ゆうけつ） | Bloodrush | 緑赤 | 手札から捨てて、攻撃しているクリーチャーを強くする |
| 進化（しんか） | Evolve | 青緑 | パワーかタフネスが これより大きいクリーチャーが出るたび、＋1/＋1カウンターを置く |
| 増殖（ぞうしょく） | Proliferate | 青緑 | カウンターが置かれているものを選び、同じ種類のカウンターをもう1個ずつ置く |
| 装備（そうび） | Equip | 無色 | コストを払って、装備品を自分のクリーチャーにつける |
| 圧倒（あっとう） | Formidable | 白緑・緑赤 | 自分のクリーチャーのパワーの合計が8以上なら、効果が出る |
| 激励（げきれい） | Strive | 青白 | 対象を好きな数だけ選べる。2つめからの対象1つにつき、マナが多くかかる |
| 鼓舞（こぶ） | Bolster | 白 | タフネスがいちばん小さい自分のクリーチャーに ＋1/＋1カウンターを置く |
| 集団戦術（しゅうだんせんじゅつ） | Pack tactics | 赤白 | 攻撃しているクリーチャーのパワーの合計が6以上なら、効果が出る |
| 教導（きょうどう） | Mentor | 赤白 | 攻撃したとき、これよりパワーが小さい攻撃クリーチャー1体に ＋1/＋1カウンター |
| 訓練（くんれん） | Training | 緑赤 | これよりパワーが大きいクリーチャーと攻撃すると ＋1/＋1カウンター |
| キッカー | Kicker | 赤青・赤白 | 唱えるときにマナを多く払うと、効果が強くなる |
| 増呪（ぞうじゅ） | Escalate | 赤青・赤白 | モードを好きな数だけ選べる。2つめからのモード1つにつき、マナが多くかかる |
| 待機（たいき） | Suspend | 赤青・青緑 | 少しのマナで手札から待機させる。時間カウンターが毎ターン1つへり、0で ただで唱える |
| Lvアップ | Level up | 青緑 | マナを払ってレベルを上げる。レベルで強さが変わる |
| **ぴったり**（オリジナル） | − | 全色 | 敵のクリーチャーを、タフネスと ちょうど同じダメージで倒したとき（あまり0）。何体かの合計でもよい |

| 用語（読み） | 意味 |

### 3.5 言いかえる言葉（決定）

用語・カード名・クリーチャー・タイプは **原作（MTG 日本語版）のまま** にする。グロテスク・残酷で小学生に不適切な言葉だけ、次のように言いかえる。

| 原作 | 本作 | 理由 |
|---|---|---|
| 生け贄（いけにえ）に捧（ささ）げる（sacrifice） | 墓地（ぼち）に置く | 残酷 |
| 虐殺のトーテム像（Massacre Totem） | 戦（いくさ）のトーテム像 | 残酷 |
| フォベロスの肉裂き（Phoberos Reaver） | フォベロスの暴（あば）れ者（もの） | グロテスク |
| ミノタウルスの流血探し（Minotaur Goreseeker） | ミノタウルスの獲物（えもの）探（さが）し | グロテスク |
| 引き千切り（Rip to Pieces） | 力（ちから）まかせの一撃（いちげき） | グロテスク |
| 頭二つによる引き裂き（Torn Between Heads） | 頭（あたま）二（ふた）つの はさみうち | グロテスク |
| 英雄の丸呑み（Swallow the Hero Whole） | 英雄（えいゆう）への かみつき | グロテスク |

- 死亡・破壊・墓地・死者の神・冥界・ゾンビ などのふつうの用語は、そのまま使う
- 新しいカードを足すときも、この表に足していく

## 4. 色とアーキタイプ

### 4.1 色の役割（MTG のカラーパイを子ども向けに）

| 色 | 性格 | 得意なこと |
|---|---|---|
| 赤 | いきおい・ほのお | ダメージ呪文、速攻、パワーアップ |
| 青 | ちえ・みず・そら | カードを引く、飛行、タップ・とめる |
| 白 | なかま・ひかり | 小さいクリーチャーをたくさん、回復、守り |
| 緑 | しぜん・おおきさ | 大きいクリーチャー、マナをふやす、到達 |
| 無色 | どうぐ・きかい | どのデッキにも入る。マナの色条件を満たさないので入れすぎ注意 |

### 4.2 アーキタイプ（4色版・決定）

算数の単元と結びつけて、**アーキタイプを使いこなすと算数の力も伸びる** 形にする。

| 2色 | アーキタイプ（MTG のメカニズム） | 遊び方 | 結びつく算数 |
|---|---|---|---|
| **白緑** | **召集**（決定）＋ **圧倒** | 小さいクリーチャーを並べ、タップしてマナの代わりにし、重いカードを早く出す。パワーの合計8で圧倒 | たし算・**10のまとまり**・繰り上がり（マナ＋なかま＝コスト、3＋2＋2＋1＝8） |
| 赤青 | **X呪文＋果敢** ＋ **キッカー・増呪・待機** | 呪文を連続で唱えてクリーチャーを強化。X を自分で決めて呪文を撃つ。マナの のこりを考えて唱える | **□を使った式**（X ＋ 1 ＝ マナ）・マナの のこり・先読み |
| 青白 | **飛行＋割り振り** ＋ **激励・鼓舞** | 空から攻める。ダメージやカウンターを「好きなように割り振る」呪文。対象を ふやすほど マナが かかる | **分解・わり算**（4 ＝ 1＋3）・かけ算（1体ごとに＋1マナ）・大小比較 |
| 緑赤 | **獰猛（パワー4以上）** ＋ **訓練・ぴったり** | 大きいクリーチャーで殴る。「パワーを2倍」などの呪文。ちょうどの数で倒す | **大小比較**・**かけ算（倍）**・ひき算 |
| 赤白 | **大隊・横並び** ＋ **集団戦術・教導** | トークンをたくさん出して一斉攻撃。「攻撃しているクリーチャー1体につき＋1」。パワーの合計6で集団戦術 | **かけ算（同じ数ずつ）**・九九・たし算・大小比較 |
| 青緑 | **＋1/＋1カウンター＋マナブースト** ＋ **Lvアップ・待機** | マナゾーンを増やし、カウンターやレベルを積んで育てる（DM の緑ブーストとも相性◎） | **大きな数・くり返しのたし算**、5年：倍数 |

## 5. 算数の入れ方（決定：問題は出さない。2026-10 に変更）

ゲームの途中に計算問題を出すのではなく、**勝つために考えると、自然に計算する** ゲームにする。MTG や DM で子どもが頭の中でやっていることを、そのまま算数にする。

| 場面 | 頭の中でしていること |
|---|---|
| 敵のライフは のこり10。手もとに パワー 5・2・3・4 | 足して10になる組み合わせ探し（10のまとまり・繰り上がり） |
| マナが4つ使える。手札には 5マナのカードが2枚 | どれをマナに置けば、次のターンに何が出せるか（たし算・先読み） |
| 4/3 で 2/5 に攻撃するとどうなる？ | 大小比較・ひき算 |
| トランプル 7 で、タフネス 3 にブロックされた | のこり 7 − 3 ＝ 4 が届く（ひき算） |
| 6点を3体に割り振る | わり算・等分 |
| ゴーレム工場の鍵 7（ちょうど同じ数で壊れる） | ぴったりの組み合わせ探し |

### 5.1 きまり

- **問題の画面は出さない**（けいさんボーナス・抜き打ちテストは やめた）
- **画面が かわりに計算しない**：攻撃するクリーチャーを選んでいる最中は、パワーの合計を出さない（決定：A）。攻撃のあとに「3 ＋ 2 ＝ 5点」「ぴったり！」と **結果だけ** 見せる
- 敵の予定は、数を ならべて出す（「3体で 攻撃（パワー 3・2・4）」）。合計は出さない
- X・割り振り・激励・増呪・キッカー は、子どもが **自分で数を決める**（X は −／＋ で選ぶ。マナが足りなければ「マナが たりない」とだけ言う）
- **数を意識する能力** をアーキタイプごとに入れる（3.2・4.2・`cards/README.md`）
- **ぴったり**：敵のクリーチャーを タフネスと ちょうど同じダメージで倒すと「ぴったり！」。ぴったりで得をするカードもある。回数は冒険の きろく に残る

### 5.2 学年

- 学年の設定は いったん なくした（問題を出さないため）
- 将来の案：学年で **出てくる数の大きさ** を変える（1年はライフ20・パワー1〜5、高学年は「×2」「半分」「割り振る」が多い色、など）。ゲームバランスが変わるので、やるときはシミュレーションで確かめる

| 学年 | 自然に出てくる算数 |
|---|---|
| 1年 | 20までのたし算・ひき算、大小比較、10のまとまり（召集・圧倒） |
| 2年 | 2けたのたし算・ひき算、九九（全体強化・大隊） |
| 3年 | わり算、□を使った式、あまり（割り振る・X呪文） |
| 4年 | 大きな数（原初のハイドラ） |
| 5年 | 倍数・偶数・奇数（どんどん2ばい・クルフィックス） |

## 6. パックとデッキ構築

### 6.1 パックの中身（決定：1パック8枚）

#### 5枚で足りるか（シミュレーション）

「2色まで」の制限があると、パックから出たカードのうち **デッキに入れられるのは半分くらい** になる。
1パックの枚数ごとに、いちばん多く集まった2色（＋無色）の枚数と点数を出した（4色が各20%・2色カード10%・無色10%、レアは各パック1枚（5枚＝C2・U2・R1、6枚＝C3・U2・R1、8枚＝C4・U3・R1、10枚＝C5・U4・R1）、4000回の平均。サプライズ・レジェンドを入れても数字はほぼ変わらない。`mathtcg/tools/packsim.py`）。

| 1パックの枚数 | 開始時（3パック） | 2階クリア後（5パック） | ボス戦の前（7パック） |
|---|---|---|---|
| **5枚** | 10枚・19点 | 16枚・30点 | 22枚・40点 |
| 6枚 | 12枚・20点 | 19枚・32点 | 26枚・44点 |
| **8枚** | 15枚・26点 | 25枚・41点 | 34枚・55点 |
| 10枚 | 19枚・31点 | 30枚・49点 | 41枚・67点 |

5枚だと：

- **開始時に使えるカードが10枚しかない**。デッキ20枚のうち半分が きほんカード になり、最初の戦いが単調になる
- キャパシティ30点に届くのが **3階になってから**。それまでは「選ぶ」悩みがほとんどない
- ボス前でも 22枚・40点 から 30点ぶんを選ぶだけで、悩みは小さい

#### 決定：1パック8枚

| レアリティ | 枚数 |
|---|---|
| コモン | 4 |
| アンコモン | 3 |
| レア | 1（8パックに1回、レジェンドになる） |

**サプライズ・レジェンド**：低い確率で、コモン1枚がレジェンドに変わる（MTG のフォイル枠のようなおまけ）。

| 項目 | 内容 |
|---|---|
| 確率 | **1パックにつき 1/20（5%）**（決定） |
| 冒険1回（7パック）で1回以上出る確率 | 約30% |
| 冒険1回で出るレジェンドの平均 | 約1.2枚（コモンが変わらない場合は約0.9枚） |
| レアもレジェンドになり、1パックに2枚出る確率 | 約0.6%（160パックに1回） |
| 演出 | コモンのはずのカードをめくると光って変わる「！？」演出 |

- 確率の候補：1/16 なら冒険1回で約36%、1/30 なら約21%
- レジェンドは4点なので、キャパシティ30点のなかで「入れるか」の悩みが増える（強すぎるだけのおまけにはならない）

#### 塔の ごほうびパック（決定）

1〜4階を倒して あけるパックは、少しずつ 良くなる（`js/engine/run.js` の `REWARD`・`openPack`）。最初の3パックは ふつう。

| 項目 | 内容 |
|---|---|
| レアリティが 上がる | クリアした階 1つにつき：コモン枠が アンコモンに +5%、アンコモン枠が レアに +4%、レアが レジェンドに +4%、サプライズ +1% |
| 例：4階クリア後 | レジェンドの出る率（レア枠）12.5% → 28.5%、サプライズ 5% → 9% |
| よく使う色 | デッキで いちばん多い色（きほんカードを のぞく）の カードが 2倍 出やすい |
| 表示 | パックを あける前に「レジェンド ○%・○色が 出やすい」を出す |

シミュレーション（ふつう）：クリア率 55% → 約60%。

- 開始時に 約15枚・26点 → **最初のデッキはほぼ全部入る**（最初から悩ませすぎない）
- 1階クリア後（4パック）にキャパシティ30点をこえ、**そこから毎回「選ぶ」悩みが出る**
- ボス前は 約34枚・55点 から30点ぶんを選ぶ → しっかり取捨選択になる
- 開封は1枚ずつめくる演出が基本。8枚は長いので「ぜんぶ めくる」ボタンもつける
- パックは **色が偏りすぎない** ように抽選（1パックに4色すべてを最低1枚）【提案】

### 6.2 デッキの制限（決定：2色まで ＋ デッキキャパシティ）

| ルール | 内容 |
|---|---|
| 色 | デッキに入れられる色は **2色まで**。無色は自由。2色カードは、その2色を選んだときだけ入る |
| デッキキャパシティ | レアリティ点数（コモン1／アンコモン2／レア3／レジェンド4）の合計が **30点以下** |
| きほんカード | 0点。キャパシティを使わない |

- 色を決めると持っているカードの半分くらいが入らなくなり、残りから30点ぶんを選ぶ、という2段階の取捨選択になる
- 2色の制限は MTG のドラフト・アーキタイプと一致し、DM のマナの色条件とも相性が良い（色が少ないほどマナが安定する）
- 点数の合計はたし算の練習にもなる。画面では「のこり ○点」のメーターと、カードを入れる前に「入れると のこり ○点」を見せて、1〜2年生でも選べるようにする
- 検討したほかの方式（レアリティ枠、コストの合計、パックから選んで取る、持てる枚数の上限）は不採用

共通のルール：

- デッキは **20枚ちょうど**（決定）。足りない分は0点の「きほんカード」（各色＋無色、小さな効果つきのマナ用カード）で自動的に埋める（DM は全カードがマナになるので、土地の代わり）
- 同じカードは、パックから出た枚数まで入れてよい
- 「おまかせ」ボタン：いちばん多い2色で自動で組む（1〜2年生向け）

### 7.3 5階：ボス「エレボス」（3段階、決定）

ボスは テーロスの死者の神 **エレボス**（決定）。塔の頂上は冥界につながっていて、1〜4階で出てきたルールを順番に使う。

- 4階のゼナゴス（赤緑の神）から、5階のエレボス（黒の神）へ「神をたおして、さらに上の神へ」の流れになる
- 用語は原作のまま（死者の神・冥界・ゾンビ など）。グロテスク・残酷な言葉だけ言いかえる（3.5）

| 段階 | 元にするルール | 勝利条件（次の段階に進む条件） | 内容 |
|---|---|---|---|
| 1 | ハイドラ | **冥界の番犬の頭が0** | 頭がたくさんある番犬がエレボスの門を守る。頭2本で始まり、頭が倒れるとライブラリーから新しい頭が出る |
| 2 | 神を討て | **エレボスの手下が0** | 冥界の住人たちが現れる。手下が1体でもいる限り、エレボスには攻撃もダメージもできない |
| 3 | 本体 | **エレボスのライフが0** | エレボスにライフ（例：15）がある。毎ターン2枚公開して唱える、いちばん強い段階。エレボスらしく「プレイヤーがライフを払う」「墓地のクリーチャーが敵として戻る」カードを入れる |

- **段階のあいだ**：プレイヤーの場・手札・マナゾーン・ライフはそのまま引きつぐ。ボスの場は段階ごとに入れかわる
- **段階が変わるときのごほうび**：ライフを3点得て、カードを1枚引く【提案】
- 段階が変わるたびに見た目・音楽を変え、「だい2だんかい！」の演出を入れる
- 長くなりすぎないように、ボス戦全体で 10〜12分 をめやすにする（ほかの階の1.5〜2倍）
- 負けたときは、どの段階まで進んだかを スコア に入れる（コンティニューすると1段階めからやり直し）

4. デッキ構築（空いている枠・残り点数の表示、色の割合グラフ、おまかせボタン）

### 8.0 チュートリアル（決定：白緑 召集＋圧倒）

はじめての人は、タイトルで「チュートリアル」が いちばん上に出る（2回めからは下に。いつでもやり直せる）。

- 場所：**メレティスの 訓練場**。あいては「訓練の まと」（0/10・ブロックしない）と「わらの 兵士」（3/3・2回めの敵のターンから攻撃）
- デッキ：白緑の きまった手札（緑のきほんカード・警報の かね・森の ちいさな エルフ・森の 大ワーム・生きている トーテム）、マナゾーンに2枚から
- 1つずつ コーチが案内し、押すところが光る。ほかを押すと「光っている ところを タップしよう」
- 計算の問題は出さない。考える場面だけを用意する

| ターン | すること | 自然に出てくる算数 |
|---|---|---|
| 1 | マナを置く → 警報の かね（兵士2体）→ エルフ | マナ 3 ＝ 2 ＋ 1 |
| 2 | マナを置く → 召集で 森の 大ワーム（コスト7） | マナ 4 ＋ なかま □ ＝ 7 |
| 敵 | わらの 兵士（パワー3）を 大ワーム（タフネス5）で ブロック | 5 と 3 の 大小比較 |
| 3 | 生きている トーテム（圧倒なら カウンター2個）→ まとに 攻撃 | 5＋1＋1＋1 ≧ 8？／7＋1＋1＋1 ＝ 10（ぴったり） |

- まとを倒せばクリア（ぴったりなら ほめる）。足りなかったら「つぎの ターンに もう一度」で、そこからは自由に遊べる
- 実装：`js/ui/tutorial.js`（ステップ）、`js/data/enemies.js` の `tutorial`（敵）

### 8.1 ずかん（決定：冒険をまたいで残す）

冒険をまたいで残るのは **ずかんだけ**。カードの解放・おまもりの解放のような「強くなって次の冒険が楽になる」要素は入れない（毎回同じ条件で遊ぶローグライクにする）。

| タブ | 中身 |
|---|---|
| カード | 126種＋きほんカード。パックから出たことのあるカードは絵と説明が見られる。まだのカードは「？」（色・レアリティだけ見える）。集めた数／126 を表示 |
| てき | 倒したことのある敵（各階・3階のA/B・エレボスの各段階） |
| アーキタイプ | 6つのアーキタイプのそれぞれで、クリアしたことがあるかのしるし |
| きろく | クリア回数、最高スコア（上位10件）、ぴったりの回数 |

## 11. 非同期オンラインバトル（実装ずみ・GAS 版）

イメージは **Backpack Battles**（相手の「スナップショット」と戦う非同期対戦）。GAS 版（`mathtcg/gas/`）で動く。

### 11.1 流れ（決定）

1. 冒険が終わったとき（**クリアしたとき、または途中で負けたとき**）、そのときのデッキを「ゴースト」としてサーバー（GAS のスクリプト プロパティ）に保管する
2. 自分が使うデッキは、**冒険で構築したデッキを3つまで保管** したもの（決定）。保管がいっぱいのときは、冒険のおわりに「どれと入れかえるか／保管しないか」を選ぶ。保管しなくても、ゴーストとしてサーバーには あずける
3. タイトルの「オンライン バトル」で、保管したデッキを選び、ほかのプレイヤーのゴーストと対戦する。相手のデッキはAIが動かす（シミュレーション用のAI `js/engine/ai.js`）
4. 対戦相手は **ランダム**：サーバーにあずけられたゴースト全部から1人（自分のゴーストはのぞく）。データにゴーストがいないとき（つながらないときも）は、見本デッキの「れんしゅう あいて」がランダムに出る
5. 勝つと **トロフィー ＋3**、負けると **−1**（ブロンズ → シルバー10 → ゴールド25 → ニクス50）。自分のゴーストが勝つと、あとで「きみの ゴーストが ○回 かったよ」と知らせる

### 11.2 対戦のルール（決定）

| 項目 | 内容 |
|---|---|
| 形 | プレイヤー同士の1対1。両方 ライフ20・DM のマナ・MTG の戦闘。先攻はランダム（先攻は1ターンめに引かない） |
| 攻撃先 | 相手プレイヤー（MTG と同じ。塔のように相手のクリーチャーは攻撃できない）。相手はブロックする |
| ニクスの 嵐 | 自分の10ターンめから、ターンのはじめにライフを 1・2・3…と失う（盤面が止まって終わらないのを防ぐ。シミュレーションで 決着なし 9% → 0%） |
| ゴーストの動き | 相手のターンは P と E を入れかえて、プレイヤー用のAIとカードの効果をそのまま使う（`js/data/enemies.js` の `pvp`） |
| 画面 | 「あいての よてい」に、攻撃してくるかもしれないクリーチャーのパワーと、ニクスの嵐で失うライフを数で出す（合計は出さない） |

**試作版で省いていること**：ゴーストは、プレイヤーのターンにインスタントを使わない（ブロックだけする）。ゴーストの呪文はプレイヤーの打ち消し呪文で打ち消せない。ゴーストはブロックのあとの強化呪文を使わない。

### 11.3 サーバー（決定：GAS ＋ スクリプト プロパティ）

| 項目 | 内容 |
|---|---|
| 保管するもの | デッキ20枚、とどいた階、ニックネーム、勝ち・負けの数、作った時刻。プレイヤー本人の情報は保管しない |
| ニックネーム | **自由入力にしない**。定型語を2つ組み合わせる：「〇〇な〇〇」（ゆうかんな ドラゴン）か「〇〇 〇〇」（ほのお ドラゴン）。1つめの言葉で形が決まる（20 × 20 通り）。オンライン バトルの画面の **プルダウン2つ** で選ぶ |
| 安全 | チャットなし。ゴーストだけのやりとりで、相手と直接つながらない |
| 不正 | デッキは「20枚・キャパシティ30点・2色まで・知っているカードだけ」をサーバーでもチェックする |
| 量 | とどいた階ごとに30人まで（古いものから消える）。1件 約6KB で、スクリプト プロパティの上限（1件9KB）に収まる |
| トロフィー | その端末の中の きろく（ランキングは将来の候補） |

### 11.4 シミュレーション（見本デッキどうし・100回ずつ）

平均 8.2 ターンで決着。緑赤が強め（ほかのデッキに 71〜89%）、赤青が弱め。塔のバランス（2色・キャパシティ）とは別の調整が要るかは、遊んでもらってから決める。
