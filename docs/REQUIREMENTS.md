# マスマティック・ザ・ギャザリング 要件定義（たたき台）

小学1〜5年生むけの **算数 × デジタルTCG × デッキ構築型ローグライク**。
カードのテキストは Magic: The Gathering（以下 MTG）、マナの仕組みは デュエル・マスターズ（以下 DM）をベースにする。

- 状態：要件定義中（このファイルは議論のたたき台。**決定** と **提案** と **未決** を分けて書く）
- 置き場所：`mathtcg/`（既存の かずまほ・アルカナンバー と同じく、ブラウザだけで動く素の JavaScript を想定）

---

## 0. 決定事項（ここまでに決まったこと）

| 項目 | 決定 |
|---|---|
| 対象 | 小学1〜5年生 |
| ジャンル | 算数のデジタルTCG、デッキ構築型ローグライク |
| カードテキスト | MTG がベース |
| マナシステム | DM がベース |
| 色 | 赤・青・白・緑の4色 ＋ 無色 |
| アーキタイプ（2色） | 赤青・青白・白緑・緑赤・赤白・青緑 の6種類（4色の2色組み合わせすべて） |
| 白緑 | **召集**（Convoke） |

## 1. ゲームの流れ（コアループ）

```
タイトル → 学年（またはうでだめし）を選ぶ
  → 3パック公開（15枚）→ デッキ構築（制限は 6.2）
  → 1階 たたかい → 勝ち → 1パック開封 → デッキ組み直し
  → 2階 → … → 4階 → 1パック開封 → デッキ組み直し
  → 5階 ボス → クリア（スコア・ずかん・きろく）
負けたら：1回だけコンティニュー（1.2）。2回目に負けたら冒険おわり。次の冒険はまた3パックから
```

- 1回の冒険：**30〜45分** を目安（1戦 5〜8分 × 5戦 ＋ 構築）【提案】
- 冒険の途中で中断・再開できる（オートセーブ）【提案】

### 1.1 世界観（決定：MTG と同じ）

- プレイヤーは **プレインズウォーカー**。次元を渡り歩く魔法使いとして塔に挑む
- 舞台の次元は **テーロス** を推奨【提案】。1・2・4階の元ネタのチャレンジ・デッキ（ハイドラ・ミノタウルスの大群・ゼナゴス）がすべてテーロスのものなので、そのままつながる
- 4色（赤青白緑）のカラーパイ・カードの雰囲気・フレーバーテキストも MTG に合わせる。子ども向けに、こわすぎる表現（死・生け贄の描写など）はやわらかくする
- **注意**：タイトル・世界観・キャラクター名は Wizards of the Coast の MTG を下敷きにした **非公式のファンメイド** になる。アイドル迷宮（仮）と同じく **個人・身内で楽しむ範囲** で作る前提とし、一般公開や学校での配布をするときは、名前・固有名詞をオリジナルに差しかえる（カード名・敵の名前はデータで差しかえられるようにしておく）

### 1.2 コンティニュー（決定：1回だけ）

| 項目 | 内容 |
|---|---|
| 回数 | 冒険1回につき **1回だけ**（全学年共通） |
| どこから | 負けた階の **はじめから**（ボスは1段階めから）【提案】 |
| 状態 | ライフ20に戻る。デッキの組み直しもできる。持っているカードは減らない【提案】 |
| 敵 | 同じ敵（3階はランダムを引き直さない） |
| スコア | コンティニューすると減点（例：最終スコア −20%）【提案】 |
| 表示 | 塔のマップに「のこり コンティニュー ○回」を表示 |

## 2. マナシステム（DM ベース）

| ルール | 内容 |
|---|---|
| マナチャージ | 自分のターンに1回、手札のカードを1枚 **マナゾーン** に置ける（どのカードでも置ける） |
| マナの色 | マナゾーンのカードは、そのカードの色のマナを1つ出す。無色カードは無色マナ |
| コストの払い方 | コストの数だけマナゾーンのカードをタップする。**そのカードの色のマナを最低1つ** 含める必要がある（DM の文明条件） |
| 2色カード | マナゾーンに **タップして** 置かれる（DM と同じ。置いたターンは使えない） |
| アンタップ | ターンのはじめに、マナゾーンのカードをすべてアンタップ |
| 土地 | **ない**。すべてのカードが呪文・クリーチャーであり、同時にマナにもなる |

> ねらい：「どのカードをマナにして、どれを使うか」という DM らしい悩みを残しつつ、MTG の土地事故をなくす。

### 2.1 対戦の基本ルール【提案】

- ライフ：プレイヤー **20**（決定。MTG・チャレンジ・デッキに合わせる）。DM のシールド・S・トリガーは **なし**（決定）
- 初期手札：5枚。先攻1ターン目はドローなし
- カードタイプ：クリーチャー／呪文（ソーサリー相当）／すばやい呪文（インスタント相当）／アイテム（アーティファクト・エンチャント相当）
- 戦闘：MTG と同じく「攻撃 → ブロック → ダメージ」。小学生向けに **ブロックの割り振りは1対1のみ**（複数ブロックなし）にして簡単にする
- インスタントのタイミング：相手ターンに使えるのは「ブロック宣言のとき」「相手が呪文を唱えたとき」の2つの決まった場面だけにして、UI で「つかう？」と聞く（スタックの理解を要求しない）

## 4. 色とアーキタイプ

### 4.1 色の役割（MTG のカラーパイを子ども向けに）

| 色 | 性格 | 得意なこと |
|---|---|---|
| 赤 | いきおい・ほのお | ダメージ呪文、速攻、パワーアップ |
| 青 | ちえ・みず・そら | カードを引く、飛行、タップ・とめる |
| 白 | なかま・ひかり | 小さいクリーチャーをたくさん、回復、守り |
| 緑 | しぜん・おおきさ | 大きいクリーチャー、マナをふやす、到達 |
| 無色 | どうぐ・きかい | どのデッキにも入る。マナの色条件を満たさないので入れすぎ注意 |

### 4.2 アーキタイプ（4色版・決定）

算数の単元と結びつけて、**アーキタイプを使いこなすと算数の力も伸びる** 形にする。

| 2色 | アーキタイプ（MTG のメカニズム） | 遊び方 | 結びつく算数 |
|---|---|---|---|
| **白緑** | **召集**（決定） | 小さいクリーチャーを並べ、タップしてマナの代わりにし、重いカードを早く出す | たし算・**10のまとまり**（マナ＋クリーチャー数＝コスト） |
| 赤青 | **X呪文＋果敢** | 呪文を連続で唱えてクリーチャーを強化。X を決めて呪文を撃つ | **□を使った式**（Xはいくつ？）・たし算の積み重ね |
| 青白 | **飛行＋割り振り** | 空から攻める。ダメージやカウンターを「好きなように割り振る」呪文 | **わり算・等分**（6点を3体に分けると？） |
| 緑赤 | **獰猛（パワー4以上）** | 大きいクリーチャーで殴る。「パワーを2倍」などの呪文 | **大小比較**・**かけ算（倍）** |
| 赤白 | **大隊・横並び** | トークンをたくさん出して一斉攻撃。「攻撃しているクリーチャー1体につき＋1」 | **かけ算（同じ数ずつ）**・九九 |
| 青緑 | **＋1/＋1カウンター＋マナブースト** | マナゾーンを増やし、カウンターを積んで育てる（DM の緑ブーストとも相性◎） | **大きな数・くり返しのたし算**、5年：倍数 |

- 各アーキタイプに **アンコモンの2色「道しるべ」カード** を1枚ずつ（MTG のドラフト・サイクル）【提案】
- 単色でも組めるように、各色に単色で完結するコモンを入れる

### 4.3 5色版（赤青白緑黒）【不採用・将来の拡張候補】

黒を加えると2色の組み合わせは **10種類**。4色版の6アーキタイプはそのまま残し、黒の入る4つを足す。

#### 黒の役割

| 色 | 性格 | 得意なこと |
|---|---|---|
| 黒 | よる・ゆめ・おばけ（こわすぎない世界観にする） | クリーチャーをたおす呪文、墓地を使う、ライフを払って力を得る、絆魂 |

- 黒が入ると、ほかの色の役割から「クリーチャーをたおす」の中心が黒に移る（4色版では白と赤が分担していた）
- キーワード候補の追加：**ちからをすいとる**（絆魂）、**どく**（接死）、**よみがえる**（墓地から戦場に戻る）

#### 黒の入る4アーキタイプ

| 2色 | アーキタイプ（MTG のメカニズム） | 遊び方 | 結びつく算数 |
|---|---|---|---|
| 白黒 | **絆魂・ライフの増減** | ライフを得るたび・失うたびに効果が出る。ライフを払って強い呪文を使う | **ひき算・ちがいを求める**（20と13のちがいは？） |
| 青黒 | **昂揚（墓地のカードの種類）** | 墓地にクリーチャー・呪文・アイテムなどの種類がそろうと強くなる | **なかま分け・表とグラフ**（種類ごとに数える） |
| 黒赤 | **生け贄** | 自分のクリーチャーを生け贄にして、そのパワーぶん相手にダメージ | **ひき算とたし算の組み合わせ**（へらして、ふやす） |
| 黒緑 | **墓地から回収・−1/−1カウンター** | たおれたクリーチャーを手札やマナゾーンに戻す。相手に−1/−1を置いて0にする | **ひき算・0のいみ** |

#### 4色版と5色版のくらべ

| 観点 | 4色版 | 5色版 |
|---|---|---|
| 2色アーキタイプ | 6 | 10 |
| 最初のリリースのカード数（目安） | 約78種 | 約98種（各色16＋2色アンコモン10＋無色8） |
| 最初の3パック（15枚）での組みやすさ | 1色あたり約4枚。2色デッキにしやすい | 1色あたり約3枚。2色にしぼりにくい → パックの色の出方を調整する必要がある |
| 冒険ごとのちがい | ふつう | 大きい（くり返し遊びやすい） |
| 1〜2年生への分かりやすさ | ◎ | ○（色が多いぶん迷う） |
| 算数の単元のカバー | たし・ひき・かけ・わり・□の式・大きな数 | ＋ちがい・表とグラフ・0 |

**決定**：4色版で作る。黒は将来 **第2弾（拡張）** として足すかもしれない。
カードデータとルールエンジンは最初から「色は5つまで」で作っておけば、あとから黒を足しても作り直しにならない。

## 5. 算数の入れ方（決定：B＋A）

カードゲームとしての面白さを壊さずに算数を入れる方法の候補。

| 案 | 内容 | 長所 | 短所 |
|---|---|---|---|
| **A. けいさんボーナス**（推奨） | 攻撃・呪文の解決時に「なんてんダメージ？」と式が出る。正解するとボーナス（＋1点、ひらめき演出など）。**まちがえても普通に解決** | テンポを崩さない。かずまほ の「よそう」で実績あり | 計算をスキップする子もいる |
| B. カードの効果そのものが算数 | 「パワーを2倍」「X＝マナの数×2」「偶数のクリーチャーは…」など。答えを入力させず、自動計算して表示 | 自然に式に触れる | 計算する機会は受け身 |
| C. コストの支払いが算数 | マナに数字があり、ちょうどの組み合わせで払う | 毎ターン必ず計算する | DM のマナシステムと別物になる。テンポが悪い |
| D. 塔の階のあいだに算数イベント | パック開封前にクイズ（正解でパックが1枚増えるなど） | 実装が簡単 | ゲームと算数が分離する |

決定：**B を土台に A を重ねる**（全カードの効果は数で書き、要所で計算を入力させる）。C は採用しない。

### 5.1 学年ごとの出題範囲【提案】

| 学年 | 主な内容 |
|---|---|
| 1年 | 20までのたし算・ひき算、大小比較、10のまとまり |
| 2年 | 2けた・3けたのたし算・ひき算、九九 |
| 3年 | わり算、□を使った式、あまり |
| 4年 | 大きな数、2けたでわるわり算、がい数 |
| 5年 | 倍数・約数、偶数・奇数、小数のかけ算 |

- カードの数値は学年で変えない（ゲームバランスを1つにする）。**出題の形** を学年で変える（例：同じ「3体×＋2」でも 1年は 2＋2＋2、2年以上は 3×2）
- 学年選択は アルカナンバー の「まほうの うでだめし」方式も流用できる

## 6. パックとデッキ構築

### 6.1 パックの中身（決定：1パック8枚）

#### 5枚で足りるか（シミュレーション）

「2色まで」の制限があると、パックから出たカードのうち **デッキに入れられるのは半分くらい** になる。
1パックの枚数ごとに、いちばん多く集まった2色（＋無色）の枚数と点数を出した（4色が各20%・2色カード10%・無色10%、レアは各パック1枚（5枚＝C2・U2・R1、6枚＝C3・U2・R1、8枚＝C4・U3・R1、10枚＝C5・U4・R1）、4000回の平均。サプライズ・レジェンドを入れても数字はほぼ変わらない。`mathtcg/tools/packsim.py`）。

| 1パックの枚数 | 開始時（3パック） | 2階クリア後（5パック） | ボス戦の前（7パック） |
|---|---|---|---|
| **5枚** | 10枚・19点 | 16枚・30点 | 22枚・40点 |
| 6枚 | 12枚・20点 | 19枚・32点 | 26枚・44点 |
| **8枚** | 15枚・26点 | 25枚・41点 | 34枚・55点 |
| 10枚 | 19枚・31点 | 30枚・49点 | 41枚・67点 |

5枚だと：

- **開始時に使えるカードが10枚しかない**。デッキ20枚のうち半分が きほんカード になり、最初の戦いが単調になる
- キャパシティ30点に届くのが **3階になってから**。それまでは「選ぶ」悩みがほとんどない
- ボス前でも 22枚・40点 から 30点ぶんを選ぶだけで、悩みは小さい

#### 決定：1パック8枚

| レアリティ | 枚数 |
|---|---|
| コモン | 4 |
| アンコモン | 3 |
| レア | 1（8パックに1回、レジェンドになる） |

**サプライズ・レジェンド**：低い確率で、コモン1枚がレジェンドに変わる（MTG のフォイル枠のようなおまけ）。

| 項目 | 内容 |
|---|---|
| 確率 | **1パックにつき 1/20（5%）**（決定） |
| 冒険1回（7パック）で1回以上出る確率 | 約30% |
| 冒険1回で出るレジェンドの平均 | 約1.2枚（コモンが変わらない場合は約0.9枚） |
| レアもレジェンドになり、1パックに2枚出る確率 | 約0.6%（160パックに1回） |
| 演出 | コモンのはずのカードをめくると光って変わる「！？」演出 |

- 確率の候補：1/16 なら冒険1回で約36%、1/30 なら約21%
- レジェンドは4点なので、キャパシティ30点のなかで「入れるか」の悩みが増える（強すぎるだけのおまけにはならない）

- 開始時に 約15枚・26点 → **最初のデッキはほぼ全部入る**（最初から悩ませすぎない）
- 1階クリア後（4パック）にキャパシティ30点をこえ、**そこから毎回「選ぶ」悩みが出る**
- ボス前は 約34枚・55点 から30点ぶんを選ぶ → しっかり取捨選択になる
- 開封は1枚ずつめくる演出が基本。8枚は長いので「ぜんぶ めくる」ボタンもつける
- パックは **色が偏りすぎない** ように抽選（1パックに4色すべてを最低1枚）【提案】

### 6.2 デッキの制限（決定：2色まで ＋ デッキキャパシティ）

| ルール | 内容 |
|---|---|
| 色 | デッキに入れられる色は **2色まで**。無色は自由。2色カードは、その2色を選んだときだけ入る |
| デッキキャパシティ | レアリティ点数（コモン1／アンコモン2／レア3／レジェンド4）の合計が **30点以下** |
| きほんカード | 0点。キャパシティを使わない |

- 色を決めると持っているカードの半分くらいが入らなくなり、残りから30点ぶんを選ぶ、という2段階の取捨選択になる
- 2色の制限は MTG のドラフト・アーキタイプと一致し、DM のマナの色条件とも相性が良い（色が少ないほどマナが安定する）
- 点数の合計はたし算の練習にもなる。画面では「のこり ○点」のメーターと、カードを入れる前に「入れると のこり ○点」を見せて、1〜2年生でも選べるようにする
- 検討したほかの方式（レアリティ枠、コストの合計、パックから選んで取る、持てる枚数の上限）は不採用

共通のルール：

- デッキは **20枚ちょうど**（決定）。足りない分は0点の「きほんカード」（各色＋無色、小さな効果つきのマナ用カード）で自動的に埋める（DM は全カードがマナになるので、土地の代わり）
- 同じカードは、パックから出た枚数まで入れてよい
- 「おまかせ」ボタン：いちばん多い2色で自動で組む（1〜2年生向け）

## 7. 塔（5階）

### 7.1 敵の仕組み（MTG チャレンジ・デッキ共通ルール）

- 敵は **マナを使わない**。敵のターンにライブラリーの一番上を公開して、そのまま唱える（自動で動くので AI が不要・子どもにも先が読みやすい）
- 敵のカードはすべて無色・マナ総量0
- 敵に「カードを引かせる・捨てさせる」など実行できない効果は無視
- **英雄カード**：プレイヤーは開始時に英雄カード（補助のエンチャント）を最大2枚出せる → 本作では **冒険の最初に選ぶ「おまもり」** に置きかえる【提案】
- **英雄の報酬**：敵のパーマネントを倒すとプレイヤーにご褒美（ライフ回復など）がある → そのまま採用（倒すと嬉しい）

### 7.2 階ごとの敵

チャレンジ・デッキは3種類しかないので、3階と5階はオリジナル。

| 階 | 元ネタ | 勝利条件 | 特徴 | 子ども向けの調整 |
|---|---|---|---|---|
| 1階 | **ハイドラとの対峙** | ターン終了時に敵の **頭が0** | 開始時に頭2本（イージー）。頭が1本倒れるたび、ライブラリーから2枚公開して頭を出す | 頭2本スタート。わかりやすい「全部たおせ」 |
| 2階 | **大群との戦い**（ミノタウルス） | 敵のライブラリーが0 **かつ** クリーチャー0 | 敵はライフがなく、ダメージ1点ごとにライブラリーを1枚削る。敵のクリーチャーは速攻 | プレイヤーの最初の追加ターンを多めに。「のこり枚数」を大きく表示 |
| 3階 | **オリジナル**（A・B から **ランダム**、決定） | 下の表 | 下の表 | 下の表 |
| 4階 | **神を討て**（ゼナゴス） | 神が戦場を離れる | 手下（歓楽者）が1体でもいる限り、神は戦場を離れない。手下を全部倒してから神を倒す | 手下の数を常に表示 |
| 5階 | **ボス（オリジナル・3段階、決定）** | 3段階めの本体のライフを0にする | 7.3 | 7.3 |

#### 3階：A・B のどちらかがランダムで出る（決定）

| | A：ゴーレムの こうじょう | B：ふえる スライム |
|---|---|---|
| 勝利条件 | 「工場」（敵のアイテム）を壊す | 敵のスライムが0 |
| 敵のターン | ライブラリーの一番上を公開して唱える。さらに工場が毎ターン ゴーレム（2/2）を1体作る | ライブラリーの一番上を公開して唱える |
| 特別ルール | 工場には **鍵の数**（例：6）があり、**ちょうどその数のダメージ** を1回で与えたときだけ壊れる。多くても少なくても壊れない。壊れなかったら鍵の数が変わる | スライム（例：8/8）は倒されると、**パワー・タフネスが半分** のスライム2体に分かれる。1/1 は分かれずに消える |
| 算数 | **ぴったりの数を作る**（たし算・ひき算） | **わり算・半分**（8→4と4→2と2…） |
| 英雄の報酬 | ゴーレムを倒すと、工場の鍵の数が1へる（ねらいやすくなる） | 1/1 のスライムを倒すと、ライフを1点得る |
| 子ども向けの調整 | 鍵の数を常に大きく表示。「いまのダメージ」と「鍵の数」を並べて見せる | 場のスライムを大きさ順に並べ、「のこり ○体ぶん」を表示 |

- 2回目以降の冒険では、前回と違うほうが出やすくする【提案】
- 難易度（イージー／ノーマル／ハード）はチャレンジ・デッキと同じく「初期の頭の数」「公開枚数」「鍵の数」「最初のスライムの大きさ」で調整する

### 7.3 5階：ボス（3段階、決定）

1〜4階で出てきたルールを順番に使う。ボスの名前・見た目は未決（MTG の世界観から選ぶ）。

| 段階 | 元にするルール | 勝利条件（次の段階に進む条件） | 内容 |
|---|---|---|---|
| 1 | ハイドラ | ボスの **頭が0** | 頭2本で始まり、頭が倒れるとライブラリーから新しい頭が出る |
| 2 | 神を討て | ボスの **手下が0** | 手下が1体でもいる限り、ボスの本体には攻撃もダメージもできない |
| 3 | 本体 | ボスの **ライフが0** | ボスにライフ（例：15）がある。毎ターン2枚公開して唱える、いちばん強い段階 |

- **段階のあいだ**：プレイヤーの場・手札・マナゾーン・ライフはそのまま引きつぐ。ボスの場は段階ごとに入れかわる
- **段階が変わるときのごほうび**：ライフを3点得て、カードを1枚引く【提案】
- 段階が変わるたびに見た目・音楽を変え、「だい2だんかい！」の演出を入れる
- 長くなりすぎないように、ボス戦全体で 10〜12分 をめやすにする（ほかの階の1.5〜2倍）
- 負けたときは、どの段階まで進んだかを スコア に入れる（コンティニューすると1段階めからやり直し）
