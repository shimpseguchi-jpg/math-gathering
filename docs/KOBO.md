# カード工房（こうぼう）

じぶんで クリーチャーの カードを つくる。コストと レアリティで きまる **「よさん」の 点** の 中で、パワー・タフネス・とくべつな 力・出たときの こうかを 買う。

- 状態：**実装ずみ**（2026-11-11。ユーザーが きめた：新しい モードの 案 2）
- ねらい：よさんの **たし算・ひき算** を、つくりたい カードの ために なんども やる（「飛行を つけたいから タフネスを 1 へらそう」）。レアリティと デッキの 点数（REQUIREMENTS 3.4）の かんけいも わかる
- ファイル：`js/data/kobo.js`（点数の きまり・カードの 定義を つくる）、`js/ui/kobo.js`（一覧・つくる 画面・ためす）
- つくった カードは **この 端末だけ**（`mtg-kobo`。12まいまで）。**ぼうけん・こうちく・オンライン・ずかんには 出ない**。「ためす」で とうの てきと たたかう だけ

## 1. よさん

**よさん ＝ コスト × 2 ＋ 2 ＋ レアリティの ぶん**

| レアリティ | よさんに 足す | デッキの 点数 | ねらいかた（ダメージ・タップ） |
|---|---|---|---|
| コモン | ＋0 | 1点 | ランダム |
| アンコモン | ＋1 | 2点 | （たおせる なかで）パワーが いちばん 大きい てき |
| レア | ＋2 | 3点 | じぶんで えらぶ |
| レジェンド | ＋4 | 4点 | じぶんで えらぶ。伝説（場に 1まい だけ） |

- コスト 1〜8、パワー 0〜12、タフネス 1〜12。色は 5色か むしょく
- 画面には いつも 式が 出る：「よさん：コスト 4 × 2 ＋ 2 ＋ 2（レア）＝ 12点」「つかった：3 ＋ 4 ＋ 2 ＋ 3 ＝ 12点」「のこり：12 − 12 ＝ 0点 ぴったり！」。こえると「5点 オーバー！」で 完成 できない
- ねらいかたは ゲームの きまり（`game.js` の `pickOf`）と おなじ。`makeCustom` が `applyPick` を とおす

## 2. 買える もの

| もの | 点 |
|---|---|
| パワー・タフネス | 1 に つき 1点 |
| 飛行 | 2 |
| 到達・速攻・警戒・トランプル | 1 |
| 絆魂・先制攻撃・果敢 | 2 |
| 接死 | 3 |
| 二段攻撃 | 5 |
| 防衛（こうげき できない） | **−2**（2点 もどる）。速攻とは いっしょに えらべない |
| 出たとき：ライフを N点 得る（1〜6） | N ÷ 2（きりあげ） |
| 出たとき：N点の ダメージ（1〜5） | N ＋ 1 |
| 出たとき：カードを N枚 引く（1〜2） | N × 3 |
| 出たとき：ほかの クリーチャー1体に ＋1/＋1カウンター N個（1〜3） | N |
| 出たとき：1/1 の 兵士を N体（1〜3） | N × 2 |
| 出たとき：敵の クリーチャー1体を タップ | 2 |

出たときの こうかは 1つまで。カードの 文は 自動で できる（ふりがな つき）。

## 3. ためす

- つくった カードを 3しゅるいまで えらぶ（4まいずつ）。のこりは おなじ 色の かんたんな カード（1年生の カードプールから、コスト 5 まで）と きほんカードで 20まい
- テーロスの とうの てき（かんたん・ふつう）と 1回 たたかう。パックけん・トロフィー・ずかんの きろくは ふえない

## 4. 名前

- 14字まで。`< > & " '` と ふりがなの きごう（（）《》｜）は とる（`cleanName`）
- よみこんだ データは `cleanSpec` で はんいに おさめる（こわれた セーブでも うごく）

## 5. これから

- こうちくモードの デッキに 入れる（れんしゅう だけ）
- あいことば（コード）で ともだちに わたす
- 「攻撃するたび」「死亡したとき」の こうか、じゅもんの カード
- つめマスの 問題に つかう
