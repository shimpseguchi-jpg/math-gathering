## 2. 新しい しくみ

| しくみ | 説明（長おしで 出す 文の 案） | 算数 |
|---|---|---|
| **記憶（きおく）の精霊（せいれい）** | キャラ（と 一部の モブ）が 出す、その キャラと **つながった トークン**。①つながった キャラが 戦場を はなれると、精霊も きえる。②1体の キャラに 精霊は 1体まで。もう いる ときに また 出すなら、かわりに その 精霊に ＋1/＋1カウンターを 1こ 置く。③精霊の パワー・タフネスは カードに 書いた 数えかたで きまる（戦技ポイントの 数・キャラの 数・精霊の 数の 2倍 など。数が かわると 大きさも かわる）。④精霊も この 弾の クリーチャー なので、攻撃すると 戦技ポイント ＋1 | **たし算**（戦技ポイント 3 ＋ 1 ＝ 4、新蕾 2 ＋ 3 ＝ 5）・**2倍**（精霊 3体 × 2 ＝ 6）・**数える**（キャラ 2人 ＋ 1 ＝ 3） |
| **追加攻撃（ついかこうげき） N** | あなたの **ほかの** クリーチャーが 攻撃して、敵の クリーチャーに ダメージを 与えたのに、その クリーチャーが **まだ たおれて いない** とき、これは その クリーチャーに **N点** の ダメージを 与える（1ターンに 1回。「2回まで」と 書いて あれば 2回）。**のこりの タフネスと N が 同じ なら ぴったり**（撃破）！ 攻撃した クリーチャーと 追加攻撃した クリーチャーの、どちらの 撃破も おきる。ダメージを うけた 敵が 2体 いれば、ぴったりで たおせる ほうを ねらう | **ひき算**（タフネス 5 − 3 ＝ のこり 2）→ **ぴったり**（2 − 2 ＝ 0）。たりない（2 − 1 ＝ 1 のこる）・あまる（のこり 1 に 2点 → 1 あまる）も わかる |

- どちらも 問題を 出す のでは なく、**ルールの 中で 計算が おきる**：「戦技ポイントを 2 つかって 安く 出すと、ラフトラは 3 − 2 ＋ 1 ＝ 2 に なっちゃう」「3点 あたって のこり 2。追加攻撃 2 で ぴったり！」
- 第1弾の しくみとの くみあわせ：戦技ポイントを **ためるか 使うか**（ラフトラ・マダム・ヘルタ）、追加攻撃で **ぴったり → 撃破**（飛霄・素裳・サフェル の 撃破）、必殺技で **トリビーの 追加攻撃**
- 長おしの 文を `glossary.js` に 入れる ときは、カードと 同じく ふりがなを つける（`node tools/kanji.mjs` が しらべる）
- カードに だけ 出る ことば（その カードの 文で 説明して いる）：新蕾（キャストリス）・火種（ファイノン）・龍霊（丹恒・騰荒）・黄金裔（しゅぞく）

### 2.1 実装メモ

さいしょに **第1弾と 同じ 弾（set 11）に 入れるか、べつの 弾（set 14）に するか** を きめる（5章 #1）。下は どちらでも ほぼ 同じ。

1. **`tools/gen_texts.py`**：`DRAFTS` に `('EXTRA2_SR.md', 11, 'SR')`（べつの 弾なら 14）を たす。ID の 正規表現は 3けた（`SR160`）も OK。`game.js` の `srDeck`（`/^SR\d/`）も そのまま 通る
2. **`js/data/set11.js`**（第2弾も ここに 書くのが いちばん 小さい。べつの ファイルに するなら `trail`・`skillAct`・`foeSkill`・`pumpOther`・`selfPump`・`spCut`・`ult`・`split`・`detain` を `export` する）
   - `skillAct(sk, max)` に `sk.can`（ファイノン：火種 6 いじょう）を たす：`can: (s, p) => spOf(s) >= 1 && … && (!sk.can || sk.can(s, p))`
   - **記憶の精霊** `memo(tokenDef)`：エンジンの 変更 なし
     ```js
     // 記憶の精霊：p と つながった トークン（p.uid を q.memoOf に）。もう いれば ＋1/＋1カウンター
     const memoOf = (s, p) => s[p.side].bf.find((q) => q.memoOf === p.uid);
     function summonMemo(s, E, p, def) {
       const m = memoOf(s, p);
       if (m) { E.addCounters(s, m, 1); return m; }
       const [t] = E.token(s, p.side, def); if (t) t.memoOf = p.uid; return t;
     }
     const memoLink = { onLeaveSelf: (s, p, E) => { for (const q of [...s[p.side].bf]) if (q.memoOf === p.uid) E.leave(s, q, 'exile'); } };
     const isMemo = (q) => q.memoOf != null;
     ```
     精霊の トークンは `T.memoW`（白 1/1 飛行）・`T.memoG`（緑 1/1）・`T.raftra`（`pow: (s) => spOf(s) + 1`, tou 3, 飛行）・`T.shiryu`（黒 5/5 飛行）・`T.ikarun`（緑 1/1 飛行）・`T.myurion`（`pow = tou = 伝説の クリーチャーの 数 + 1`）・`T.nagayo`（`pow = tou = 2 × 精霊の 数`、飛行）。どれも `onAttack` で 戦技ポイント ＋1（`trail` と 同じ）。`memoLink` は 精霊を 出す カード（キャラ・モブ）に かさねる
   - **追加攻撃** `fu(n, max = 1, o)`：
     ```js
     // 追加攻撃 N：みかたの 戦闘ダメージで のこった 敵の クリーチャーに N点（ぴったり → 撃破を いちばんに ねらう）
     const fu = (n, max = 1, o = {}) => ({ fuN: n, followUp: (s, p, evs, E) => {
       const src = o.src ? o.src(s, p) : p; if (!src || !E.onBf(s, src)) return;
       const left = (t) => E.pt(s, t)[1] - t.dmg;
       while ((p.flags.turn.fu || 0) < max) {
         const c = [...new Set(evs.filter((e) => e.src !== src && e.t?.side === 'E' && E.onBf(s, e.t) && E.isCreature(e.t) && !e.t.dt && left(e.t) > 0).map((e) => e.t))];
         if (!c.length) return;
         const t = c.find((x) => left(x) === n) || c.filter((x) => left(x) < n).sort((a, b) => E.power(s, b) - E.power(s, a))[0] || c.sort((a, b) => left(a) - left(b))[0];
         p.flags.turn.fu = (p.flags.turn.fu || 0) + 1;
         E.L(s, `ついかこうげき：${src.def.name} → ${t.def.name}（のこり ${left(t)} − ${n}）`);
         E.damage(s, t, n, src); o.after?.(s, p, E, t);
         for (const q of [...s.P.bf]) q.def.onFollowUp?.(s, q, E); // 黎明の ミハニ
       }
     } });
     ```
     丹恒・騰荒は `fu(1, 1, { src: (s, p) => s.P.bf.find((q) => q.dragon === p.uid) })`（龍霊の ついた クリーチャーが 追加攻撃）＋ `anthem`（＋1/＋0）
3. **エンジン `js/engine/game.js`（3行）**：`resolveCombat` の `for (const step of ['first', 'normal'])` の 中で、ダメージの まえに `const ev0 = s.combat.events.length;`、ブロッカーの はんげきの あと・`sba(s)` の まえに

   const evs = s.combat.events.slice(ev0); // この ステップで みかたが あたえた ダメージ（追加攻撃の ダメージは ふくめない ＝ 追加攻撃が 追加攻撃を よばない）

- ねらいかた（2026-10-27 の きまり）：コモンは ランダム、アンコモンは パワーが いちばん 大きい 敵、レア・レジェンドは じぶんで えらぶ。テキストも それに あわせた（SR145・SR158 は PICK_FREE に 入れて じぶんで えらぶ）
- 装備品は 3まい だけ（ゼンゼロで 8まい だと デッキが 装備品で うまって クリアが 下がった ため）。「カードを 引く だけ」の カードは 入れて いない
