# 第6弾 カード案「三（みっ）つの 旗（はた）」（45種）

マスマティック・ザ・ギャザリングの第6弾（拡張）の案。**3色デッキ** の 弾。3色の ルールの 考えかたと シミュレーションは [`THREE_COLOR.md`](THREE_COLOR.md)、弾の 一覧は [`ROADMAP.md`](ROADMAP.md)。

- 状態：**第1案**（2026-10。数値は バランス調整前。データ化は まだ）
- 5色（第3弾で 黒が 入った あと）として 書いて いる。3色の 組み合わせは **10**（楔（くさび）5つ ＋ 断片（だんぺん）5つ）
- 書き方は 第1弾〜第5弾と 同じ。元のカードは 実在の MTG カード（英語名）。オリジナルの ものは そう 書く

### 1.1 3色の ルール（[`THREE_COLOR.md`](THREE_COLOR.md) の 案 B）

| ルール | 中身 |
|---|---|
| 色 | ふつうは 2色まで。**旗が デッキに あれば、その 旗の 3色まで** 使える（旗を 2まい 入れても 3色まで） |
| 点数 | **旗は 4点**（レアリティとは 別。カードに 書く）。これで キャパシティが 実質 26点に なり、3色が 強すぎない（THREE_COLOR の シミュレーション：3色・26点で ふつう 59%） |
| 3色の カード | 唱えるのに **3色の うち 2色の マナ** が いる（いまの 2色の カードは 1色で よい。3色は 少し きびしく） |
| 色を 出す | 旗は タップで 3色の どれかの マナを 出す。3色の カードを マナに 置くと、3色の どれでも 出せる（2色と 同じ） |
