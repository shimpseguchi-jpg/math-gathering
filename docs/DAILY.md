# きょうの ぼうけん

毎日、**みんな おなじ 条件** で 1回だけ いどむ ぼうけん。その日だけの「きょうの ルール」が つく。けっかを クラスで くらべる（ぼうグラフ）。

- 状態：**実装ずみ**（2026-11-11。ユーザーが きめた：新しい モードの 案 4）
- ファイル：`js/data/daily.js`（ルール・日づけから 種）、`js/ui/daily.js`（画面・きろく・サーバー）、`js/ui/app.js`（ぼうけんの 流れ：`A.daily`）、`tools/gas_Code.gs`（`mtgDailySubmit`・`mtgDailyBoard`）

## 1. 条件

| こと | なかみ |
|---|---|
| せかい・むずかしさ | テーロスの とう・ふつう・パック（ドラフト・統率者戦は なし） |
| 回数 | **1日 1回**（その 端末の 日づけ）。コンティニュー なし。とちゅうで やめても「つづきから」で もどれる（日が かわると きえる） |
| おなじ もの | **出て くる 階（てき）の ならび** と **パックの なかみ**（日づけと 何こめの パックかで きまる。`packRng`）。ごほうびパックは デッキの 色で 出やすさが かわる ので、人に よって ちがう ことが ある |
| もんしょう | つかわない（パックの もんしょうも）。**きょうの ルール** だけ |
| きろく | のぼった 階（0〜5）・ぴったりの 回数・ターンの 合計。この 端末に `mtg-daily`（とちゅうの ぼうけんは `mtg-daily-run`） |
| とうの きろく | ずかんの クリア回数・かいほう（むずかしい など）には **かぞえない**（ルールで らくに なる 日が ある ので）。カードの ずかん・トロフィーの 数は いつもどおり |
| ごほうび | さんか（1日 1回）：もんしょうポイント ＋1。パックけんは とうと おなじ（クリアした 階 1つに 1まい） |
| むげんの とう | なし（5階を クリアしたら おわり） |

## 3. みんなの けっか（GAS 版）

- おわると `mtgDailySubmit({ d, f, e, t, n, g })`：1人 1回（学校アカウントの 読めない 番号。なければ 端末の 番号 12けた）。**さいしょに とどいた けっかだけ** のこす。14日より 古い 行は けす
- `mtgDailyBoard({ d, g })`：人数・のぼった 階ごとの 人数（0〜5）・じぶんの じゅんい・上から 20人（なまえは オンラインの「ゆうかんな ドラゴン」の 2語）
- じゅんばん：のぼった 階が 多い → ぴったりが 多い → ターンが 少ない
- 画面：**ぼうグラフ**（上が クリア。じぶんの 段は 金色）と 上位 10人
- シート「きょうのぼうけん」：日づけ・ひと・なまえ1・なまえ2・階・ぴったり・ターン・日時
- サーバーの ない ところ（GitHub Pages）：じぶんの けっかと これまでの きろく（7日ぶん）だけ
- **GAS の Code.gs が かわった**（シートと 関数を 足した）ので、学校の サーバーは Code.gs を はりなおす まで「みんなの けっか」は 出ない（ほかは うごく）
