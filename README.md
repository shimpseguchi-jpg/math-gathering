# マスマティック・ザ・ギャザリング

小学1〜5年生むけの **算数のデジタルTCG・デッキ構築型ローグライク**（試作版）。
パックを開けてデッキを組み、MTG のチャレンジ・デッキをもとにした5階だての塔を登る。マナは DM ベース。

- 遊ぶ：`mathtcg/index.html` をブラウザで開く（HTTPS か `npx http-server -p 8124 -c-1 .` などで配信。ファイルを直接開くと動かない）
- スマホの縦向きが基準。iPad・PC でも動く
- 冒険の途中（たたかいの合間）はブラウザに自動で保存され、「つづきから」で再開できる

## つくり

```
index.html          入口
css/style.css       見た目
js/ui/app.js        冒険の流れ（タイトル・パック・デッキ構築・塔・おわり）
js/ui/battle.js     たたかいの画面（タップの操作、敵のターン中の質問）
js/ui/view.js       カードの見た目・ルビ・シート（対象・割り振り）・けいさんの問題
js/ui/sfx.js        効果音（WebAudio で合成）
js/ui/glossary.js   ことばの せつめい（キーワード能力・用語 約55）
js/engine/          ルール（game.js）・シミュレーション用AI（ai.js）・冒険（run.js）
js/data/            カード（cards.js）・敵（enemies.js）・カードの文章（texts.js：docs から自動生成）
docs/               要件定義・カードリスト・敵・シミュレーションの結果
tools/              sim.mjs（バランス）・e2e.mjs（ブラウザの通しテスト）・gen_texts.py・check_cards.py・packsim.py
```

## 遊び方のポイント

- 対象を選ぶカード（ダメージ・除去・強化・格闘・割り振る）は、使うときに相手を選ぶ。割り振るは ＋／− で分ける
- 上の「つぎの 敵」に、敵の次のターンの予定（攻撃してくる数とパワー・頭のダメージ・めくる枚数など）が出る。次に攻撃してくる敵には「つぎに 攻撃」の札
- 敵がめくったカードは、1まいずつ見せる
- 点線の ことば（キーワード能力・用語）は、長おしか2回タップで 小学3年生向けの せつめいが出る（js/ui/glossary.js）
- パックはガチャ風：光るパックをやぶり、裏の光り方（銀＝アンコモン・金＝レア・虹＝レジェンド）を見てから めくる。めくった カードは、テキスト欄 いがいを タップすると 次へ（テキスト欄は 長おしで ことばの せつめい）。「おと」で効果音を切りかえ
- 塔の ごほうびパックは、登るほど レアが出やすく、デッキで いちばん使っている色が 出やすい
- 自分の クリーチャーを 敵へ スワイプすると 攻撃、敵の ターンに 自分の クリーチャーを 攻撃してきた 敵へ スワイプすると ブロック（タップでも できる）
- ボロスの 魔除けなど「1つを 選ぶ」呪文は、使うときに モードを 選ぶ（自分の ターン・攻撃の とちゅう・敵の 攻撃の とき）

## 試作版でできないこと

- 「敵に〜点」の能力（路地裏の火の子など）は、本体がない階では自動で相手が選ばれる
- 学年の設定は「抜き打ちテスト」の問題だけに使う
