# マスマティック・ザ・ギャザリング

小学1〜5年生むけの **算数のデジタルTCG・デッキ構築型ローグライク**（試作版）。
パックを開けてデッキを組み、MTG のチャレンジ・デッキをもとにした5階だての塔を登る（1〜4階の 敵は 2〜3種から ランダム）。マナは DM ベース。

- 遊ぶ：`index.html` をブラウザで開く（HTTPS か `npx http-server -p 8124 -c-1 .` などで配信。ファイルを直接開くと動かない）
- スマホの縦向きが基準。iPad・PC の 横画面では、たたかいの 画面が 卓の ような ならべかた（左に やまふだ・ライフ、まんなかに 場と 手札、右に ボタン）に かわる（`docs/REQUIREMENTS.md` 8.4）
- 冒険の途中（たたかいの合間）はブラウザに自動で保存され、「つづきから」で再開できる
- **ずかん**：パックから 出た カード・たおした てき・クリアした 2色・さいこう スコア（とどいた 階 × 100 ＋ ぴったり × 10）。タイトルの「ずかん」で 見る（`docs/REQUIREMENTS.md` 8.1）
- **トロフィー**：あそんで できた こと（ぴったり・ちょうど 12時・ライフ ちょうど 1 で かつ など）で もらえる 23こ（ブロンズ〜プラチナ）。タイトルの「トロフィー」で 見る（`docs/REQUIREMENTS.md` 8.3）
- **しゅぎょうと もんしょう**：タイトルの「もんしょう」で、60秒で 1年生の 問題（くりあがり・くりさがり・3つの 数・10の まとまり・とけい・漢字の 読み・てにをは）を とく。7割より 多く 正解すると もんしょうポイント。ポイントで スキルツリーの もんしょう（マリガン・ヴァンガード も）を えらぶと 12時間 冒険で つよく なる。ふりなおしも できる（[`docs/EMBLEMS.md`](docs/EMBLEMS.md)、`docs/REQUIREMENTS.md` 12章）
- **こうちくモード**：冒険とは べつに、**パックけん**（とうの 階を クリア・しゅぎょう・トロフィーで もらう）で ショップの すきな 弾の パックを あけて カードを あつめ、**ノーマル**（とうと 同じ 30点・2色）・**エターナル**（点・色の せいげん なし）と、それぞれの **統率者** の デッキを くむ（ならべかえ・しぼりこみ つき）。**1年生** の ルールでは、第1〜3弾から ルールと 漢字の かんたんな 60しゅるい（`js/data/pool1.js`）だけで、もって いなくても デッキが くめる。同じ カードは 4まいまで、4まい そろった カードは もう 出ない。くんだ デッキは「れんしゅう」で とうの てきと たたかえる（[`docs/CONSTRUCTED.md`](docs/CONSTRUCTED.md)）
- **せかい**：タイトルで テーロス・**ラヴニカ**・**ストリクスヘイヴン**（第5弾と いっしょ。2026-10-29 に 出した。入学式で 寮を えらんで 6階だて・ライフを ひきつぐ・休み時間・通知表：[`docs/STRIXHAVEN.md`](docs/STRIXHAVEN.md)）を えらぶ。ラヴニカの 塔は 1〜4階が 10の ギルドの リーダー、5階が ギルドパクトの ジェイス。リーダーは バトルの すすみぐあいで セリフを しゃべる（[`docs/RAVNICA.md`](docs/RAVNICA.md)。ニコル・ボーラスは いつかの レイドバトル用に とっておく）
- **あそべる じゅんばん**：はじめては チュートリアル → ストーリー 1章 → テーロスの とう（かんたん・ふつう）。「ふつう」で のぼりきると「むずかしい」と ラヴニカが ひらく。ラヴニカを「ふつう」で のぼりきると ストリクスヘイヴン（`docs/REQUIREMENTS.md` 8.7）
- **みため**：タイトルの「せってい」で「いまの みため」「ドット（GBA ふう）」「くっきり（見やすい：白い 画面に 黒い 文字・太い わく・大きめの 文字）」を えらべる（`docs/REQUIREMENTS.md` 8.4）
- WEB版は **デバッグモード**：タイトルの「せってい」で、パックに 入る 弾を えらべる（`js/ui/settings.js` の `DEV`）。GAS 版では 先生だけ（開発モードの 画面で オン）。開発中の 弾・サブセット・番外編も えらべる（[`docs/ROADMAP.md`](docs/ROADMAP.md) 6章）
- ほかの AI や 新しい セッションへの 引き継ぎは [`docs/HANDOFF.md`](docs/HANDOFF.md)

## GAS（Google Apps Script）版とオンライン バトル

学校の iPad などで github.io が開けないときは、GAS のウェブアプリとして公開できる。手順は [`gas/README.md`](gas/README.md)。
GAS 版では **オンライン バトル（非同期）** が遊べる：冒険を おえた デッキが「ゴースト」になり、ほかの人のゴーストと たたかう（REQUIREMENTS 11章）。
GitHub Pages 版でも、見本デッキとの「れんしゅう」として遊べる。

```sh
node tools/build_gas.mjs   # gas/ の 1ファイル版を つくりなおす
```

## 漢字

3年生までに 習う 漢字だけを つかう。それ いがいは、画面の ことばは ひらがな、カードの 文章は ふりがな「漢字（よみ）」（REQUIREMENTS 3.1）。
カードの 文章は `docs/cards/*.md`・`docs/ENEMIES.md` に ふりがなを 書いて、`python3 tools/gen_texts.py` で `js/data/texts.js` に する。
`node tools/kanji.mjs` で、ふりがなの ない 習わない 漢字が のこって いないか しらべられる。

## 遊び方のポイント

- はじめての人は タイトルの「チュートリアル」（メレティスの 訓練場）から。白緑の きまった 手札で、マナ・召集・ブロック・圧倒・ぴったりを 1つずつ 案内する

- **たたかいの中に 計算問題は出ない**。勝つために考えると 自然に計算する（REQUIREMENTS 5章。問題を とくのは たたかいの そとの しゅぎょう だけ）。攻撃の あとに「3 ＋ 2 ＝ 5点」と けっかが出て、敵を タフネスと ちょうど同じ ダメージで 倒すと「ぴったり！」
- X は −／＋ で 自分で きめる。キッカー・増呪・激励は、使うときに マナを 多く はらうか えらぶ。待機は 手札から「待機する」、Lvアップは 戦場の カードを タップ

- 対象を選ぶカード（ダメージ・除去・強化・格闘・割り振る）は、使うときに相手を選ぶ。割り振るは ＋／− で分ける
- 上の「つぎの 敵」に、敵の次のターンの予定（攻撃してくる数とパワー・頭のダメージ・めくる枚数など）が出る。次に攻撃してくる敵には「つぎに 攻撃」の札
- 敵がめくったカードは、1まいずつ見せる
- 点線の ことば（キーワード能力・用語）は、長おしか2回タップで 小学3年生向けの せつめいが出る（js/ui/glossary.js）
- パックはガチャ風：光るパックをやぶり、裏の光り方（銀＝アンコモン・金＝レア・虹＝レジェンド）を見てから めくる。めくった カードは、テキスト欄 いがいを タップすると 次へ（テキスト欄は 長おしで ことばの せつめい）。「おと」で効果音を切りかえ
- 塔の ごほうびパックは、登るほど レアが出やすく、デッキで いちばん使っている色が 出やすい
- **てきの ターンにも インスタントや クリーチャーの 能力が 使える**：てきが こうげきしてきて ブロックを きめた あと と、てきの ターンの おわりに、使える インスタント（コンバットトリックも）が 手札で 光り、使える 能力（戦技 など）の ある クリーチャーも 光る。タップして 使う（使わないなら「つぎへ」）。自分の ターンで のこした マナで 使う（`docs/REQUIREMENTS.md` 8.8）
- 自分の クリーチャーを 敵へ スワイプすると 攻撃、敵の ターンに 自分の クリーチャーを 攻撃してきた 敵へ スワイプすると ブロック（タップでも できる）
- ボロスの 魔除けなど モードを 選ぶ 呪文は、使うときに モードを 選ぶ（自分の ターン・攻撃の とちゅう・敵の 攻撃の とき）。増呪なら いくつでも

## 試作版でできないこと

- 「敵に〜点」の能力（路地裏の火の子など）は、本体がない階では自動で相手が選ばれる
- 学年の設定は ない（将来、数の大きさを 学年で変える 案。REQUIREMENTS 5.2）
